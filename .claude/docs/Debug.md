# 디버깅 체크리스트

발견된 버그/개선 필요 사항을 여기에 기록하고 진행 상황을 체크박스로 추적한다.

**형식:** `- [ ] N. 제목` — 완료되면 `[x]`로 변경.

---

- [ ] 1. 점프 애니메이션이 높이(체공 시간)에 따라 구분되지 않음
  - **증상:** 점프 애니메이션 1종만 사용 중이라, 높은 곳에서 뛰어내릴 때 실제로 땅에 닿기도 전에 착지(Landing) 모션이 먼저 재생됨. 지금은 체공 시간과 무관하게 항상 같은 타이밍으로 점프→착지가 흘러감.
  - **원인:** `Brother_Anim_Jumping` 하나로 시작~착지를 전부 커버하고 있어서, 실제 낙하 거리/시간과 애니메이션 길이가 안 맞음.
  - **해결 방향:** `Jump_Start`(도약) / `Fall_Loop`(공중 유지, 루프) / `Jump_Landing`(착지) 애니메이션을 분리하고, 지면까지의 거리(Line Trace 등) 또는 체공 시간을 기준으로 상태 전환 조건을 추가해야 함.
  - **상태:** 보류 (지금은 단일 점프 애니메이션으로 진행, 추후 수정 예정)

- [ ] 2. 착지 직후 연속 점프 시 애니메이션이 깨짐
  - **증상:** 스페이스바를 빠르게 연타하면, 첫 점프는 정상 재생되지만 착지 후 바로 다시 점프할 때 애니메이션이 이상하게 출력됨.
  - **원인(추정):** 이전 `Jump → Idle/Run` 전환(블렌드)이 채 끝나기 전에 `Idle/Run → Jump` 전환이 다시 겹쳐 들어가면서 포즈가 꼬이는 것으로 추정.
  - **해결 방향:** `BP_Brother`에 재점프 쿨다운(`bCanJump` bool + 타이머, 착지 전환 시간보다 살짝 길게)을 추가해 이전 전환이 끝난 뒤에만 재점프를 허용하도록 게이트. 또는 각 전환의 Blend Duration을 줄여서 겹칠 여지를 줄이는 방법도 고려.
  - **상태:** 미착수

## 항목 추가 규칙

- 새 항목은 리스트 맨 아래에 번호를 이어서 추가한다.
- 각 항목은 **증상 / 원인(추정) / 해결 방향 / 상태** 4줄 구조를 기본으로 하되, 상황에 따라 생략 가능.
- 완료 시 체크박스만 `[x]`로 바꾸고 항목은 지우지 않는다 (이력 추적용).
