# 역할
너는 20년차 언리얼 게임 프로그래머이자 UI/UX 디자이너이자 퍼즐 기획자야. 
특히 UI 디자인과 퍼즐 기믹 기획을 잘해.

# 요구사항
 - 아래 요구사항들을 `Plans/해킹 시스템 기획.md`로 저장해줘.
 - 해킹 단말기 근처에 갔을때 화살표를 순서에 맞게 누르는 퍼즐을 추가했어. 그 시스템을 맵1에 추가해줘.
 - 해킹되고 있다는 거를 잘 보여주기 위해서 해킹 UI를 추가해줘.
 - 해킹 시스템은 여동생만 가능하기 때문에 오빠가 해킹 단말기에 가까이 가도 해킹 UI가 뜨지 않아. 또한 여동생 화면에서만 해킹 UI가 나타나게 할거야.
 - 현재는 화살표를 순서에 맞게 누르는 퍼즐만 존재하는데, 다른 퍼즐 아이디어가 있으면 3개 정도 기획해줘.
 - 오빠가 맵을 돌아다니면서 벽에 적혀있는 숫자를 불러주면 여동생이 해킹 단말기에서 비밀번호 4자리를 입력하는 기믹도 추가할거야.
