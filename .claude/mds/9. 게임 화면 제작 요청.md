# 역할
너는 20년차 언리얼 게임 프로그래머이자 UI/UX 디자이너야.
특히 UI 디자인을 매우 잘해.

# 배경
 - `Project_CX`에 어울리는 UI 디자인을 할거야.
 - 지금은 **ESC 메뉴, 게임 시작화면, 게임 오버화면, 게임 클리어화면**을 구현하기 위한 기획서를 작성하는 단계야. 아직 언리얼로 구현하는 단계가 아니야.
 - 게임은 **한 PC에서 2인 로컬 협동**(오빠 + 여동생, 화면 분할)으로 진행돼.

# 요구사항
 - 아래 내용을 바탕으로 기획서를 만들어 `.claude/Plans` 폴더에 **화면별로 나눠서** 저장해줘.
    - `ESC 메뉴 기획.md`
    - `게임 시작화면 기획.md`
    - `게임 오버화면 기획.md`
    - `게임 클리어 화면 기획.md`
    - `설정 메뉴 기획.md` — ESC 메뉴와 시작화면이 같은 설정 메뉴를 쓰므로 별도 문서로 두고, 두 문서에서는 참조만 해.
 - 각 기획서에 다음 내용을 넣어줘: **언리얼에서 한글이 깨져 보이면 메뉴명을 모두 영어로 바꿔도 된다.** (한글을 쓰려면 한글 폰트 에셋, 예: Noto Sans KR을 프로젝트에 추가해야 함)
 - 아직 없는 시스템은 전투 시스템이 갖춰진 뒤 구현할 예정이야. 각 기획서에 **필요한 전제 시스템**으로 명시해줘.
    - **세이브포인트(체크포인트) 저장**: 이어하기·재시작·타이틀로 이동 시 저장 범위의 기준
    - **체력 / 사망 판정**: 사망 조건은 체력 0 또는 낙사
    - **부활(리스폰) 시스템**: 게임 오버화면 참고
    - **클리어 판정**: 마지막 맵(`Map3_Final`, 보스방) 출구 문 앞에서 두 사람이 각자 버튼을 눌러 문을 열면 게임 클리어(게임 클리어화면 참고)

## 공통 규칙 (모든 화면)

 - **메뉴는 화면 전체에 하나만** 띄운다(분할된 한쪽 칸이 아님). 두 플레이어 **누구나** 메뉴를 조작할 수 있다.
 - **게임패드로도 모든 메뉴를 조작**할 수 있어야 한다(여동생은 기본적으로 게임패드 사용).

    | 동작 | 키보드/마우스 | 게임패드 |
    |---|---|---|
    | 메뉴 열기/닫기 | `ESC` | `Start` |
    | 이동 | 방향키 / 마우스 | D-pad / 왼쪽 스틱 |
    | 선택 | `Enter` / 클릭 | `A` |
    | 뒤로 | `ESC` | `B` |

 - 되돌릴 수 없는 동작(타이틀로, 새 게임 덮어쓰기, 게임 종료)은 **확인창**을 띄운다. 단, 게임 클리어화면의 `타이틀로`는 잃을 진행이 없으므로 확인창 없이 바로 이동한다.
 - 비주얼은 인게임 HUD와 같은 톤으로 통일한다: 어두운 반투명 패널 + 얇은 네온 라인, 오빠 청록 / 여동생 마젠타 (`.claude/Plans/HUD 기획.md` 참고).

## 설정 메뉴 (ESC 메뉴·시작화면 공용)

 - `사운드`: 음량 바 3개 — `전체`, `배경음`, `효과음`.
 - `화면 분할`: `상하` / `좌우` 선택, **기본값 상하**. (만일에 대비해 두는 옵션)
 - `조작 장치`: 오빠와 여동생이 각각 **키보드/마우스**와 **게임패드** 중 무엇을 쓸지 지정한다.
    - 기본값: 오빠 = 키보드/마우스, 여동생 = 게임패드.
    - 둘 다 게임패드도 가능하다. 키보드는 하나뿐이므로 두 사람 모두 키보드는 불가.
    - 플레이 중 장치가 바뀌면 혼란스러우므로 **시작화면에서만 변경**할 수 있고, ESC 메뉴에서는 현재 설정만 보여준다.
 - `조작법`: 오빠/여동생 조작 안내 페이지(키보드·게임패드 각각). 현재 조작 장치 설정에 맞는 쪽을 먼저 보여준다.
 - 설정값은 게임을 껐다 켜도 유지되도록 저장한다.

## ESC 메뉴

 - 플레이 중 `ESC`(게임패드 `Start`)를 누르면 메뉴창이 열리고 **게임이 일시정지**된다(두 플레이어 모두).
 - 다시 `ESC`/`Start`를 누르거나, `계속하기` 또는 `뒤로`(`B`)를 누르면 닫히고 게임이 재개된다.
 - 메뉴 목록
    - `계속하기`: 메뉴를 닫는다.
    - `설정`: 설정 메뉴를 연다(조작 장치는 보기만 가능).
    - `타이틀로`: 확인창("마지막 세이브포인트 이후의 진행은 사라집니다") 후 진행 중인 맵을 종료하고 시작화면으로 이동한다. **세이브포인트에서 저장한 내용만 남는다.**

## 게임 시작화면

 - 게임을 실행하면 처음 나오는 화면이다.
 - 구성
    - 게임명: 지금은 임시로 `Project_CX`라고 출력한다.
    - 배경: 시작화면 배경 이미지, 또는 Map1 풍경을 천천히 움직이는 카메라로 보여준다.
    - `P2 PRESS START`: 2인 플레이이므로 시작 전에 2P 장치 연결을 확인한다.
 - 메뉴 목록
    - `이어하기`: 세이브가 있을 때만 표시. 마지막 세이브포인트에서 시작한다.
    - `새 게임`: 처음부터 시작한다. 세이브가 있으면 덮어쓴다는 확인창을 띄운다.
    - `설정`: 설정 메뉴를 연다(조작 장치 변경 가능).
    - `게임 종료`: 확인창 후 게임을 종료한다.

## 게임 오버화면

 - 부활 규칙
    - 캐릭터가 죽으면 **10초 뒤에 부활**한다. 대기 중에는 그 플레이어 화면에 부활까지 남은 시간을 보여준다.
    - 한 명이 부활 대기 중일 때 **나머지 한 명도 죽으면** 게임 오버화면이 나온다.
 - 누가 마지막으로 쓰러졌는지 보여준다(예: `SISTER — SIGNAL LOST`).
 - 두 플레이어 누구나 메뉴를 선택할 수 있다.
 - 메뉴 목록
    - `재시작`: 마지막 세이브포인트에서 다시 시작한다. **세이브포인트를 하나도 지나지 않았다면 맵 시작 지점**에서 시작한다.
    - `타이틀로`: 시작화면으로 이동한다.

## 게임 클리어화면

 - MVP 진행 구조: 방 1 → 방 2 → 세이브 복도 → 마지막 방(보스맵, `Map3_Final`) → 클리어.
 - 클리어 조건: 두 사람이 모두 출구 문 앞에 도착해 **각자 자기 버튼을 눌러야** 문이 열린다. 문이 열리면 이 화면이 나온다.
 - 클리어하면 **세이브포인트를 초기화**한다(시작화면에 `이어하기`가 더 이상 나오지 않음).
 - 아직 엔딩 연출이 없으므로 **임시 화면**으로 둔다.
 - 화면 중앙에 `Coming Soon` 텍스트를 띄운다.
 - 두 플레이어 누구나 메뉴를 선택할 수 있다.
 - 메뉴 목록
    - `타이틀로`: 시작화면으로 이동한다. (버튼은 이것 하나만 둔다)
