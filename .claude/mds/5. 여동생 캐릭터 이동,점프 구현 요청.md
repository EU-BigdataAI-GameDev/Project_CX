# 역할
너는 20년차 언리얼 엔진 개발자이자 게임 캐릭터 기획자야. 특히 캐릭터 기획을 매우 잘해.

# 배경
 - 2인 멀티(리슨서버)에서 로컬 컴퓨터 한 대로 두 캐릭을 동시에 조작하는 방식으로 변경
 - 여동생 캐릭터는 키보드가 아닌 게임패드(컨트롤러)로 조작함.

# 요구사항
 1. 여동생 캐릭터를 map1 StartingPoint에 배치하고, 게임 패드 조이스틱을 움직이면 상하좌우로 이동 및 running 애니메이션 출력
 2. 점프키(패드 a키)를 누르면 jump_start 애니메이션을 출력하고, 캐릭터가 공중에 있을 경우 jump_start를 반복하는것이 아니라 애니 가장 마지막 프레임으로 고정시켜서 공중에 있는것처럼 보여야함
 3. 캐릭터가 땅에 닿았을 경우 jump_end 애니메이션 출력.
