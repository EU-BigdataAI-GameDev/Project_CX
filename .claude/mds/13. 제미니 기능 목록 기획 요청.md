# 역할
너는 20년차 언리얼 게임 개발자이자 AI API를 활용한 AI봇 개발자야.

# 배경
- 도우미 드론 로봇 '제미니'를 게임에 추가했어.
- 모델링과 API연결은 완료한 상태야.(모델: gemini-3.5-flash-lite)
- 실제 게임에서 요청할 수 있는 기능 목록을 기획서로 리스트업할거야.

# 요구사항
- 아래 기능 목록들을 참고해서 '제미니'에게 채팅/음성으로 명령을 전달했을때 실제 게임에서 반영되도록 해줘
- 기능을 수행할때 제미니도 대사를 쳐주도록 해줘. 예를들어 재장전 요청이 들어왔으면 제미니가 "재장전 해드릴게요!"라고 대사를 출력하면서 재장전이 진행되도록 해줘.
- 요구사항 내용들을 `제미니 기능 기획.md`로 작성하고 실제 구현은 아직 하지마.

## 재장전
- 오빠의 탄약 재장전
- 배터리 5 소모
- "재장전", "재장전해줘","재장전 부탁해"와 같이 재장전과 관련된 입력 시 발동
## 해킹
- 단말기 해킹
    - 단말기 퍼즐을 대신 풀어줌(3초 소모)
    - 배터리 20 소모
    - "퍼즐 좀 풀어줘","해킹 좀 대신해줘"와 같이 퍼즐/단말기 해킹 풀이와 관련된 입력 시 발동
- 적 해킹
    - 적 로봇을 해킹해서 그로기 상태로 만듦(즉시 발동)
    - 배터리 20 소모
    - "적 해킹해줘","적 무력화시켜줘"와 같이 적 해킹과 관련된 입력 시 발동
## 적 공격
- 강력한 펄스를 방출해 적을 한방에 물리침.
- 배터리 50 소모
- "적 공격해","적 처치해줘","적 좀 어떻게 해봐"와 같이 적을 공격/처치와 관련된 입력 시 발동
- 적 해킹과 헷갈리는 입력이 들어오면 적 해킹을 우선 발동. 적 공격은 배터리 소모가 많아 가급적 해킹 우선
## 오빠 공격력 강화
- 오빠의 레일건 공격력 증가시킴(30초간)
- 배터리 10 소모
- "공격력 올려줘","데미지 올려줘"와 같은 공격력 지원과 관련된 입력 시 발동
## 체력 회복
- 오빠와 여동생 체력 50 회복
- 배터리 30 소모
- "힐 좀 해줘","체력 채워줘","힐 부탁해" 와 같이 힐/체력과 관련된 입력 시 발동
