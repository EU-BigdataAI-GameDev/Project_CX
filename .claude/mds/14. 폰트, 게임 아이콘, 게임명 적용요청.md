# 역할
너는 20년차 언리얼 개발자이자 UI디자이너야.

# 배경
- `Art/Fonts`폴더에 두 개의 폰트를 넣어놨어.
- `Art/Icon`폴더에 게임에 사용할 아이콘 이미지를 넣었어.
- 게임명은 `Project_CX` -> `CAELUM:UNCHAINED`로 정했어.

# 요구사항
- 아래 요구사항들을 적용해줘.

## 게잉 타이틀 적용
- 확정한 게임명을 게임 시작 화면에 적용하고 다른 게임 화면에도 'Project_CX'라고 적힌 것들은 다 바꿔줘.

## 아이콘 적용
- 게임 아이콘을 Icon에 있는 `CAELUM_UNCHAINED_Icon.png` 이미지로 설정해줘.

## 글자 폰트 적용
- 아래 `UI 폰트 가이드`는 GPT가 추천해준 폰트에 대한 설명이야. 이를 참고해서 적절한 글자에 각 폰트들을 적용해줘.

### UI 폰트 가이드
```
# CAELUM: UNCHAINED — UI 폰트 가이드

게임의 사이버펑크·디스토피아 세계관에 어울리는 두 가지 폰트를 선정했습니다. 각 폰트의 특징과 권장 용도를 참고하여 HUD 및 UI에 적절하게 적용해 주세요.

### 1. Oxanium — 메인 게임 UI 폰트

**특징**
- 각지고 기하학적인 형태가 특징인 미래지향적 서체
- SF 게임, 우주선 조종석, 첨단 장비의 HUD를 연상시키는 디자인
- 기계적이고 날카로우면서도 비교적 깔끔한 인상
- 숫자와 짧은 영문 레이블에서 개성이 잘 드러남

**어울리는 용도**
- 플레이어 상태 및 전투 HUD
- 체력, 탄약, 에너지 등 주요 수치
- 무기 및 장비 이름
- 메뉴 제목, 버튼, 주요 알림
- 즉각적인 판단이 필요한 게임플레이 정보

**디자인 키워드:** Futuristic / Tactical / Sci-Fi / Mechanical

### 2. IBM Plex Mono — 시스템·해킹 UI 폰트

**특징**
- 모든 문자의 폭이 동일한 고정폭(Monospace) 서체
- 프로그래밍 터미널, 시스템 콘솔, 네트워크 진단 화면을 연상시키는 디자인
- 정돈되고 분석적이며 기술적인 인상
- 코드, 숫자, 로그처럼 규칙적인 데이터 표현에 적합
- Oxanium보다 장식성이 적어 두 폰트의 시각적 대비를 만들기 좋음

**어울리는 용도**
- 해킹 인터페이스와 퍼즐 UI
- 시스템 메시지 및 상태 로그
- 네트워크 연결 상태, 접근 권한, 오류 코드
- 스캔 결과, 진단 데이터
- 터미널 및 기술 정보

**디자인 키워드:** Terminal / Digital / Technical / Data

### 적용 방향

**Oxanium은 플레이어에게 전달하는 게임 정보, IBM Plex Mono는 게임 세계 속 시스템이 출력하는 데이터**라는 기준으로 구분하면 좋겠습니다.

다만 이 기준을 엄격하게 강제하기보다는 각 UI의 목적과 가독성을 고려하여 유연하게 적용해 주세요.

기존의 Cyan(오빠·전투)과 Magenta(여동생·해킹) 색상 체계는 유지하고, 폰트의 개성과 정보의 중요도가 자연스럽게 드러나도록 구성해 주세요.

최종적으로 두 폰트가 서로 다른 인터페이스처럼 느껴지는 것이 아니라, 하나의 사이버펑크 UI 디자인 시스템 안에서 조화롭게 사용되는 것이 목표입니다.
```
