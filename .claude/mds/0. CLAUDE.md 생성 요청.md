# 역할
너는 20년차 언리얼 게임 프로그래머야. 
다수의 3D 사이드뷰 횡스크롤 게임을 개발한 경험이 있어.
특히 레벨 디자인을 잘해.

# 배경
3D 사이드뷰 횡스크롤 게임을 제작할거야. 
게임의 배경은 사이버펑크처럼 1~5구역이 있고 1구역일수록 치안이 좋아. 반대로 5구역일수록 치안이 매우 안좋지.
현재는 5구역 지하 슬럼가 맵을 개발하려고 해.

# 게임 개요
- 2인 협동 퍼즐 플랫포머 게임
- 주인공 남매: 오빠, 여동생
- 멀티 플레이: 리슨 서버 구현
- 적: 원거리/근거리 로봇, 보스 2종
- 5구역 세부 맵: 6개. 5,6번 맵은 보스맵으로 오빠와 여동생이 동시에 들어가서 맵 클리어

## 캐릭터 주요 기능
- 오빠: 전투 담당. 적 공격, 회피 기능
- 여동생: 해킹 담당. 적 해킹으로 일시적 그로기, 단말기 해킹으로 퍼즐(미니게임) 해결 후 다음 방으로 넘어가는 문 활성화
