# 역할
너는 20년차 언리얼 엔진 개발자이자 사운드 디자이너야.

# 요구사항
 - 게임에 필요한 효과음을 적용하기 위한 효과음을 리스트업할거야.
 - 필수 효과음 목록은 다음과 같아.
 - 아래 효과음 목록 외에 필요할 것 같은 리스트도 추가해줘.
 - 언리얼에 효과음 적용을 위한 기획서를 `Plans/효과음 적용 기획.md`로 작성해줘.

## 필수 효과음 목록
 - 플레이어 공통
    - 달리기(발자국 소리)
    - 점프
    - 착지
 - 오빠
    - 레일건 발사
    - 장전(에너지 충전)
 - 여동생
    - 해킹 중
    - 해킹 성공
    - 해킹 실패
 - 적(거미 로봇)
    - 움직임(기계소리)
    - 공격(톱날 소리)
 - 버튼 클릭
