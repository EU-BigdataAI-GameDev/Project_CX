- 배경음(BGM)은 수노 AI로 따로 제작한다. 이 문서는 **효과음(SFX)과 환경음**의 목록, 에셋 공수 방법, 언리얼 적용 방식을 다룬다.

## 1. 전제

| 항목 | 내용 | 사운드 설계에 미치는 영향 |
|---|---|---|
| 플레이 형태 | 한 PC 2인 로컬 협동, 상하 분할 화면 | 스피커는 하나뿐이다. 두 사람이 모든 소리를 같이 듣는다. 한 사람 전용 소리(해킹 UI 등)는 다른 소리와 음색을 확실히 구분한다 |
| 카메라 | 사이드뷰 망원(FOV 37.5), 캐릭터에서 약 13m 뒤 | 리스너가 카메라에 있으면 모든 소리가 멀고 작게 들린다. 리스너 위치를 **캐릭터 위치로 옮긴다**(6.3) |
| 리스너 | 분할 화면이라 리스너가 2개 | 언리얼은 소리마다 가장 가까운 리스너를 기준으로 계산한다. 두 캐릭터가 떨어져 있어도 각자 주변 소리가 잘 들린다 |
| 네트워크 | listen server 전제(실제 플레이는 로컬) | 소리는 연출용이다. 이미 복제되는 상태(총알 액터 스폰, 단말기 State 등)에 붙여 모든 머신에서 재생한다(6.5) |
| 일시정지 | ESC 메뉴에서 월드 전체 일시정지 | 월드 소리는 같이 멈춘다. UI 소리는 `bIsUISound = true`로 재생해야 일시정지 중에도 들린다 |

## 2. 효과음 목록

표기 규칙
- **구분**: ★ 필수(요청 목록) / ☆ 추가 제안
- **공간**: 3D = 월드 위치에서 재생(감쇠·패닝 적용) / 2D = 화면 소리(UI·피드백)
- **변형**: 같은 소리의 버전 개수(랜덤 재생으로 반복감 제거)
- **공수**: 3장의 출처 코드. SC = 프로젝트 안의 SoulCity 에셋, SN = Sonniss GDC 번들, KN = Kenney, FS = Freesound(CC0 우선), LY = 여러 소리를 겹쳐 직접 가공

## 3. 에셋 공수 방법

| 코드 | 출처 | 쓰는 곳 | 라이선스 / 주의 |
|---|---|---|---|
| SC | 프로젝트 안 `Content/SoulCity/Sound/` (발소리 흙·금속 각 8개, 비, 슬럼, 증기, 불꽃, 바람, 물, 철판 흔들림) | 발소리, 환경음 전부, 불꽃 계열 가공 재료 | 이미 프로젝트에 포함된 에셋팩. 추가 비용 없음 |
| SN | Sonniss GDC 무료 번들(매년 공개) | 총·충격·기계·서보·톱날·폭발 등 사실적인 소리 | 상용 사용 가능, 크레딧 의무 없음. 받은 연도와 파일명을 기록해 둔다 |

### 5.2 Sound Class(음량 바 3개와 연결)

```
SCl_Master            ← 설정 "전체"
├─ SCl_BGM            ← 설정 "배경음"
└─ SCl_SFX            ← 설정 "효과음"
   ├─ SCl_SFX_UI      (일시정지 중에도 재생, 일시정지 덕킹 제외)
   └─ SCl_Ambient     (환경음. 효과음 바를 따른다)
```

- `SMix_UserVolume`: 설정 메뉴 값을 Sound Class 음량으로 적용하는 믹스. 게임 시작 시 Push하고 계속 유지한다.

## 6. 언리얼 적용 방식(C++ 우선)

### 6.1 재생 지점(코드 연결표)

| 소리 | 연결 위치 | 방법 |
|---|---|---|
| 발소리 | 오빠 `Brother_Anim_Running_InPlace`, 여동생 달리기 애니메이션 | C++ `UAnimNotify_CXFootstep`(신규): 단일 발소리 에셋 하나를 발 위치에서 `PlaySoundAtLocation`. 바닥 판별 없음. 두 캐릭터 애니메이션에 같은 노티파이를 단다 |
| 점프 | 플레이어 캐릭터 | `OnJumped()` 오버라이드 |
| 착지 | 플레이어 캐릭터 | `Landed(const FHitResult&)` 오버라이드. 낙하 속도 800cm/s 이상이면 강, 아니면 약 |
| 레일건 발사 | `ABrotherBullet::BeginPlay` | 총알은 복제되는 액터라 모든 머신에서 같은 위치에서 재생된다 |
| 장전 충전 | `UBrotherCombatComponent::StartReload` / `FinishReload` | `UAudioComponent` 하나를 Play/Stop. Tick에서 `GetReloadProgress()`를 피치 파라미터로 넘긴다 |
| 헛방 / 탄약 부족 | `UBrotherCombatComponent::Fire` | 탄약 0이면 헛방, 25% 경계를 넘는 순간 경고음 1회 |
| 탄 충돌 | `ABrotherBullet` 충돌 처리 | 맞은 대상이 적인지 벽인지로 소리 구분 |
| 해킹 루프·결과 | `USisterHackComponent` | 세션 시작/종료에 루프 Play/FadeOut, `SetFeedback(EHackFeedback)`에서 Correct / RoundClear / Denied / Granted별 소리 |
| 게이트 꺼짐 | `AHackTerminal::ApplyStateVisuals`(`Hacked` 분기) | `UnlockActors` 위치에서 재생. State가 복제되므로 모든 머신에서 재생된다. 단, 레벨 시작 시 이미 `Hacked`인 상태로 복제될 때는 재생하지 않는다 |
| 단말기·게이트 루프 | `AHackTerminal`, 게이트 액터 | `UAudioComponent`(자동 재생). 해킹 성공 시 게이트 루프 정지 |
| UI | `UCXMenuWidgetBase::PlayUISound` | 이미 있는 슬롯에 에셋만 지정. `PlaySound2D(..., bIsUISound = true)` 확인 |
| 거미로봇(보류) | 적 클래스(미구현) | 적 구현 후 적용. 움직임 루프는 `UAudioComponent` + 이동 속도 → 음량·피치, 다리 착지와 톱날은 AnimNotify |

### 6.2 소리 에셋 지정 방식

- 지금 메뉴 위젯처럼 **각 클래스에 `UPROPERTY(EditDefaultsOnly) TObjectPtr<USoundBase>` 슬롯**을 둔다. 슬롯이 비어 있으면 아무것도 재생하지 않는다(에셋이 없어도 오류 없이 동작).
- 기본값은 C++ 생성자에서 경로로 지정하거나, 이미 있는 BP 자식 클래스(예: `BP_` 캐릭터)의 기본값에서 지정한다. 데이터 지정만 BP에서 하고 로직은 C++에 둔다.
- 슬롯이 많은 클래스(해킹 컴포넌트 등)는 소리를 묶은 데이터 에셋(`UCXHackSoundSet : UDataAsset`)으로 정리해도 된다. 소리 교체가 에셋 하나에서 끝난다.

### 6.3 리스너 위치

- 플레이어 컨트롤러(`LocalCoopGameMode`가 쓰는 컨트롤러)에서 리스너 위치를 **자기 폰 위치 + 위로 100cm**로 덮어쓰고, 회전은 카메라 그대로 둔다(`APlayerController::GetAudioListenerPosition` 오버라이드 또는 `SetAudioListenerOverride`).
- 효과: 13m 뒤 카메라 기준으로 모든 소리가 작고 멀게 들리는 문제가 없어지고, 감쇠 거리를 캐릭터 기준으로 직관적으로 정할 수 있다.

### 6.4 음량 설정 연결

- `UCXAudioSubsystem`(GameInstanceSubsystem, 신규): 게임 시작 시 저장된 설정의 음량 3개를 읽어 `SMix_UserVolume`에 `SetSoundMixClassOverride`로 적용하고 Push한다.
- 설정 메뉴에서 바를 움직이면 즉시 같은 함수로 다시 적용한다(`설정 메뉴 기획.md` 사운드 항목).
- 일시정지 덕킹 `SMix_PauseDuck`의 Push/Pop도 이 서브시스템이 맡는다.

### 6.5 네트워크

- 소리는 연출용이므로 RPC를 따로 만들지 않는다. **이미 복제되는 것에 붙인다**: 총알 액터 스폰, 단말기 State, 캐릭터 이동(애니메이션은 모든 머신에서 재생되므로 AnimNotify 발소리도 자동으로 재생됨).
- 해킹 UI 소리는 해킹하는 여동생의 로컬 머신에서만 재생한다(로컬 협동에서는 같은 스피커).

## 8. 검증

- PIE에서 두 캐릭터가 달릴 때 발 닿는 타이밍에 같은 발소리가 나고, 8개 버전이 랜덤으로 돌아가는지 확인.
- 레일건 연사 시 소리가 3개 넘게 겹치지 않는지(동시 재생 제한).
- 장전 충전음이 장전 게이지(HUD `RECHARGING %`)와 같이 올라가고, 장전이 끝나면 바로 멈추는지.
- 해킹: 정답·라운드 통과·실패·성공 소리가 HUD 연출과 같은 프레임에 나는지. 게이트 꺼짐 소리가 게이트 위치에서 나는지.
- ESC 메뉴를 열었을 때 월드 소리는 멈추고 UI 소리는 나는지, 배경음이 낮아지는지.
- 설정 음량 바 3개가 각각 해당 소리에만 적용되는지, 껐다 켜도 유지되는지.
- 오빠와 여동생이 멀리 떨어져 있을 때 각자 주변 소리가 들리는지(분할 화면 리스너 2개).

## 9. 확인 필요 사항

1. **거미로봇**: 이동·공격·사망이 구현되면 2.4 표를 기준으로 보류를 푼다.
2. **회피·체력·부활·세이브**: 시스템이 없어 관련 소리는 목록만 두었다(3단계).
3. **단일 발소리 에셋**: 기본값은 SoulCity `Footstep_Dirt_Cue`. 들어 보고 금속 쪽이 맞으면 `Footstep_Metal_Cue`로 교체한다(노티파이 슬롯 하나만 바꾸면 됨).

- 사운드 클래스: 게임플레이 = `SCl_SFX`, UI = `SCl_SFX_UI`. 루프 3개(장전·해킹·단말기)는 `Looping` + `VirtualizationMode = PlayWhenSilent`.
- 음량: 원본 크기를 재서(400ms 최대 RMS) 에셋 `Volume`으로 대략 맞춤 — 레일건 0.9, UI 0.6~1.0, 해킹 루프 0.18, 단말기 웅웅거림 0.35, 장전 루프 0.3 등. 실제 청취로 다듬어야 한다.

**기획과 다른 점**
- 발소리: 6.1의 AnimNotify 대신 **이동 거리 기반**(애니메이션 에셋을 고치지 않기 위해). 발이 닿는 프레임과 정확히 맞지는 않는다 — 어긋나 보이면 `StrideLength`를 조정하거나, 나중에 노티파이로 바꾼다.
- 점프·착지: 전용 SN 소리 대신 SoulCity 발소리 큐를 피치·음량만 바꿔 재사용(AI 효과음 금지 + 사용 가능한 소스 기준).
- 변형 랜덤: Sound Cue(`SC_*`) 대신 C++ 슬롯 배열에서 랜덤 선택(레일건·벽 충돌).
- 리스너: 플레이어 컨트롤러 서브클래스를 만들지 않고, 위 컴포넌트가 매 틱 `APlayerController::SetAudioListenerOverride`를 호출(맵이 쓰는 기본 `APlayerController` 그대로, 카메라 수정 없음).
- **총알 지형 충돌 수정**: 레벨 벽/COL 박스는 Generate Overlap Events가 꺼져 있어 총알이 벽을 뚫고 지나갔다(벽 충돌음이 날 수 없음). `CollisionComp`의 WorldStatic 응답을 Block으로 바꾸고 `OnProjectileStop`에서 충돌음 + 소멸 — `공격 시스템.md` 체크리스트("지형 충돌 시 소멸")와 맞춘 동작 변경이다.
- 장전·헛방·탄약 부족·조준 고정은 원래 복제되지 않는 로컬 로직(탄약이 비복제)이라 오빠를 조작하는 머신에서만 난다(로컬 협동에서는 같은 스피커라 차이 없음).
- 거미로봇·피격/사망/부활·게임 오버/클리어 징글·환경음 배치·`SMix_PauseDuck`은 이번 범위 밖.

- 리스너: 두 컨트롤러 모두 덮어쓰기 적용, 위치 = 각자 폰 +100cm, 앞 방향 (0.98, 0, -0.17) = 카메라.
