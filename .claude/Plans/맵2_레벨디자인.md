## 1. 컨셉

Map1(평평한 거리 + 뒤쪽 파사드)과 **다른 체감**을 목표로, 맵2는 "위아래로 쌓인 판자촌"이다.

- **수직성**: 수로 바닥(-210) ~ 옥상(728)까지 약 9.4m의 높이 차를 오르내린다.
- **단면(컷어웨이) 연출**: 3층 공동주택의 앞벽을 잘라낸 단면을 지나며 방 안을 통과한다(Little Nightmares 식 스케일감).
- **갈라짐-합류 1회**: 여동생은 낮은 처마 밑 통로(천장 170cm), 오빠는 지붕 위 루트. 몸 크기 차이로 **코드 없이** 분기가 성립한다.
- **톤**: 젖은 수로, 녹슨 양철 지붕, 빨래와 전선이 얽힌 거주 구역 → 끝에서 동굴 암반으로 내려가 Map3(산업 시설)로 이어짐.
- **조명**: 맵 전체를 비추는 기본광(스카이라이트 + 동굴 틈 달빛) 위에 구간별 실제 광원을 배치한다(§7).

## 2. 좌표계와 플레이어 실측 (BP 실측값)

| 항목 | 오빠 | 여동생 |
|---|---|---|
| 캡슐 반경 / 반높이 | 34 / 88 (키 176) | 34 / 80 (키 160) |
| 걷기 속도 / JumpZ / 중력 | 450 / 420 / 1.0 | 450 / 420 / 1.0 |
| 최고 점프 높이 | 420²/(2·980) ≈ **90cm** | ≈ 90cm |
| 자동 계단 오르기 / 걸을 수 있는 경사 | 45cm / 44.8° | 45cm / 44.8° |
| 공중 제어 | 0.05 (거의 없음) | 0.35 |
| 카메라 | 붐 500, 피치 0 | 붐 800, 피치 -10, 소켓 Z+100 |

- 진행 방향 **+Y**, 카메라는 **-X** 쪽에서 +X를 바라본다.
- **설계 한계(여동생 기준)**: 필수 상승 점프 ≤ **55cm**, 필수 간격 ≤ **180cm**(오빠 공중 제어가 0.05라 Map1의 200보다 보수적으로), 계단 30°, 일반 천장 ≥ 210cm.
- **여동생 전용 높이**: 통로 천장 **170cm** → 여동생(160) 통과, 오빠(176) 불가.

## 3. 카메라 가림 규칙 (요구사항: 캐릭터 앞쪽에 지형지물 금지)

- 플레이 레인: X ∈ [-120, 150]. **X < -120 영역에는 바닥 높이 이상의 메시를 두지 않는다.** 바닥 판(윗면이 발판 높이 이하)까지만 허용.
- 배경/장식은 전부 레인 뒤(X > 150)에 둔다.
- 머리 위 천장이 있는 구간(처마 통로, 공동주택 1·2층)은 천장 앞 모서리가 카메라 시선에 걸리지 않게 계산했다.
  - 여동생 카메라 시선 높이: 캐릭터 앞 d cm 지점에서 `Z = h + (320 - h)·d/790` (h = 몸 높이)
  - 처마 통로: 천장 170 → 앞 모서리가 머리에서 약 50cm 이내여야 함 → 통로 깊이를 100cm로 제한(머리 끝 몇 cm 외엔 보임)
  - 공동주택: 천장 334 이상 → d가 800cm를 넘어야 가려지므로 문제 없음
- 스프링암 충돌: 두 캐릭터 모두 `bDoCollisionTest = true` 이므로 **모든 COL 박스는 Camera 채널을 무시**하게 만든다(앞쪽 경계벽이 카메라를 끌어당기는 문제 방지).

### 4.1 S2 갈라짐-합류 상세 (맵2의 핵심)

```
      Z
  365 |                  ┌R3┐
  310 |          ┌──R2───┘  │  ┌──R4──┐          (오빠: 뒤쪽 X -20~150)
  260 |  ╱계단┌R1┘          └──┘      └╲계단
      | ╱     ├──────────── 처마(170~190) ──────┤   (여동생: 앞쪽 X -120~-20)
    0 |╱______│ 여동생 통로 (천장 170)          │_______
      +--------------------------------------------------→ Y
       2550  3000        3870  4400 4780  5300  5820 6000
```

- 갈림길(Y 2550~3000): 뒤쪽엔 지붕으로 오르는 계단, 앞쪽엔 낮은 처마 입구 — 입구 모양 자체가 "여기서 갈라진다"를 예고.
- 여동생 통로는 오빠가 들어갈 수 없다(170 < 176). 지붕 루트는 여동생도 갈 수 있다(해킹 문 연동은 추후 — §6).
- 오빠가 지붕 위에 있을 때 처마(앞쪽, 190 이하)는 발밑보다 낮아 오빠를 가리지 않는다.
- 합류(Y 5600~6000): 통로 출구와 내리막 계단이 같은 마당으로 모인다. 합류 직전 체크포인트.

## 8. 검증 계획

1. 빌드 후 레벨을 다시 열어 생성 액터 수 = manifest 항목 수 확인
2. 모든 COL 박스: BlockAll + Camera 무시, 장식 메시: NoCollision
3. 필수 점프: 상승 ≤ 55, 간격 ≤ 180
4. 천장 높이: 여동생 통로 170(오빠 불가), 그 외 머리 위 공간 ≥ 210
5. X < -120 에 바닥 높이를 넘는 메시 없음 (자동 검사)
6. 라이트 액터 0개
7. 조명이 없으므로 캡처는 Lighting 쇼플래그를 끈 상태(언릿)로 구간별 확인

### 작업 중 수정한 것

- **여동생 스폰 위치 버그(기존 코드)**: `LocalCoopGameMode`에서 2P가 1P 시작 지점 옆에 스폰되던 문제. 로그인 중(`InitNewPlayer`)에는 LocalPlayer가 아직 없어 2P 판정이 실패하고 1P 시작 지점이 캐시되던 것이 원인 → `IsSecondLocalPlayer`가 LocalPlayer가 없을 때는 "첫 컨트롤러가 아니면 2P"로 판정하도록 수정(.cpp만, 라이브 코딩 반영).
- 수면: `SM_Water_A`는 외곽이 불규칙해 수로 바닥이 비쳐 보여서, 사각 평면 + 같은 물 머티리얼로 교체.
- 뒤쪽 바닥이 없어 건물/바위가 떠 보이던 문제 → 레인 뒤 바닥 평면 추가, 중경/원경 바닥 높이 정리.
- 레인 일부만 쓰는 계단 밑이 비어 보이던 문제 → 계단식 벽판으로 채움.
