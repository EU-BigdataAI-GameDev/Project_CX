## 3. 전투 루프

```
거미로봇 감지(플레이어 접근) → 추적 → 접촉하면 톱 내려찍기 루프(1.1초마다 30, 피격 무적 1초가 연속 피해를 거름)
  → 대상이 범위를 벗어나면 공격 중단·다시 추적 / 대상 사망 시 다음 생존자
오빠: 우클릭 조준 / 좌클릭 발사(10) → 5발 → 거미로봇 파괴
플레이어 체력 0 → 기존 흐름: 파트너 생존 시 10초 후 부활(체력 100, 무적 2초) / 둘 다 사망 시 게임 오버
여동생: 무기 없음 — 거미로봇을 피해 다니며 해킹 담당(피격·사망은 동일 규칙)
```

## 5. 총알 발사 (요약 — 상세는 `자동 조준 사격 구현.md`)

전투가 의존하는 부분만 요약한다. 구조는 그대로 유지하고 **데미지 값과 타겟 필터만** 바꾼다.

| 항목 | 현재(유지) | 이번 변경 |
|---|---|---|
| 조준 | 우클릭 Hold → `FindNearestTarget`(3000cm, 전방 120°, LOS) → `CurrentTarget`, 5m 근접 자동 조준 | 후보에서 **사망한 적 제외**(사망 후 3초 남아 있는 동안 조준되면 안 됨) |
| 발사 | 좌클릭 1발, 서버 권위 `Server_Fire` → `ABrotherBullet` 서버 스폰·복제 | — |
| 총알 | 3000cm/s, 수명 1초, 관통 없음, WorldStatic 막힘 소멸 | — |
| 피해 | Pawn 겹침 → 서버에서 `ICombatDamageable::ApplyDamage(Damage)` | `BulletDamage` 5 → **10** |
| 사운드 | 발사음, 벽 충돌음 | 적 명중 시 `SFX_Brother_Impact_Enemy`(보류 해제) |

⚠ 플레이어는 `ICombatDamageable`을 **구현하지 않는다** — 구현하면 자동 조준이 파트너(여동생)를 적으로 잡고 총알이 아군에게 들어간다(아군 사격 없음).

## 6. 피격·데미지 처리 방식

### 6.1 비교

| 방식 | 장점 | 단점 |
|---|---|---|
| A. 엔진 `UGameplayStatics::ApplyDamage` → `TakeDamage` 오버라이드 | 표준 | `BP_Brother`는 C++ 부모가 없는 BP라 `TakeDamage` 오버라이드 불가(리페어런트 위험 — 자동 조준 문서 9.1) |
| B. 커스텀 체력 컴포넌트만(직접 호출) | C++로 완결 | 엔진 데미지 파이프라인(권위/`CanBeDamaged`) 재구현 |
| **C. A의 전달 + B의 보관 (권장)** | 아래 참고 | — |

### 6.2 권장안 C — `UCXHealthComponent` (신규, `Coop/Gameplay/`)

- **전달**: 공격자는 엔진 `UGameplayStatics::ApplyDamage(Target, 30, ...)`를 부른다. `APawn::TakeDamage`가 `ShouldTakeDamage`로 **서버 권위 + `CanBeDamaged()`**를 자동 검사한다 → 사망·부활 무적 중(`UCXPlayerLifeComponent`가 이미 `SetCanBeDamaged(false)`)에는 피해가 들어오지 않는다.
- **보관**: `UCXHealthComponent`가 소유 액터의 `OnTakeAnyDamage`에 바인딩해 체력을 깎는다. → **BP 수정 없이** 동작(`SetPlayerDefaults`에서 `EnsureOn`으로 런타임 부착 — Life/Audio 컴포넌트와 같은 패턴).
- **공용**: 플레이어와 거미로봇이 같은 컴포넌트를 쓴다. 거미로봇의 `ICombatDamageable::ApplyDamage`(총알 진입점)는 `TakeDamage`로 넘겨 같은 경로를 탄다.

| 멤버 | 내용 |
|---|---|
| `MaxHealth` (EditDefaultsOnly) | 플레이어 100 / 거미로봇 50 |
| `CurrentHealth` (`ReplicatedUsing=OnRep_Health`) | HUD·피격 연출용 복제 |
| `IsDead()`, `GetHealthPercent()` | HUD·타겟 필터용 |
| `ResetToMax()` (서버) | 부활 시 |
| `OnHealthChanged(New, Delta, Instigator)`, `OnDepleted` | 델리게이트 — 플레이어는 사망 연결, 거미로봇은 파괴 |
| 서버 처리 순서 | 소유자 생존 확인(`UCXPlayerLifeComponent::IsAlive()` 있으면) → 감소·클램프 → 피격 연출 → 0이면 1회만 `OnDepleted` |

## 7. 거미로봇 행동

### 7.1 구현 방식 — 단순 C++ 상태 기계 (권장)

| 선택지 | 판단 |
|---|---|
| `ACombatEnemy` 상속 + StateTree | 비권장: 몽타주 콤보 전제·`check(LifeBarWidget)`·HP 비복제·피격 시 래그돌, StateTree 플레이어 탐색이 0번 고정. 상태 4개에 과함 |
| **`ASpiderBot : ACharacter, ICombatDamageable` + 서버 Tick 상태 기계** | 권장: 행동이 단순, C++로 전부 보임(포트폴리오), 기존 `ICombatDamageable`로 총알·자동 조준과 바로 호환 |

- 위치: `Source/Project_CX/Variant_SpiderBot/AI/SpiderBot.h/.cpp`(CLAUDE.md 폴더 규칙), BP: `BP_Enemy_SpiderBot`(레벨 기획 네이밍).
- 컨트롤러: 기본 `AAIController`(AutoPossessAI) — 판단 로직은 폰에. 이동은 NavMesh 없이 `AddMovementInput`(사이드뷰 평면 제약) — 플레이 맵에 NavMesh가 없음.
- 확장: 적 종류가 늘면 같은 상태를 StateTree C++ 태스크로 옮긴다(이번 범위 밖).

### 7.2 상태

| 상태 | 진입 | 행동 | 전이 |
|---|---|---|---|
| `Idle` | 시작 | Idle 애님, 0.25초마다 감지 | 감지 반경 안 + LOS인 **살아 있는** 플레이어 → `Chase` (`SFX_Spider_Alert`) |
| `Chase` | 대상 확정 | 대상 쪽으로 이동(스크롤 축) | 접촉 → 즉시 `Attack`(쿨타임 없음) / 대상 사망·해제 반경 이탈 → 다른 대상 재탐색, 없으면 `Idle` |
| `Attack` | 접촉 | 정지 + 대상 바라보기, `AS_SpiderBot_Attack` 루프(1.1초) + 톱날 루프음. 매 주기 0.78초(내려찍기 끝)에 `ApplyDamage(30)` — 피격·부활 무적 중이면 헛침 | 대상이 접촉 + 30cm 밖으로 벗어남 / 사망 → `Chase`(즉시 재평가) |
| `Dead` | 체력 0 | 이동 정지, 충돌 끔, 파괴 연출, 3초 후 `Destroy` | — |

- 대상 선택: 두 플레이어 중 **가장 가까운 생존자**(`UCXPlayerLifeComponent::IsPawnAlive`). 0.5초마다 재평가 — **제안**.
- 피격 반응(거미로봇): 짧은 붉은 점멸만, 넉백 없음 — **제안**(5발 리듬 유지).

#### 톱날 회전 축 수정 (2026-11-04)

- 증상(사용자): 톱날이 톱처럼 제 축으로 돌지 않고 옆으로 구른다 — "톱날 옆면(날 끝)을 정면에서 보면 넓은 면 방향으로 돈다".
- 측정: 스켈레탈 메시를 glTF로 내보내 `Mat_SawGray` 정점 294개(전부 `saw_blade` 가중치 1.0)를 PCA → 원판 두께 방향 = 메시 **+X**(특잇값 5.8 / 5.8 / 0.36), 원판 면 = 메시 Y-Z(팔 방향 Y 포함). `saw_blade` 참조 회전 pitch −90 → 본 로컬 축(메시 공간) X = 아래, Y = +Y(팔), **Z = +X = 원판 법선**.
- 원인: Attack 생성 스크립트가 톱날 키를 `Rotator(pitch=−90+θ)`로 썼다 = 부모 Y(팔 방향, 원판 면 안의 축) 회전 → 원판이 공중제비. Idle(`SpiderBot_Skeletal_Anim`)은 본 로컬 −Z로 약 184°/s 회전 — **원래 맞음, 수정 안 함**(백업 불필요).
- 수정: `Tools/Animation/fix_spider_saw_spin.py`(에디터 원격 실행) — `AS_SpiderBot_Attack`의 `saw_blade` 트랙만 다시 씀: `q(f) = q_ref · Rot(로컬 Z, −1080°·f/24)`(루프당 3바퀴, Idle과 같은 방향, 프레임당 45°). 위치·스케일 키와 다른 본 트랙은 그대로. 확인: 프레임 0 대비 상대 회전 축이 본 로컬 (0, 0, ±1).
- 사이드뷰: 거미가 ±Y(진행 방향)를 보면 원판 법선(메시 X)이 카메라 깊이 방향 → 원판이 **정면으로 보이며 시계 바늘처럼** 돈다. 그로기 포즈(Attack 17/24 프레임 고정)도 원판이 정면으로 보이는 둥근 톱날 그대로.
- PIE 확인(Map2, AI 끈 미리보기 거미 + `slomo 0.1`): 연속 캡처 6장에서 원판이 계속 둥글게 보이고 톱니만 돈다(옆으로 뒤집혀 선이 되는 프레임 없음) — `Docs/Screenshots/Combat/saw_01_attack_spin_sequence_closeup_slomo.png`, 전체 화면 `saw_02_side_view_previews.png`, 그로기 포즈 `saw_03_stun_pose_closeup.png`.
