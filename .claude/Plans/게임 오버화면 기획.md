# 게임 오버화면 + 부활 규칙 기획

- 문서 버전: v1.0 (2026-10-29)
- 원본 요청: `.claude/mds/9. 게임 화면 제작 요청.md`
- 공통 규칙: **`설정 메뉴 기획.md` 0장 "공통 UI 규칙"** (전체 화면 단일 메뉴·누구나 조작, 입력 표, 포커스, 확인창, HUD 톤, 사운드 큐)을 따른다. 이 문서에는 부활 대기 표시와 게임 오버화면 고유 내용만 적는다.
- 범위: 기획 단계. 아직 언리얼 구현 전.

---

## 1. 목적

- 한 명이 쓰러져도 협동 흐름이 끊기지 않게 **10초 뒤 부활**시킨다.
- 두 명 모두 쓰러지면 게임 오버화면을 띄우고 재시작 / 타이틀로를 고르게 한다.

## 2. 부활 규칙

| 상황 | 결과 |
|---|---|
| 한 명 사망(체력 0 또는 낙사), 다른 한 명 생존 | 사망자 **부활 대기 10초** → 부활 |
| 부활 대기 중 나머지 한 명도 사망 | **게임 오버화면** |
| 두 명이 같은 순간(0.1초 이내) 사망 | 게임 오버화면 |

- 부활 대기 중 생존자는 평소대로 플레이한다(게임은 멈추지 않음).
- ESC 메뉴를 열면 카운트다운도 멈춘다(`ESC 메뉴 기획.md`).
- 부활 시 체력 전체 회복 + **무적 2초**(캐릭터 반투명 점멸) — 부활 직후 바로 다시 죽는 것 방지.
- 여동생이 해킹 중 사망하면 해킹 세션은 **취소(실패 아님)** 처리, 단말기는 다시 시도 가능.

### 2.1 부활 위치 — 가정(확정 필요)

- **기본안: 살아 있는 파트너 근처의 안전한 지면**에서 부활. 협동 흐름이 끊기지 않고 분할 화면에서 서로 멀어지지 않는다.
  - 파트너의 "마지막으로 밟은 안전 지면"(공중·이동 발판·킬존 근처 제외)을 0.5초마다 기록해 두고, 그 위치에서 파트너 뒤쪽(진행 반대 방향) 1~2m 지점에 스폰.
  - 그 지점이 막혀 있으면 기록된 이전 안전 지점으로 후퇴.
- **대안: 마지막 세이브포인트**에서 부활. 구현이 단순하지만 파트너와 멀리 떨어질 수 있다.

## 3. 부활 대기 표시 (사망한 플레이어의 분할 칸에만)

```
┌──────────────── 사망자 칸 (1920x540) ────────────────┐
│ (채도 0 + 비네팅 + 약한 노이즈, 카메라는 파트너 추적)   │
│                                                      │
│              SIGNAL LOST                             │
│                  07                                  │
│          ━━━━━━━━━━━━━━━━━━━━░░░░░░░░░░              │
│              REBOOTING IN 7s                         │
└──────────────────────────────────────────────────────┘
```

| KR | EN |
|---|---|
| 신호 끊김 | SIGNAL LOST |
| 재접속까지 n초 | REBOOTING IN ns |
| 재접속 완료 | REBOOTED |

- `ACoopHUD`가 사망자 칸 중앙에 그린다(전체 화면 아님 — 이건 HUD 영역). 숫자는 플레이어 색, 마지막 3초는 숫자 펄스 + 짧은 틱 사운드.
- 사망자 칸 카메라: 사망 1초 동안 그 자리에 머문 뒤 **파트너를 따라간다**(부활 위치 기본안과 맞음, 사망자가 상황을 보며 기다림).
- 생존자 칸: 파트너 표시(머리 위 아이콘)가 `SIGNAL LOST` + 남은 초로 바뀐다.

## 4. 게임 오버화면

### 4.1 진입 / 종료

| 구분 | 조건 |
|---|---|
| 진입 | 2장의 게임 오버 조건 |
| 종료 | `재시작` 또는 `타이틀로` 선택 |

- 진입 연출: 마지막 사망 순간 0.5초 슬로우(타임 딜레이션 0.3) → 두 칸 동시에 화면 노이즈 → 분할선이 사라지며 전체 화면으로 전환(0.6초) → 월드 일시정지 → 메뉴 표시.
- 게임 오버 중 **ESC/Start는 일시정지 메뉴를 열지 않는다.** 연출 중(약 1.2초)에는 모든 입력 무시.

### 4.2 레이아웃 (1920x1080)

```
┌──────────────────────────────────────────────────────────────────────┐
│ (마지막 프레임 정지 화면, 채도 0 + 검정 70% 딤 + 굵은 스캔라인)            │
│                                                                      │
│                       ALL SIGNALS LOST                               │
│               ─────────────────────────────────                      │
│                 SISTER — SIGNAL LOST          (마젠타)               │
│                 마지막으로 쓰러진 동료: 여동생                         │
│                                                                      │
│                       ▌재시작                                         │
│                        타이틀로                                       │
│                                                                      │
│                 재시작 지점: 세이브포인트 B-2                          │
│                                         [A] 선택                      │
└──────────────────────────────────────────────────────────────────────┘
```

- 큰 제목 + **마지막으로 쓰러진 플레이어**를 그 플레이어 색으로 표기.
- 메뉴 아래 재시작 지점 안내(세이브포인트 이름, 없으면 맵 시작 지점).

### 4.3 문구

| 용도 | KR | EN |
|---|---|---|
| 제목 | 모든 신호 끊김 | ALL SIGNALS LOST |
| 마지막 사망 = 여동생 | 여동생 — 신호 끊김 | SISTER — SIGNAL LOST |
| 마지막 사망 = 오빠 | 오빠 — 신호 끊김 | BROTHER — SIGNAL LOST |
| 동시 사망 | 오빠·여동생 — 신호 끊김 | BROTHER & SISTER — SIGNAL LOST |
| 재시작 지점(세이브 있음) | 재시작 지점: 마지막 세이브포인트 | RESTART FROM: LAST SAVE POINT |
| 재시작 지점(세이브 없음) | 재시작 지점: 맵 시작 지점 | RESTART FROM: MAP START |

### 4.4 메뉴 항목

| KR | EN | 동작 | 조건 |
|---|---|---|---|
| 재시작 | RETRY | 마지막 세이브포인트에서 다시 시작. **세이브포인트를 하나도 지나지 않았다면 맵 시작 지점** | 항상 |
| 타이틀로 | QUIT TO TITLE | 시작화면으로 이동 | 항상 |

- 두 플레이어 **누구나** 선택 가능. 기본 포커스 `재시작`, 위/아래 순환.
- 최상위에서 `ESC`/`B`는 아무 동작 없음(실수로 빠져나가지 않게).
- `재시작`은 확인창 없음(되돌릴 진행이 이미 없음).
- `타이틀로`: 원본 요청의 확인창 대상이지만, 게임 오버 시점에는 잃을 진행이 없으므로(세이브포인트 이후 진행은 어차피 재시작 시 사라짐) **확인창 없이 바로 이동**한다. 팀이 일관성을 원하면 ESC 메뉴와 같은 확인창을 붙인다 — 가정(확정 필요).

## 5. 비주얼 / 사운드

- 0장 톤을 쓰되 경고 색(주황) 비중을 높인다: 제목 라인과 브래킷을 주황, 마지막 사망자 줄만 플레이어 색.
- 제목은 글리치 2~3회 후 고정(0.4초). 메뉴는 0.3초 뒤 페이드인.
- 사운드: 진입 시 BGM 컷 + 저음 신호 끊김 효과(효과음 버스), 메뉴 큐는 0장 그대로. 부활 대기 마지막 3초 틱, 부활 시 짧은 재부팅 효과음.

## 6. 예외 상황

| 상황 | 처리 |
|---|---|
| 두 사람이 동시에 다른 항목 선택 | 먼저 들어온 입력 처리, 이후 0.15초 잠금 |
| 부활 10초가 끝나는 프레임에 생존자 사망 | 부활 처리가 먼저 끝났으면 계속 진행(새 대기 시작), 아니면 게임 오버. 판정은 서버(호스트) 한 곳에서 순서대로 |
| 낙사 중(킬존 진입 전 추락) 파트너 사망 | 낙사는 킬존 도달 시점에 사망 확정 — 그 시점 기준으로 판정 |
| 부활 지점 계산 실패(파트너 안전 지면 기록 없음) | 마지막 세이브포인트 → 없으면 맵 시작 지점 |
| 부활 대기 중 게임패드 끊김 | 일시정지 메뉴 자동 열기(`ESC 메뉴 기획.md`), 카운트다운 정지 |
| 게임 오버화면 중 게임패드 끊김 | 메뉴는 그대로, 상단에 연결 끊김 경고만 표시(키보드/다른 패드로 선택 가능) |
| 재시작/타이틀로 페이드 중 입력 | 무시 |

## 7. 필요한 전제 시스템

| 시스템 | 이 문서와의 관계 | 상태 |
|---|---|---|
| 체력 / 사망 판정 | 사망 조건 **체력 0 또는 낙사**(킬존). 사망 이벤트가 있어야 부활·게임 오버가 동작 | 미구현 — 전투 시스템이 갖춰진 뒤 구현 |
| 부활(리스폰) 시스템 | 2장 규칙 그 자체(10초 대기, 위치, 무적) | 미구현 — 전투 시스템 이후 |
| 세이브포인트(체크포인트) 저장 | `재시작` 위치, 부활 위치 대안안 | 미구현 — 전투 시스템 이후 |
| 거미로봇 적 공격 | 체력 감소의 실제 원인 | 진행 중(전투 시스템) |

## 8. 한글 폰트 / 영문 전환

**언리얼에서 한글이 깨져 보이면 메뉴명을 모두 영어로 바꿔도 된다.** 한글을 쓰려면 한글 폰트 에셋(예: Noto Sans KR)을 프로젝트에 추가해야 한다. 영문 라벨은 3장·4.3·4.4 표에 모두 적어 두었다(`RETRY`, `QUIT TO TITLE`, `SIGNAL LOST`, `ALL SIGNALS LOST` 등). 부활 대기 표시는 Canvas HUD라 원래 영문으로만 쓴다(`HUD 기획.md`와 동일).

## 9. 구현 메모 (C++ 우선)

- **판정 주체**: `ALocalCoopGameMode`(서버 권위, listen server 전제와 동일 구조)에 `UCXRespawnComponent` 또는 함수 추가.
  - `OnPlayerDied(AController*)` → 생존자 있으면 `FTimerHandle` 10초 후 `RespawnPlayer`, 없으면 `TriggerGameOver(LastDied)`.
  - 타이머는 `SetGamePaused` 중 자동으로 멈춘다(월드 타이머).
- **사망 상태 공유**: `ACXPlayerState`에 `bIsDead`, `RespawnEndTime`(Replicated) → `ACoopHUD`가 읽어 대기 화면을 그린다(로컬 전용이면 복제는 생략 가능하지만 listen server 확장을 위해 PlayerState에 둔다).
- **부활 위치**: 각 폰에 `UCXSafeGroundTracker`(0.5초마다 `CharacterMovement->IsMovingOnGround()` + 바닥이 정적 지오메트리이고 킬존과 거리 충분할 때 위치 기록, 링버퍼 5개).
- **낙사**: 레벨 킬존 볼륨 또는 `KillZ` → `FellOutOfWorld` 오버라이드에서 `Destroy` 대신 사망 이벤트로 연결.
- **사망자 카메라**: 사망자 컨트롤러 `SetViewTargetWithBlend(파트너 폰, 0.5)`, 부활 시 자기 폰으로 복귀.
- **게임 오버 위젯**: `UCXGameOverWidget : UCXMenuWidgetBase`, `UCXMenuSubsystem`이 `AddToViewport` + `SetGamePaused(true)` + 일시정지 메뉴 차단 플래그.
- **재시작**: 세이브 있으면 `UCXSaveGame`의 맵·세이브포인트로 `OpenLevel` 후 해당 세이브포인트에 스폰, 없으면 현재 맵 `OpenLevel`(기본 PlayerStart — `SecondPlayerStartTag` 로직 그대로).
- 전체 화면 전환 연출: `UGameViewportClient::SetForceDisableSplitscreen(true)` 후 게임 오버 위젯 표시, 레벨 이동 시 원복.
