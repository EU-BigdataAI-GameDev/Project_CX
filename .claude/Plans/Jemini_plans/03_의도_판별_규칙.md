## 3. LLM 의도 판별 규칙

시스템 지시문에 넣고, 게임 상태로 판단하게 한다.

| 상황 | 규칙 |
|---|---|
| 적 해킹 vs 적 공격 | **애매하면 항상 HackEnemy**("적 좀 어떻게 해봐", "도와줘 적이야", "막아줘"). PulseAttack은 "공격/처치/죽여/없애/펄스"처럼 **확실한 공격 명령**이 있을 때만 |
| 단말기 해킹 vs 적 해킹 | "적/거미/로봇"이 들어가면 HackEnemy. "단말기/퍼즐/문/비밀번호"는 HackTerminal. "해킹해줘"만 있으면 상태로: `sister_puzzle.type == enemy` → HackEnemy / `terminal` → HackTerminal / 퍼즐 없음 → 15m 안 해킹 가능한 적이 있으면 HackEnemy, 없으면 HackTerminal(다음 잠긴 단말기) |
| 미끼 vs 적 해킹 | "어그로/유인/시선/관심 끌어/데려가"만 Decoy. 그 외 애매한 적 요청은 HackEnemy |
| 보호막 vs 적 해킹 | "보호막/지켜/보호/실드"는 Shield, "막아줘"는 HackEnemy(적을 막는 뜻) |
| 부활 vs 회복 | "살려/부활/일으켜/재부팅"은 QuickReboot(쓰러진 사람), "힐/체력/치료"는 HealSupport(살아 있는 사람) |
| 회복 vs 다른 기능 | "체력/힐/치료/회복/아파"만 HealSupport. "배터리 채워줘"는 Chat(충전은 세이브 복도). "탄 채워줘"는 ReloadSupport |
| 공격력 vs 공격 | "공격력/데미지/화력/세게" = DamageBoost, "공격해/처치해" = PulseAttack |
| 한 문장에 여러 요청 | 함수 1개만 호출. **먼저 말한 요청**을 실행하고, 대사로 "하나씩 할게요, 먼저 재장전부터요!"처럼 알린다 |
| 불명확·잘 안 들림 | Chat으로 되묻기("재장전이요, 회복이요?") |
| 할 수 없는 요청 | Chat으로 짧게 거절(순간이동, 배터리 조작, 길 안내·정찰 등 없는 기능) |
| 명백히 불가능한 상태 | 함수를 그대로 호출해도 된다(서버가 사유별 거절). LLM이 미리 판단하지 않아도 됨 |

서버 보정(LLM이 틀려도 안전): HackEnemy가 와도 서버는 **절대 더 비싼 PulseAttack으로 바꾸지 않는다**. 해킹 불가(전부 그로기)면 `ENEMY_NOT_HACKABLE` 거절 + "이미 기절해 있어요! 확실히 처치하려면 공격하라고 말해 주세요" 안내.
