## 2. 기능별 상세

### 2-1. 재장전 `ReloadSupport` (기존 유지)

| 항목 | 내용 |
|---|---|
| 발동 | 재장전·탄·총알·장전 관련. "재장전 부탁해", "탄 다 떨어졌어", "총알 채워줘" |
| 발동 안 함 | "공격력 올려줘"(→ DamageBoost), "총 쏘는 법 알려줘"(→ Chat) |
| 서버 거절 | `ALREADY_RELOADING`(장전 중), `AMMO_FULL`(30/30), `LOW_BATTERY`(< 5) |
| 효과 | ① 응답 수신 → 대사 표시 + `Action = FlyToReload` ② 드론이 오빠에게 비행(최대 `MaxFlyTime` 2초) ③ 도착 → `UBrotherCombatComponent::RequestJeminiReload()`(원격 오빠는 Client RPC) → 장전 2초 |
| 표정 | ok = 기쁨(4초) / 배터리 부족 = 슬픔 / 그 외 거절 = 기본 |
| HUD | 드론 상태 `RELOAD SUPPORT`, 오빠 칸 장전 게이지(기존) |
| 거절 대사 | AMMO_FULL "탄창은 이미 가득 찼어요! 마음껏 쏘세요." (기존) |

변경 없음. 대사 예시만 요청 문구("재장전 해드릴게요!")를 기본 ok 대사에 추가.

### 2-2. 단말기 해킹 `HackTerminal`

| 항목 | 내용 |
|---|---|
| 발동 | 퍼즐·단말기·문 열기 해킹 대행. "퍼즐 좀 풀어줘", "해킹 좀 대신해줘", "비밀번호 모르겠어" |
| 발동 안 함 | "적 해킹해줘"(→ HackEnemy), 여동생이 **적 화살표 퍼즐 중**일 때 "퍼즐 풀어줘"(→ HackEnemy, 3절) |
| 대상 | **A. 여동생이 단말기를 연 상태**(`sister_puzzle.type == "terminal"`) → 그 단말기. <br>**B. 열지 않았으면** → 맵 진행 순서상 **가장 앞의 잠긴 단말기**(1번이 풀렸고 2번이 잠겼으면 2번). 진행 순서 = 진행 방향(+Y) 좌표가 작은 순 — 단말기 `TerminalName` 번호가 있으면 번호 순 |
| 서버 거절 | `NO_TERMINAL`(맵에 잠긴 단말기가 하나도 없음 — 기존 `NO_PUZZLE` 대체), `LOW_BATTERY`(< 20) |
| 효과 | **A**: ① 대사 + `Action = HackAssist`(드론 여동생 곁) ② `USisterHackComponent::BeginJeminiAssist(AssistTimeTerminal = 3초)` — 원격 여동생은 `Client_BeginJeminiAssist` ③ 3초 후 `CompleteJeminiAssist()` → `FinishSuccess()`(메모리 패턴은 `SendMemorySession`) → HACKED <br>**B**: ① 대사 + 드론이 그 단말기로 비행 ② 도착 후 3초 해킹 연출(단말기 상태등 깜빡임, 드론 빔) ③ 서버 `AHackTerminal::MarkHacked()` → 연결된 게이트 열림 → 드론 복귀 |
| 배터리 | 3초 해킹이 **완료된 순간** 차감(5-4절). A에서 3초 안에 여동생이 직접 풀거나 취소하면 대행 종료 + 차감 없음 |
| 표정 | ok = 기쁨, 대행 중 기본 / 완료 시 기쁨 1회 더(선택) |
| HUD | 드론 상태 `HACK ASSIST`, 여동생 칸 `JEMINI ASSIST nn%` 진행 바(기존) |
| 거절 대사 | NO_TERMINAL "이 구역 단말기는 전부 열려 있어요!" |

### 2-3. 적 해킹 `HackEnemy`

| 항목 | 내용 |
|---|---|
| 발동 | "적 해킹해줘", "적 무력화시켜줘", "저 거미 멈춰", "적 좀 막아줘", "적 좀 어떻게 해봐" 등 **적에 대한 애매한 요청 전부**(3절) |
| 발동 안 함 | "적 죽여", "처치해"(→ PulseAttack), 단말기 퍼즐 중 "퍼즐 풀어줘"(→ HackTerminal) |
| 전제 조건 | 범위 안 **해킹 가능한 적**(`ICXHackTarget::IsHackTargetAvailable` — 살아 있고 그로기 아님) 1기 이상 |
| 서버 거절 | `NO_ENEMY`(범위 안 적 없음), `ENEMY_NOT_HACKABLE`(적은 있지만 전부 그로기), `LOW_BATTERY`(< 20) |
| 대상 선택 | 여동생이 화살표 퍼즐 중이면 **그 적**(`ActiveEnemy`, 즉시 성공 + 20). 아니면 살아 있는 플레이어에게 가장 가까운 해킹 가능한 적, **15m(1500cm) 이내**(5-2절) |
| 효과 (즉시) | **A. 여동생 화살표 퍼즐 중**: `BeginJeminiAssist(0초 수준)` → 여동생 머신에서 `ResolveEnemyHack(true)` → 서버 재검증 → `ApplyHackSuccess` (기존 경로 재사용, 퍼즐 UI도 성공으로 닫힘) <br>**B. 세션 없음**: 서버가 대상에 바로 `ICXHackTarget::ApplyHackSuccess(Hacker = 여동생 폰)` → `ASpiderBot::ApplyHackStun` → Stunned 3초 |
| 드론 연출 | 효과는 응답 즉시. 드론은 대상 쪽으로 대시(0.5초) 후 해킹 빔(얇은 원통 메시, 0.5초) → 따라다니기 복귀 |
| 쿨타임 | 여동생 적 해킹 쿨타임(`EnemyHackCooldown` 3초)은 **건드리지 않음**(제미니 해킹은 별개) |
| 표정 | ok = 기쁨 / ENEMY_NOT_HACKABLE = 기본 |
| HUD | 드론 상태 `ENEMY HACK`, 대상 위 기존 그로기 표시(거미 스턴 라이트·스파크) |
| 거절 대사 | NO_ENEMY "근처에 해킹할 적이 없어요." / ENEMY_NOT_HACKABLE "이미 기절해 있어요! 지금 공격하세요." |

### 2-4. 적 공격 `PulseAttack`

| 항목 | 내용 |
|---|---|
| 발동 | **확실한** 공격·처치 명령만: "적 공격해", "적 처치해줘", "죽여", "없애줘", "펄스 쏴" |
| 발동 안 함 | "적 무력화해줘", "멈춰줘", "막아줘", "적 좀 어떻게 해봐"(→ HackEnemy). 애매하면 항상 HackEnemy(3절) |
| 전제 조건 | 15m 안 살아 있는 적 1기 이상(그로기 포함) |
| 서버 거절 | `NO_ENEMY`, `LOW_BATTERY`(< 50) |
| 대상 | **1기만**(5-2절 규칙, 그로기 중인 적도 대상) |
| 효과 | ① 대사 + 표정 화남 + `Action = PulseAttack` ② 드론이 **대상 머리 위**로 비행(대상은 응답 시점에 고정, 비행 중 대상을 따라감) ③ 도착 → 펄스 이펙트(아래로 퍼지는 링 + 빛 기둥 0.3초) + 효과음 ④ 서버 `ICombatDamageable::ApplyDamage(대상 남은 체력 이상)` → 거미 Dead ⑤ 처치 확인 후 **플레이어에게 복귀**(따라다니기) |
| 예외 | 비행 중 대상이 이미 죽으면 펄스 생략·차감 없음 → 바로 복귀(5-4절) |
| 표정 | 실행 = **화남**(1.5초) → 처치 후 기쁨 / 배터리 부족 = 슬픔 |
| HUD | 드론 상태 `PULSE`, 화면 플래시 없음(분할 화면 가독성), 대상 위치에 링 |
| 거절 대사 | NO_ENEMY "공격할 적이 안 보여요." / LOW_BATTERY "펄스를 쏠 전력이 부족해요..." |

### 2-5. 오빠 공격력 강화 `DamageBoost`

| 항목 | 내용 |
|---|---|
| 발동 | "공격력 올려줘", "데미지 올려줘", "화력 지원", "총 세게 해줘" |
| 발동 안 함 | "적 공격해"(→ PulseAttack), "재장전해줘"(→ ReloadSupport) |
| 전제 조건 | 오빠 생존 |
| 서버 거절 | `BROTHER_DOWN`(오빠 사망·부활 대기), `LOW_BATTERY`(< 10) |
| 효과 | ① 대사 표시 ② 드론이 오빠에게 비행(재장전과 같은 방식, 최대 1초) ③ `UBrotherCombatComponent::ApplyDamageBoost(30초, x2)` — 서버에 남은 시간 저장, 복제 ④ `SpawnBullet`의 `Bullet->SetDamage(BulletDamage * 2)` |
| 배율 | **x2**(10 → 20, 거미 50HP를 5발 → 3발) |
| 강화 중 재요청 | **남은 시간 +30초 연장**, 배터리 10 차감(거절 없음). 대사 "30초 더 늘려 드릴게요!" |

| 오빠 사망 | **즉시 해제**(부활해도 없음) |
| 표정 | ok = 기쁨 |
| HUD | 오빠 레일건 패널에 `DMG x2  28s` 카운트다운 + 탄 눈금 색 강조, 총알 색 변경(선택) |

### 2-6. 체력 회복 `HealSupport`

| 항목 | 내용 |
|---|---|
| 발동 | "힐 좀 해줘", "체력 채워줘", "힐 부탁해", "치료해줘", "아파" |

| 효과 | ① 대사 표시 ② 드론이 두 플레이어 중간 위로 이동 ③ 서버 `UCXHealthComponent::Heal(50)` 를 **살아 있는** 폰에만 — 최대 체력(100)으로 클램프 ④ `CurrentHealth` 복제 → HUD 갱신 ⑤ 회복된 플레이어마다 **초록 반짝이 이펙트**(몸 주위로 올라가는 초록 빛 입자 1초, 멀티캐스트로 두 칸 모두) |
| 부활 | 없음. 사망·부활 대기 중인 플레이어는 대상에서 빠진다 |
| 한 명만 다친 경우 | 실행(비용 30 그대로). 대사로 "오빠 먼저 치료할게요" 등 |
| 표정 | ok = 기쁨 |
| HUD | 두 칸 체력 바 회복 + `+50` 초록 숫자 1초 |
| 거절 대사 | HP_FULL "두 분 다 체력이 가득해요! 아껴 둘게요." |


### 2-7. 미끼(어그로) `Decoy`

| 항목 | 내용 |
|---|---|
| 발동 | "어그로 끌어줘", "적 좀 유인해줘", "시선 좀 돌려줘", "관심 좀 끌어줘", "적 좀 데려가" |
| 발동 안 함 | "적 좀 어떻게 해봐", "막아줘"(→ HackEnemy), "적 처치해"(→ PulseAttack) |
| 전제 조건 | 15m 안 **움직이는**(살아 있고 그로기 아님) 적 1기 이상 |
| 서버 거절 | `NO_ENEMY`(15m 안 움직이는 적 없음 — 전부 그로기여도 같은 사유), `LOW_BATTERY`(< 15) |
| 대상 | 15m 안 움직이는 거미 **전부**(미끼는 여러 마리를 한 번에 끄는 게 핵심) |
| 효과 | ① 대사 + `Action = Decoy` ② 드론이 플레이어와 적 사이, 플레이어 반대쪽으로 비행(거미 손이 닿지 않는 높이 약 2.5m) ③ 드론 라이트 빠른 점멸 + 경고음 루프 5초 ④ 서버: 각 거미 `ASpiderBot::ApplyDecoy(드론, 5초)` — 그동안 추적 목표가 플레이어 대신 **드론 아래 바닥 위치**, 톱 공격(접촉 판정)은 하지 않음 ⑤ 5초 뒤 거미는 원래 감지 규칙(`FindDetectTarget`)으로 복귀, 드론은 플레이어에게 복귀 |
| 배터리 | 미끼 시작 순간(비행 도착) 차감 |
| 작업 중 | 5초 동안 드론 작업 중 → 다른 요청 `BUSY` |
| 쓰임새 | 오빠가 어그로를 끄는 대신 제미니가 끌어 주는 동안 여동생이 문 해킹 / 오빠가 재장전 기다림 |
| 표정 | ok = 기쁨(장난스러운 대사) |
| HUD | 드론 상태 `DECOY 5s` 카운트다운, 거미 머리 위 표시를 드론 쪽 화살표로(선택) |
| 거절 대사 | NO_ENEMY "근처에 유인할 적이 없어요." / 전부 그로기 "다들 멈춰 있어요! 지금 지나가세요." |

### 2-8. 빠른 재부팅 `QuickReboot`

| 항목 | 내용 |
|---|---|

| 효과 | ① 대사 + `Action = Reboot` ② 드론이 살아 있는 파트너 곁(부활 위치)으로 비행 ③ 1초 재부팅 연출(드론 빔 + 감정 색 링) ④ 서버: 게임모드 부활 타이머(`RespawnTimers`)를 즉시 실행 → 기존 `RespawnPlayer` 경로(파트너 근처, 체력 100, 부활 직후 무적 2초 그대로) |
| 배터리 | 부활이 실제 실행된 순간 차감. 연출 중 남은 대기 시간이 끝나 자연 부활하면 차감 없음 |
| 말하는 사람 | **쓰러진 사람도 말할 수 있다**(2026-11-07 결정). 쓰러진 사람이 직접 "살려줘"라고 해도 된다 |
| 표정 | ok = 기쁨 / 쓰러진 동안 기본 표정 화남(기존) |
| HUD | 쓰러진 칸 `SIGNAL LOST` 오버레이에 `JEMINI REBOOTING...` 문구 |
| 거절 대사 | NO_DOWNED_PLAYER "두 분 다 멀쩡해요!" |

### 2-9. 보호막 `Shield`

| 항목 | 내용 |
|---|---|
| 발동 | "보호막 쳐줘", "지켜줘", "여동생 지켜줘", "오빠 보호해줘", "실드" |
| 발동 안 함 | "막아줘"(→ HackEnemy, 적을 막는 뜻), "힐 해줘"(→ HealSupport) |
| 대상 | 문장에 사람이 있으면 그 사람(함수 인자 `who`: brother / sister), **없으면 말한 사람**(상태 `speaker`) |
| 전제 조건 | 대상이 살아 있음 |
| 서버 거절 | `TARGET_DOWN`(대상이 쓰러짐 — "빨리 살려줘"라고 하면 재부팅할 수 있다고 안내), `LOW_BATTERY`(< 25) |
| 효과 | ① 대사 + 드론이 대상에게 비행(≤1초) ② 서버 `UCXHealthComponent::GrantInvulnerability(5초)` — 기존 피격 무적(`HitInvulnerableTime`)과 같은 판정 ③ 대상 주위 반투명 구체(감정 색, 가산 머티리얼) 5초, 끝나기 1초 전 깜빡임 |
| 이미 보호막 중 | **5초로 다시 채움**(+25 차감) — 연장 아님(공격력 강화와 달리 짧은 순간용) |
