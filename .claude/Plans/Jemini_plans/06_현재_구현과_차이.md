## 6. 현재 구현과 달라지는 점

| 항목 | 현재(as-built) | 변경 후 |
|---|---|---|
| 함수 | `ReloadSupport`, `HackAssist`, `Chat` (3개) | 10개. `HackAssist` → `HackTerminal` + `HackEnemy`로 분리 |
| 단말기 대행 시간 | `AssistTimeTerminal` 6초 | **3초** |
| 단말기 대행 비용 | 20 | 20(동일) |
| 적 해킹 비용 | `COST_HACK_ENEMY` 10 | **20** |
| 단말기 해킹 조건 | 여동생이 단말기를 연 상태만 | + 안 열었으면 진행 순서상 다음 잠긴 단말기(드론이 날아가 해킹) |
| 적 해킹 조건 | 여동생이 **화살표 퍼즐 중**일 때만(`sister_puzzle.type == enemy`) | 퍼즐 없어도 15m 안 해킹 가능한 적이 있으면 가능. 퍼즐 중이면 그 대상 |
| 적 해킹 시간 | 3초 대행 후 성공(`AssistTimeEnemy`) | **즉시** 그로기. `AssistTimeEnemy`는 미사용(또는 0) |
| 적 처치·공격력·회복 | 없음 | 신규 `PulseAttack` / `DamageBoost` / `HealSupport` |
| 미끼·재부팅·보호막 | 없음 | 신규 `Decoy` / `QuickReboot` / `Shield`, 거미 미끼 추적·즉시 부활·무적 부여 함수 |
| 쓰러진 사람 입력 | 제미니 입력 막힘(죽으면 채팅창 닫힘·녹음 취소) | **허용**(게임 오버 중만 차단) |
| 거절 사유 | `ALREADY_RELOADING`, `AMMO_FULL`, `NO_PUZZLE`, `LOW_BATTERY` | `NO_PUZZLE` → `NO_TERMINAL`, 신규 `NO_ENEMY`, `ENEMY_NOT_HACKABLE`, `BROTHER_DOWN`, `HP_FULL` (+ UE `TARGET_LOST`) |
| 배터리 20% 이하 | 기본 표정 슬픔만 | + HUD `LOW BATTERY` 문구, 대사에 배터리 부족 언급 |
| 상태 JSON | 오빠 탄·HP, 여동생 퍼즐, 배터리 | + 체력 최대·생존(두 사람), 적 수·거리, 버프 남은 시간 |
| 요청 차단 | 요청 대기 중 + 재장전 비행 중 | 요청 대기 중 + 드론 행동 중(`Action != Idle`) |
| 배터리 반영 시점 | 응답 ok 즉시 `SetBattery` | 효과가 실제로 실행된 순간 |
| 체력 회복 수단 | 부활 시 `ResetToMax`만 | `UCXHealthComponent::Heal` 추가 |
| 명세서·테스트 | 명세 6절·10절, pytest 26개 | 명세서 갱신, HackAssist 테스트를 신규 함수 테스트로 교체 |
