### 9-2. pytest (모의 모드)

- 기능별 ok + 정확한 차감: 5 / 20 / 20 / 50 / 10 / 30.
- 거절: `NO_TERMINAL`(잠긴 단말기 0), `NO_ENEMY`, `ENEMY_NOT_HACKABLE`, `BROTHER_DOWN`, `HP_FULL`, 각 기능 `LOW_BATTERY`(비용-1), 거절 시 차감 없음·사유 대사.
- DamageBoost 강화 중 → ok(연장). HackTerminal 퍼즐 없음 + 잠긴 단말기 있음 → ok.
- `battery_after <= 20`이면 대사에 배터리 부족 꼬리말.
- HackEnemy: 퍼즐 없음 + 해킹 가능 적 → ok / 여동생 화살표 중 → ok(20).
- 판별: "공격력 올려줘" → DamageBoost, "적 공격해" → PulseAttack, "적 어떻게 해봐" → HackEnemy, 퍼즐 상태 terminal에서 "퍼즐 풀어줘" → HackTerminal / enemy에서 → HackEnemy.
- 신규 3종: Decoy ok(-15)·움직이는 적 0 → NO_ENEMY / QuickReboot ok(-30)·쓰러진 사람 없음 → NO_DOWNED_PLAYER / Shield `who` 지정·미지정(말한 사람) ok(-25)·대상 쓰러짐 → TARGET_DOWN.
- 판별: "어그로 끌어줘" → Decoy, "막아줘" → HackEnemy, "지켜줘" → Shield, "살려줘" → QuickReboot, "힐 해줘" → HealSupport.
- 허용 안 된 함수명(`HackAssist` 포함) → 실행 안 됨.
- 기존 테스트(음성 mock_text, fallback, 401, 로그) 유지.
- 실제 Gemini 스모크(`tools/smoke.py`): 기능별 문장 3개 + 발동 안 해야 할 문장 + 여러 요청 문장.

### 9-3. PIE 확인 (모의 모드 서버, `CXJemini <문장>` 콘솔)

| 기능 | 확인 |
|---|---|
| 재장전 | 탄 0 → 비행 후 30발, 95 / 탄 가득 → AMMO_FULL |
| 단말기 해킹 | 단말기 접속 → 대행 **3초** 후 HACKED, -20 / 접속 없이 → 드론이 다음 잠긴 단말기로 가서 3초 후 HACKED·게이트 열림 / 전부 열림 → NO_TERMINAL / 3초 안 직접 풀면 대행 종료·차감 없음 |
| 적 해킹 | 퍼즐 없이 거미 근처 → 즉시 Stunned 3초, -20 / 여동생 화살표 중 → 퍼즐 성공 UI + 그로기 / 전부 그로기 → ENEMY_NOT_HACKABLE / 적 없음 → NO_ENEMY |
| 적 공격 | 드론이 거미 머리 위로 → 펄스 → 1기 Dead, -50 → 플레이어에게 복귀 / 그로기 거미도 처치 / 비행 중 대상 사망 → 펄스 생략·차감 없음 |
| 공격력 강화 | 거미 3발 처치, HUD 카운트다운 30→0, 종료 후 5발 / 강화 중 재요청 → 남은 시간 +30 / 맵 이동 후 남은 시간 유지 / 오빠 사망 → 즉시 해제 |
| 체력 회복 | 70/40 → 100/90 + 두 사람 초록 반짝이 / 한 명 사망 중 → 생존자만 / 둘 다 100 → HP_FULL |
| 미끼 | 거미 2기가 5초간 드론 아래로 이동·공격 안 함 → 5초 뒤 플레이어 추적 복귀, -15 |
| 빠른 재부팅 | `CXKillPlayer sister` → "여동생 빨리 살려줘" → 1초 연출 후 부활(10초 안 기다림), -30 / 쓰러진 사람이 직접 채팅·음성으로 요청 → 동작 / 게임 오버 중 입력 차단 |
| 보호막 | "여동생 지켜줘" → 여동생 5초 무적(`CXDamagePlayer sister 30` 무시), 구체 표시, -25 / 말한 사람 기본 대상 |
| 공통 | 표정(기쁨·화남·슬픔), 말풍선 대사 = 효과 시작 시점, 드론 작업 중 입력 → `JEMINI BUSY`, `CXJeminiBattery 4` 후 각 기능 LOW_BATTERY, 배터리 20 이하 → HUD `LOW BATTERY` + 대사 언급 |
