## 2. 맵 출구 `ACXLevelExit`

| 항목 | 규칙 |
|---|---|
| 판정 | 서버에서 0.1초마다. **살아 있는 플레이어 전원이 상자 안**이면 이동. 한 명이라도 사망/부활 대기면 막힘 |
| 대기 안내 | 상자 안에 있는데 조건 미충족 → 안에 있는 사람 칸에만 `WAITING FOR PARTNER`(파트너 사망 중이면 `PARTNER REBOOTING`) |
| 다음 맵 없음 | `NextMap` 패키지가 없으면 이동하지 않고 두 칸에 `NEXT AREA OFFLINE` 3초 + 출구 네온 빨강. 모두 상자를 나갔다가 다시 들어오면 재시도 |
| 이동 연출 | 입력 차단 + 일시정지 메뉴 차단 → 두 칸 검정 카메라 페이드 0.5초 + `StopMusic(0.5)` → 독립 실행 `OpenLevel`, 리슨 서버 `ServerTravel` |
| 이동 중 | 사망 보고 무시(페이드 중 게임 오버 방지) |
| 다음 맵 | 2P는 로컬 플레이어가 유지되어 다음 맵에서 컨트롤러가 다시 생긴다(게임모드 BeginPlay는 없을 때만 생성). 각 맵의 PlayerStart(태그 `Sister`)에서 시작 |
| 비주얼 | 엔진 큐브 + `M_NeonEmissive`: 바닥 구역 네온 테두리, 뒤쪽 네온 프레임(선택 `bShowFrame`), 진행 방향 화살표 3개(순차 점멸), `EXIT` 라벨. 대기 = 주황, 오프라인 = 빨강 |
| 설정 | `NextMap`(소프트 경로, `FSoftObjectPath` — 월드 에셋), `ZoneExtent`, `ArrowDirection`(±1, 로컬 Y), `bShowFrame`, `Label` |

## 3. 세이브포인트 `ACXSavePoint`

| 항목 | 규칙 |
|---|---|
| 저장 조건 | **살아 있는 플레이어 아무나** 구역에 들어오면 저장(서버). 방문 1회 — 모두 나갔다가 다시 들어오면 다시 저장 |
| 저장 내용(`CX_Slot0`) | MapName(롱 패키지, PIE 접두사 제거), SavePointId, ZoneName, SaveTime, **SpawnLocation/Yaw**(액터를 못 찾을 때 대비, 신규), SaveVersion(신규). **체력은 저장 안 함**(이어하기/부활 = 100) |
| 두 캐릭터 | 하나의 세이브포인트 = 두 사람의 재시작 지점(레벨 디자인 3.7의 "한쪽만 저장 금지"를 만족 — 위치를 사람별로 따로 두지 않는다) |
| 피드백 | 두 칸 `PROGRESS SAVED` 배너 2.5초 + `SW_Hack_Granted` 1회 + 표시등 주황(대기) → 초록(저장됨) + 포인트 라이트 색 변경 |
| 스폰 | 세이브포인트 앞 바닥, 오빠 −Y 90cm / 여동생 +Y 90cm(겹치지 않게), 바닥 트레이스로 높이 보정 |
| 스폰 직후 | 그 세이브포인트는 "저장됨" 상태로 시작하고 재저장하지 않음(배너 없음). 나갔다 들어오면 저장 |
| 설정 | `SavePointId`(비면 액터 이름), `ZoneName`(비면 HUD 구역명), `SpawnSpacing` |

## 4. 이어하기 / 재시작 / 새 게임 / 클리어

| 경로 | 동작 |
|---|---|
| CONTINUE | 세이브의 맵을 열고 `PendingContinueSave` 전달 → 게임모드 `InitGame`이 맵이 같으면 소비 → `RestartPlayer`에서 두 사람 모두 세이브포인트(없으면 저장 위치)에 스폰 |
| 게임 오버 RETRY | 세이브가 있고 **세이브 맵 = 현재 맵**이면 같은 방식으로 세이브포인트에서, 아니면 현재 맵 시작 지점. 안내 문구 `RESTART FROM: LAST SAVE POINT` / `MAP START` |
| 부활 위치 fallback | 파트너 근처 실패 시: 이 맵의 마지막 세이브포인트 → 맵 시작 지점 |
| NEW GAME | 세이브 삭제 후 `/Game/Project_CX/Maps/Map1_SoulCity1`(리디렉터 `Map1_SoulCity` 대신 실제 맵) |
| 맵 이동(출구) | `PendingContinueSave` 비움 → 다음 맵 시작 지점 |
| 클리어 | 기존대로 `DeleteSlot`(변경 없음) |

## 8. 구현 결과 (as-built, 2026-11-04)

전부 C++(WBP·새 에셋 없음). 비주얼은 엔진 큐브 + 기존 `M_NeonEmissive` + `BasicShapeMaterial`, 효과음은 기존 `SW_Hack_Granted` 재사용.

### 구현한 것

| 항목 | 내용 |
|---|---|
| `ACXLevelExit`(신규, `Coop/Gameplay/`) | 2장 그대로. 판정은 겹침 이벤트가 아니라 **로컬 상자 위치 계산**(`CXShapeKit::IsInFloorBox`) — 숨김/충돌 꺼진 사망 폰도 같은 규칙. `NextMap`은 `TSoftObjectPtr<UWorld>`(에셋 피커), 없는 맵은 `SetNextMapPackage("/Game/...")`(BlueprintCallable — Python 배치용)로 경로만 저장. 복제: `bTravelling`, `OfflineSerial`(RepNotify → 각 머신이 알림 시각 기록). 화살표 3개 순차 점멸, 상태색 청백(대기) / 주황(누군가 안) / 빨강+`OFFLINE` 라벨(알림 3초) / 흰색(이동 중). |
| `ACXSavePoint`(신규) | 3장 그대로. 단말기(받침·기둥·화면·비컨·안테나) + 기둥 상태 띠 + 바닥 패드 + 포인트 라이트(칸델라 10, 저장 직후 플래시) + `SAVE POINT` / `STANDBY`·`SAVED` 라벨. 복제: `bSaved`, `SaveSerial`. 저장 직후 0.8초 밝기 플래시. `SaveNow()`가 슬롯 기록 → `ALocalCoopGameMode::NotifyProgressSaved`. |

| `UCXSaveGame` | `SaveVersion`(1), `SpawnLocation`, `SpawnYaw` 추가. `LoadSlotForMap`, `GetWorldMapPackageName`(PIE 접두사 제거), `GetSlotDebugState`/`DebugDeleteSlot`(Python). |

| `ACoopHUD` | `DrawFlowNotices`(배너 3종) + `DrawTravelFade`(카메라 페이드 알파만큼 HUD 위에도 검정). 구역명 `Map_SaveCorridor` = `SERVICE CORRIDOR`, `Map3_Final` = `THE PIT` 추가. |
| `UCXGameOverWidget` | RETRY: `LoadSlotForMap(현재 맵)` 결과를 `PendingContinueSave`로 → 같은 맵 재로드. 안내 문구 `RESTART FROM: LAST SAVE POINT` / `MAP START`. |

### 기획과 다른 점 / 발견한 것

- **PIE 소프트 경로**: PIE에서 맵을 `OpenLevel`로 다시 읽으면 `NextMap`이 `UEDPIE_0_Map2_SoulCity2`로 고쳐져 `DoesPackageExist`가 실패(가짜 OFFLINE) → `GetNextMapPackage`에서 `UWorld::RemovePIEPrefix`. 패키징 빌드에는 영향 없음.
- **RETRY 범위**: 사용자 지시대로 "세이브의 맵 = 현재 맵"일 때만 세이브포인트. 예) 복도에서 저장 후 Map3_Final에서 게임 오버 → Map3_Final 시작 지점.
- **체력**: 저장 안 함(이어하기/RETRY = 새 폰 100).
- **진행 플래그**(`ProgressFlags`)는 이전 세이브 값을 이어받기만 하고 아직 쓰는 곳 없음.

### 보류 / 미검증

- 이동 검정 페이드·`DrawTravelFade` 순간은 화면 캡처 못 함(로그·상태로만 확인). 원격 클라이언트 `ServerTravel` 경로, 세이브포인트/출구 복제는 네트워크 PIE 미검증.
- 부활 위치 fallback(파트너 근처 실패 → 마지막 세이브포인트)은 정상 흐름에서 재현하지 못해 미검증.
- 타이틀 CONTINUE/NEW GAME은 `SimulateMenuInput`(P2 Start 시뮬레이션)으로만 검증.
- `Map_SaveCorridor` → `Map3_Final` 실제 이동은 두 맵이 생긴 뒤 확인.
