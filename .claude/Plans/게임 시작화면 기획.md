# 게임 시작화면(타이틀) 기획

- 문서 버전: v1.0 (2026-10-29)
- 원본 요청: `.claude/mds/9. 게임 화면 제작 요청.md`
- 공통 규칙: **`설정 메뉴 기획.md` 0장 "공통 UI 규칙"** (전체 화면 단일 메뉴·누구나 조작, 입력 표, 포커스, 확인창, HUD 톤, 사운드 큐)을 따른다. 이 문서에는 시작화면 고유 내용만 적는다.
- 범위: 기획 단계. 아직 언리얼 구현 전.

---

## 1. 목적

게임을 실행하면 처음 나오는 화면. 게임 분위기를 보여주고, **2P 장치 연결을 확인**한 뒤 이어하기 / 새 게임 / 설정 / 게임 종료를 고르게 한다.

## 2. 진입 / 종료

| 구분 | 조건 |
|---|---|
| 진입 | 게임 실행 직후, ESC 메뉴·게임 오버화면의 `타이틀로` |
| 종료 → 게임 | `이어하기` 또는 `새 게임`(두 플레이어 장치 확인 완료 후) |
| 종료 → 앱 종료 | `게임 종료` 확인 |

- 시작화면은 **분할 화면 없이** 전체 화면 하나. 이 화면에서는 ESC가 일시정지 메뉴를 열지 않는다(최상위에서 `ESC`/`B`는 아무 동작 없음 — 실수로 종료 확인창이 뜨는 것 방지).

- 게임명은 좌측 상단 1/3 지점, 큰 글씨 `Project_CX`(임시) + 청록 얇은 밑줄, 부제 `DISTRICT 5`.

- 하단 중앙에 플레이어 슬롯 2개(오빠 청록 / 여동생 마젠타 테두리).

## 4. 배경

| 안 | 내용 | 비용 |
|---|---|---|
| A (기본) | 시작화면 배경 이미지 1장(Map1 하이레졸 스크린샷) + 느린 켄 번스 줌(30초 1.0→1.06) + 먼지/비 파티클 오버레이 | 낮음 |
| B (여력 시) | 가벼운 타이틀 전용 맵에 Map1 풍경 일부를 배치, `ACineCameraActor`가 30~40초 루프로 천천히 가로 이동 | 중간 |

- 어느 쪽이든 위에 하단 그라디언트(검정 0→70%)와 스캔라인을 깔아 메뉴 가독성 확보.
- BGM: 타이틀 앰비언트(배경음 버스).

## 5. 2P 장치 확인 (`P2 PRESS START`)

설정의 `조작 장치` 값에 따라 각 슬롯이 무엇을 기다리는지 정해진다(`설정 메뉴 기획.md` 4.4).

| 슬롯 장치 | 초기 상태 |
|---|---|
| 키보드/마우스 | 처음부터 `READY` (키보드는 항상 있음) |
| 게임패드 | `PRESS START` 깜박임 → 해당 게임패드의 `Start` 입력 시 `READY` |

흐름:

1. 실행 직후 메뉴는 바로 조작 가능(`설정`/`게임 종료`는 언제든).
2. 게임패드 슬롯이 `READY`가 아니면 `이어하기`/`새 게임` 선택 시 시작 대신 안내: 슬롯 테두리 펄스 + "2P 장치를 연결하고 START를 누르세요" / `CONNECT P2 DEVICE AND PRESS START`.
3. `READY` 슬롯은 `P2 SISTER ■ READY` + 짧은 `UI_Confirm`.
4. `READY`인 게임패드가 끊기면 다시 `PRESS START`로 돌아간다.
5. 둘 다 게임패드면 두 슬롯 모두 `PRESS START`. **먼저 Start를 누른 패드가 P1**, 다음이 P2.

| 상태 KR | EN |
|---|---|
| 준비 완료 | READY |
| START를 누르세요 | PRESS START |
| P2 START를 누르세요 | P2 PRESS START |
| 연결 안 됨 | NOT CONNECTED |

## 6. 메뉴 항목

| KR | EN | 동작 | 조건 |
|---|---|---|---|
| 이어하기 | CONTINUE | 마지막 세이브포인트에서 시작 | **세이브가 있을 때만 표시** |
| 새 게임 | NEW GAME | 처음(Map1_SoulCity 시작 지점)부터 시작. 세이브가 있으면 덮어쓰기 확인창 | 항상 |
| 설정 | SETTINGS | 설정 메뉴 — **`설정 메뉴 기획.md` 참조**. 시작화면에서는 `조작 장치` **변경 가능**(ESC 메뉴에서는 보기만) | 항상 |
| 게임 종료 | QUIT GAME | 확인창 → 앱 종료 | 항상 |

- 기본 포커스: 세이브가 있으면 `이어하기`, 없으면 `새 게임`. 위/아래 순환.
- `이어하기`/`새 게임`은 5장의 장치 확인이 끝나야 실행된다.
- 게임 시작 시 검정 페이드(0.5초) → 맵 로드 → 인게임 구역 배너(`HUD 기획.md`).

## 7. 비주얼 / 애니메이션 / 사운드

- 진입 연출(첫 실행만): 검정 → 배경 페이드인(1.0초) → 게임명 글자가 네온 점등처럼 0.6초에 걸쳐 켜짐(2~3회 짧은 깜박임) → 메뉴 슬라이드인(0.2초, 항목별 0.04초 간격). 아무 입력이나 누르면 연출 즉시 완료.
- `타이틀로`로 돌아온 경우는 연출을 0.3초 페이드로 축약.
- 메뉴 포커스/확인창/색 규칙은 0장 그대로. `PRESS START`는 1.2초 주기 페이드 깜박임.
- 사운드: 게임명 점등 시 네온 지직음 1회, 이후 0장 큐.

## 8. 예외 상황

| 상황 | 처리 |
|---|---|
| 두 사람이 동시에 다른 항목 선택 | 먼저 들어온 입력 처리, 이후 0.15초 잠금 |
| 세이브 파일 손상 | `이어하기` 숨김 + 하단 경고 "저장 데이터를 읽을 수 없습니다" / `SAVE DATA COULD NOT BE LOADED`. `새 게임` 덮어쓰기 확인창은 그대로 띄움 |
| 게임패드 0개 + 설정이 여동생 게임패드 | `P2 PRESS START` 유지, 시작 불가 안내(5장). 설정에서 장치 조합을 바꿀 수 있음 |
| 설정에서 조작 장치 변경 후 복귀 | 슬롯 상태를 새 설정 기준으로 다시 계산(게임패드로 바뀐 슬롯은 `PRESS START`로) |
| 게임 시작 페이드 중 입력 | 전부 무시 |
| 마우스로 클릭 | 키보드 사용자 입력으로 처리(P1이 키보드일 때 P1 색) |

## 9. 필요한 전제 시스템

| 시스템 | 이 문서와의 관계 | 상태 |
|---|---|---|
| 세이브포인트(체크포인트) 저장 | `이어하기` 표시 여부·시작 위치, `새 게임` 덮어쓰기 | 미구현 — 전투 시스템이 갖춰진 뒤 구현 |
| 체력 / 사망 판정(체력 0 또는 낙사) | 직접 의존 없음 | 미구현 — 전투 시스템 이후 |
| 부활(리스폰) 시스템 | 직접 의존 없음(`게임 오버화면 기획.md`) | 미구현 — 전투 시스템 이후 |
| 시작화면 맵 / 게임모드 | 실행 시 첫 맵 | 미구현(현재 `GameDefaultMap`은 템플릿 `Lvl_ThirdPerson`) |

세이브 시스템이 생기기 전에는 `이어하기`가 항상 숨겨지고 `새 게임`은 확인창 없이 시작된다.

## 10. 한글 폰트 / 영문 전환

**언리얼에서 한글이 깨져 보이면 메뉴명을 모두 영어로 바꿔도 된다.** 한글을 쓰려면 한글 폰트 에셋(예: Noto Sans KR)을 프로젝트에 추가해야 한다. 영문 라벨은 5·6·8장 표에 모두 적어 두었다(`CONTINUE`, `NEW GAME`, `SETTINGS`, `QUIT GAME`, `PRESS START`, `READY` 등). 게임명 `Project_CX`는 원래 영문.

## 11. 구현 메모 (C++ 우선)

- 맵: `Content/Project_CX/Maps/Map_Title`(신규) + `ACXTitleGameMode`(폰 없음, HUD 없음, 로컬 플레이어 1명). 구현 시 `DefaultEngine.ini`의 `GameDefaultMap`을 이 맵으로 변경.
- 위젯: `UCXTitleMenuWidget : UCXMenuWidgetBase`, 슬롯은 `UCXPlayerSlotWidget`. 생성/구동은 `UCXMenuSubsystem`(GameInstanceSubsystem).
- 장치 확인: 타이틀에서는 2P 로컬 플레이어를 아직 만들지 않으므로, `IInputProcessor`를 `FSlateApplication::RegisterInputPreProcessor`로 등록해 **모든 게임패드의 Start**를 감지하고 장치 ID를 슬롯에 기록한다. 결과(어떤 장치가 P1/P2인지)는 `UCXGameInstance`에 넘겨 인게임에서 `ALocalCoopGameMode`가 `CreatePlayer`/장치 매핑 시 사용(`설정 메뉴 기획.md` 8장 조작 장치 메모).
- 세이브: `UCXSaveGame : USaveGame`(맵 이름, 세이브포인트 ID, 저장 시각, 진행 플래그), 슬롯 `CX_Slot0`. `UGameplayStatics::DoesSaveGameExist`로 `이어하기` 표시, `LoadGameFromSlot`로 정보줄 표시. `새 게임`은 `DeleteGameInSlot` 후 `OpenLevel(Map1_SoulCity)`.
- 종료: `UKismetSystemLibrary::QuitGame`.
- 배경 B안 카메라: `ACXTitleCameraRig`(C++ 액터, 스플라인 따라 일정 속도 이동, `SetViewTargetWithBlend`).

## 12. 구현 결과 (as-built, 2026-11-01)

전부 C++(WBP 없음). 위젯은 `UUserWidget::NativeOnInitialized`에서 `WidgetTree->ConstructWidget`으로 트리를 직접 만든다. 라벨은 10장 규칙대로 영문.

| 항목 | 내용 |
|---|---|

| 시작/종료 | NEW GAME(세이브 있으면 확인창 → `DeleteGameInSlot`) → 0.5초 검정 페이드 → `OpenLevel(Map1_SoulCity)`. CONTINUE → 세이브의 MapName(비면 Map1_SoulCity), 읽은 세이브는 `UCXGameInstance::PendingContinueSave`. QUIT → 확인창 → `QuitGame`. SETTINGS → 자리표시 알림창 `SETTINGS — COMING SOON`(BACK/ESC/B로 닫힘). |
| 진입 연출 | 첫 진입만: 검정 → 배경 페이드인 1.0초 → 게임명 네온 점등(0.6초, 짧은 깜박임 3회) → 메뉴 슬라이드인(0.2초, 항목별 0.04초) → 슬롯/힌트 페이드. 아무 입력이나 누르면 즉시 완료. 두 번째 진입부터 0.3초 페이드. |
