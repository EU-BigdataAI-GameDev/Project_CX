## 1. 목적과 흐름

```
Map2_SoulCity2 ──출구──▶ Map_SaveCorridor(세이브포인트 1) ──출구──▶ Map3_Final(보스, 팀원 제작) ──출구 문──▶ 클리어
```

| 항목 | 내용 |
|---|---|
| 역할 | 보스 직전 **숨 고르기**: 적·위험·필수 점프 없음. 저장하고, 분위기와 짧은 이야기를 보고, 보스방 문으로 간다 |
| 플레이 시간 | 약 30~45초(걷기 450cm/s로 40m ≈ 9초 + 둘러보기) |
| 서사 | Map2 판자촌 아래 정비 통로(D5-07). 누군가 여기서 지냈던 흔적("KEEP THE LIGHT ON", 날짜 세기 표시, "J + M WERE HERE") → 마지막으로 따뜻한 곳. 끝의 방폭문 너머가 "THE PIT" |
| 구역명(HUD) | `SERVICE CORRIDOR`(`ACoopHUD::ZoneTitles`에 이미 있음), 세이브 `ZoneName`도 같은 값 |
| 배경음 | 시작화면 곡 `SW_BGM_Title`(District 5 - Signal)을 "안전 지대 테마"로 재사용 — 인트로 1회 후 21~224.5초 반복, 페이드인 2초(§7) |
| 상호작용 | 선택 상호작용은 넣지 않음(요구 아님). 세이브포인트·출구만 |

## 2. 좌표계와 설계 한계

- 진행 **+Y**, 카메라는 **-X** 쪽에서 +X를 봄(Map1/Map2와 같음). 레인 **X ∈ [-120, 150]**(Map2와 같은 폭).
- 실측(BP): 캡슐 반경 34, 반높이 오빠 88 / 여동생 80, 자동 계단 45cm, 걸을 수 있는 경사 44.8°, 최고 점프 ≈ 90cm.
- 이 맵은 **점프가 필요 없다**. 높이 변화는 30° 계단 하나(0 → -180)뿐 — 여동생·오빠 모두 걸어서 통과.
- 천장 없음(머리 위 공간 무제한). 머리 위 보는 소품(배관·형광등·천장 보)은 바닥 + 300 이상.

| 구간 | Y 범위 | 바닥 높이 | 내용 | 필수 동작 |
|---|---|---|---|---|

| C1 정비 계단 | 700 ~ 1012 | 0 → -180 | 30° 계단(런 312 / 라이즈 180), 첫 단 주황 안내선, 벽 청록 손잡이 등 | 걸어서 내려감 |
| C2 세이브 쉼터 | 1012 ~ 2500 | -180 | **세이브포인트(Y 1750)**, 불 켜진 관리실 창문 2칸, 야영 흔적(상자 탁자·전구·천·쓰레기봉투), 벽 낙서 | 없음 |
| C3 피트 출입구 | 2500 ~ 3600 | -180 | 경고 표지 `PIT ACCESS >>`, 붉은 경고등, 바닥 경고 줄무늬, **출구(Y 3350)**, 닫힌 방폭문(끝벽) | 두 명이 출구 구역에 |

## 8. 검증 계획

1. 저장된 레벨 재로드 → 생성 액터 수 = manifest
2. GameMode/KillZ, PlayerStart 2개(하나 Sister)가 바닥 위
3. COL 설정(Pawn 막음·Camera 무시·숨김), 아트·글씨 NoCollision
4. 바닥 연속성: X -80 / 0 / 110 세 줄, 20cm 간격 트레이스 — 빈틈 없음, 인접 높이차 ≤ 45
5. 양 끝·앞뒤 막힘(수평 트레이스)
6. 카메라 앞 가림 0건
7. 오빠·여동생 캡슐로 X -60 줄을 시작 → 출구까지 30cm 간격 겹침 검사
8. 세이브포인트·출구가 바닥 위, 구역이 통로를 덮음
9. PIE: Map2 출구 → 복도 도착(2명·분할 화면·HUD) → 세이브 → 출구 OFFLINE → 시작화면 CONTINUE → 세이브포인트 스폰

### 작업 중 바꾼 것 / 발견한 것

- **`camera_cull.py`를 쓰지 않음**: 처음엔 Map1처럼 컬링했더니 뒷벽 윗단 19개가 지워져 PIE 화면 위쪽에 빈 하늘이 보였다. PIE 실측으로 분할 화면 한 칸이 캐릭터 깊이에서 가로 약 18m(→ 카메라 거리 ≈ 2700)를 보여, 스크립트의 카메라 모델(1289 / 433)보다 훨씬 넓다. 대신 뒷벽을 바닥 + 660으로 제한(보이는 만큼만). **`camera_cull.py`의 카메라 모델은 현재 오빠 카메라와 맞지 않는 것으로 보인다**(Map1/Map2 재생성 시 주의 — 이번엔 그 파일·맵은 건드리지 않음).
- 양 끝 너머 빈 공간이 화면에 보여서 레인 밖 콘크리트 덩어리(`Art/EndMass_0/1`)를 추가.
- 환풍구가 `PIT ACCESS` 글씨를 가려 위치 이동(Y 2950 → 2680).

### 남은 사항

- `Map3_Final`이 생기면 실제 이동(복도 → 보스맵) 확인. 지금은 의도대로 `NEXT AREA OFFLINE`.
- 구역 진입 배너(구역명 표시) 순간은 캡처하지 못함(도착 후 상태로만 확인).
- 네트워크(리슨 서버 원격 클라이언트) PIE, 실제 패드 조작, 배경음 청취는 미확인.
