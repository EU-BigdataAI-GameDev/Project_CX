## 2. 좌표계와 설계 한계

- 진행 **+Y**, 카메라는 **-X** 쪽에서 +X를 봄(Map1/Map2와 같음). 레인 **X ∈ [-120, 150]**(Map2와 같은 폭).
- 실측(BP): 캡슐 반경 34, 반높이 오빠 88 / 여동생 80, 자동 계단 45cm, 걸을 수 있는 경사 44.8°, 최고 점프 ≈ 90cm.
- 이 맵은 **점프가 필요 없다**. 바닥은 높이 0 **평지**(v1.0의 30° 계단은 단축하면서 뺐다 — 22m 안에서 계단 3m는 화면만 가리고 쉼터 리듬에 보탬이 없었다).
- 천장 없음(머리 위 공간 무제한). 머리 위 보는 소품(배관·형광등·천장 보)은 바닥 + 300 이상.

## 3. 구간 구성 (길이 22m, Y -400 ~ 1800)

**길이 근거**: 분할 화면 한 칸은 캐릭터 깊이에서 가로 약 17~18m를 보여 준다(PIE 실측). 22m ≈ 화면 1.2칸이라
① 도착 지점(Y 0)에서 이미 세이브 단말기(Y 600)가 화면 오른쪽에 보이고, ② 단말기 앞에서 출구(Y 1550)가 보인다.
세 박자(도착 → 저장 → 출구)가 각각 7~8m(반 화면 이하)라 걷는 시간은 약 5초 — 쉼터 분위기는 남기고 지루한 이동만 뺐다.
v1.0(40m)은 화면 2칸 이상을 빈 길로 걸어야 했다.

| 구간 | Y 범위 | 내용 | 필수 동작 |
|---|---|---|---|
| C0 입구 해치 | -400 ~ 300 (7m) | 지나온 산업 셔터(시작 끝벽), 시작 지점 2개, 구역 표지 `SERVICE CORRIDOR D5-07` / `MAINTENANCE ACCESS // PIT GATE AHEAD` | 없음 |
| C1 세이브 쉼터 | 300 ~ 1000 (7m) | **세이브 단말기(Y 600)** — 뒤는 민벽(창문 없음)으로 비워 실루엣이 묻히지 않게, 양옆에 불 켜진 관리실 창문, 야영 흔적(상자 탁자·전구·천·쓰레기봉투), 낙서 `KEEP THE LIGHT ON` · 날짜 세기 · `J + M WERE HERE` | 단말기 앞에서 F/X(저장) |

- 해킹 단말기 메시(`SM_Slums_Vent_02b` 환풍구)는 이 맵에 쓰지 않는다(v1.3 — 출구 해킹 단말기 제거). 장식용 환풍구도 두지 않는다(세이브 단말기와 혼동 방지).

## 8. 검증 계획

1. 저장된 레벨 재로드 → 생성 액터 수 = manifest
2. GameMode/KillZ, PlayerStart 2개(하나 Sister)가 바닥 위
3. COL 설정(Pawn 막음·Camera 무시·숨김), 아트·글씨 NoCollision
4. 바닥 연속성: X -80 / 0 / 110 세 줄, 20cm 간격 트레이스 — 빈틈 없음, 인접 높이차 ≤ 45, 전부 높이 0(평지)
5. 양 끝·앞뒤 막힘(수평 트레이스)
6. 카메라 앞 가림 0건
7. 오빠·여동생 캡슐로 X -60 줄을 시작 → 출구까지 30cm 간격 겹침 검사
8. 세이브포인트·출구가 바닥 위, 구역이 통로를 덮음
8-1. 세이브 단말기: 대표 에셋 사용(`terminal=SM_glowstick02`), 몸체 충돌(Pawn 막음·Camera/Visibility 무시), 이어하기 스폰 캡슐 2개가 몸체·COL과 안 겹침
9. PIE: Map2 출구 → 복도 도착(2명·분할 화면·HUD) → 세이브 → 출구 OFFLINE → 시작화면 CONTINUE → 세이브포인트 스폰
