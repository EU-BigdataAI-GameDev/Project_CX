# 인게임 HUD 기획 (v1.0, 2026-10-08)

명확한 기획서 없이, 지금까지 확정된 게임 구조에서 도출한 HUD. 구현: `Source/Project_CX/Coop/UI/CoopHUD.h/.cpp` (C++ `AHUD` + Canvas).

## 전제

- 로컬 2인 협동, **위아래 화면 분할**(각 칸 1920x540 기준). HUD는 플레이어 컨트롤러마다 하나씩, **자기 칸에만** 그린다.
- 카메라: 망원(FOV 37.5) 사이드뷰, 캐릭터는 화면 중앙 부근 → HUD는 **모서리에만** 두고 중앙/진행 방향(오른쪽)을 비운다.
- 톤: 사이버펑크 지하 슬럼. 얇은 네온 라인 + 반투명 어두운 패널. 플레이어 색: **오빠 청록**(총알 색과 동일), **여동생 마젠타**.
- 엔진 기본 Canvas 폰트(Roboto)는 한글 글리프가 없어 HUD 문구는 영문으로 표기한다.

## 구성

| 요소 | 위치 | 대상 | 데이터 |
|---|---|---|---|
| 플레이어 태그 | 좌상단 | 공통 | P1/P2, 이름, 역할 |
| 레일건 패널 | 좌하단 | 오빠 | 권총 아이콘, 탄약 숫자 + 30칸 눈금(25% 이하 주황 `LOW CHARGE`), 장전 중 충전 게이지·%(`GetReloadProgress`) |
| 타겟 마커 | 월드 → 화면 투영 | 오빠 | `CurrentTarget` — 우클릭 조준 시 `LOCK`(실선 브래킷), 5m 근접 자동 조준 시 `AUTO`(점멸 브래킷), 거리 |
| 해킹 링크 패널 | 좌하단 | 여동생 | 단말기 없음 `SCANNING` → 20m 안 `SIGNAL DETECTED`+거리, 신호 막대 → 3m 안 **`TERMINAL ONLINE` / `[F] BREACH`**(패널 맥박) |
| 단말기 마커 | 단말기 위 | 여동생 | 20m 안 단말기에 마름모 + 거리, 활성 단말기는 굵은 펄스 마름모 + `[F] HACK` |
| 파트너 표시 | 파트너 머리 위 / 화면 밖이면 가장자리 화살표 | 공통 | 상대 폰 위치, 거리(m) — 분할 화면에서 서로 위치 파악 |
| 구역 배너 | 상단 중앙, 시작 4초 페이드 | 공통 | 맵 이름 → 구역명(`ZoneTitles`) |
| 분할 경계선 | 분할선 쪽 가장자리 | 공통 | 플레이어 색 얇은 라인 |

## 미구현 데이터(연결 지점만 확보)

- 체력: 오빠/여동생 모두 HP 시스템 없음 → HUD에 표시하지 않음. 생기면 플레이어 태그 아래 바로 추가.
- 회피 쿨타임(1초), 해킹 쿨타임(3초)/미니게임 진행도: 시스템 구현 시 각 패널에 추가.

## 해킹 단말기 인식 규칙

해킹 시스템 C++ 인터페이스가 아직 없어서, HUD는 다음 중 하나면 단말기로 본다(1초마다 목록 갱신).

- 액터 태그 `Hackable`
- 클래스 이름 접두사 `BP_HackTerminal`(레벨 컨벤션), `BP_HackZone`(develop의 맵2 해킹 방어전)

거리 기준은 `HackActivateRange` 300cm(여동생 기획서 상호작용 반경), `HackSignalRange` 2000cm — 모두 `ACoopHUD` 기본값이며 BP 서브클래스나 게임모드에서 바꿀 수 있다.
