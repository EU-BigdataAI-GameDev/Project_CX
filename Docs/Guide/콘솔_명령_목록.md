# 시연·테스트용 콘솔 명령 목록

게임을 진행하면서 쓸 수 있는 콘솔 명령(`CX…`)을 모았다. 시연할 때 맵을 건너뛰거나 상황을 만들 때 쓰고, 개발 중 확인에도 쓴다. 기능별 설명은 `Docs/Guide/빌드_실행.md`, 튜토리얼은 `Docs/Guide/튜토리얼_가이드.md`, 컷신은 `Docs/Guide/오프닝_컷신_가이드.md`.

## 사용법

- 콘솔 열기: 게임 중 **`~`** 키(키보드 숫자 1 왼쪽, 한글 입력 상태면 영문으로 바꾼 뒤). 입력하고 Enter. 에디터 PIE와 **Development 패키징본** 모두 된다(Shipping 빌드는 안 됨).
- 명령은 **로컬 협동(같은 PC)** 에서만 동작한다(게임 모드에서 실행).
- 문장을 받는 명령(`CXJemini` 등)은 따옴표 없이 뒤에 그대로 쓴다. 예: `CXJemini 적이 오면 미끼를 던져 줘`
- 플레이어 지정 `Who`: `0`/`brother`(오빠), `1`/`sister`(여동생), `all`(둘 다). 기본값이 명령마다 다르다.
- 결과는 화면 로그와 로그 파일(`LogTemp`, 접두 `CX…:`)에 남는다.

## 시연 시나리오별 추천 순서

### A. 제미니 데모 (Map1에서, 서버 켜져 있을 때)
1. `CXTutorialEnable 0` — 튜토리얼 카드 끄기(시연 흐름을 끊지 않게)
2. `CXJeminiBattery 100` — 배터리 가득
3. `CXSpawnSpider` — 앞에 거미 소환(기능 시연용)
4. 제미니에게 직접 말하기: Enter(채팅)/패드 Y(음성). 또는 `CXJemini 재장전 해줘`, `CXJeminiSister 적 해킹해줘`
5. 규칙 시연: `CXJemini 적이 5미터 안에 오면 미끼를 던져 줘` → `CXJeminiRuleList`로 목록 확인
6. 회복·부활 시연: `CXDamagePlayer brother 60`(오빠를 다치게) → "힐 해줘", `CXKillPlayer sister` → "여동생 살려줘"

### B. WARDEN 데모 (Map2 끝)
1. 맵2로 이동: Map1에서 `CXGotoNextMap`(출구로 이동), 또는 `open Map2_SoulCity2`
2. 증거 지급: `CXGiveEvidence all`(3개 모두) 또는 `CXGiveEvidence E1`처럼 하나씩(부분 증거 시연)
3. `CXGotoWarden` — 오빠·여동생을 WARDEN 문 앞으로 순간이동
4. 여동생(또는 근처 오빠)이 Enter/Y로 WARDEN에게 말한다(증거를 근거로 설득)
5. 서버 문제로 막힐 때 비상: `CXSolveWarden`(강제 해결)

### C. 맵 건너뛰기·진행
- `CXGotoNextMap`: 현재 맵의 출구로 이동(Map1 → Map2 → 세이브 복도 → 복도 출구는 베타 종료 안내)
- 특정 맵으로 바로: `open Map1_SoulCity1`, `open Map2_SoulCity2`, `open Map_SaveCorridor`, `open Map_Title`(엔진 기본 명령)

### D. 컷신·튜토리얼
- `CXCutscene` 오프닝 컷신만 재생(`CXCutscene 4`는 4번 컷부터). 세이브·맵을 건드리지 않고 끝나면 원래 화면으로 돌아온다
- `CXTutorialReset` 봤음 기록 초기화, `CXTutorialShow <Id|1~6>` 특정 단계 강제 표시, `CXTutorialEnable 0|1` 끄기/켜기, `CXTutorialState` 현재 상태

## 전체 명령

### 진행·세이브

| 명령 | 설명 |
|---|---|
| `CXGotoNextMap` | 현재 맵의 출구(`ACXLevelExit`)로 이동해 다음 맵으로(출구가 없는 맵에서는 실패) |
| `CXSaveHere` | 현재 위치에 세이브 지점을 만들어 즉시 저장 |
| `CXSpawnSavePoint [OffsetY]` | 세이브 지점을 소환(기본 Y +400) |
| `CXDeleteSave` | 세이브 슬롯 삭제(**CONTINUE 기록이 사라진다**) |
| `CXSpawnExitDoor [OffsetY] [OffsetX]` | 출구 문을 소환(기본 500, 150) |

### 플레이어·전투

| 명령 | 설명 |
|---|---|
| `CXKillPlayer [Who]` | 플레이어 즉사(부활·게임 오버 시험). `0` `1` `brother` `sister` `all` |
| `CXDamagePlayer [Who] [양]` | 피해(기본 0=오빠, 30). 회복·보호막 시험 |
| `CXSpawnSpider [Who] [Offset]` | 해당 플레이어 앞에 거미 소환(기본 600) |
| `CXStunSpider [Who]` | 거미를 그로기로 만듦(기본 여동생). 적 해킹 시험 |

### 해킹·퍼즐

| 명령 | 설명 |
|---|---|
| `CXSolveHack` | 진행 중인 해킹을 강제 성공(회로 연결은 정답 회로를 채운 뒤 성공). WARDEN이 15m 안이면 WARDEN도 연다 |
| `CXSpawnMemoryTerminal [OffsetY] [DepthX]` | 메모리 패턴 단말기를 소환(여동생 기준) |

### 제미니

| 명령 | 설명 |
|---|---|
| `CXJemini <문장>` | 1P(오빠)가 제미니에게 채팅한 것처럼 요청 |
| `CXJeminiSister <문장>` | 2P(여동생)가 말한 것처럼(쓰러진 상태에서도) |
| `CXJeminiBattery [0~100]` | 배터리 설정(기본 100) |
| `CXJeminiEmotion [0~3]` | 드론 표정 고정(0 기본, 1 기쁨, 2 슬픔, 3 화남), `-1`은 자동 |
| `CXJeminiCmd <이름> [대상]` | 서버 없이 기능 실행. 이름: `ReloadSupport` `HackTerminal` `HackEnemy` `PulseAttack` `DamageBoost` `HealSupport` `Decoy` `QuickReboot` `Shield` |
| `CXJeminiRuleAdd <조건,조건> <행동[:대상]> [예비배터리] [반복 0\|1]` | 서버 없이 조건부 규칙 추가(최대 2). 조건: `enemy_within=500` `sister_hacking` `hp_below=brother:30` `ammo_below=5` `player_downed=any` `battery_above=50`. 예) `CXJeminiRuleAdd sister_hacking,enemy_within=500 Decoy` |
| `CXJeminiRuleClear [id]` | 규칙 삭제(0=전부) |
| `CXJeminiRuleList` | 규칙 목록·감시 상태 |
| `CXJeminiVoiceFile "<wav 경로>" [Who]` | 마이크 없이 음성 경로 시험(16bit PCM wav) |

### WARDEN

| 명령 | 설명 |
|---|---|
| `CXGiveEvidence [all\|E1 E2 E3]` | 증거 지급(기본 all) |
| `CXGotoWarden` | 두 명을 WARDEN 문 앞으로 이동(**맵2 전용** — 다른 맵에서는 "이 맵에 WARDEN 단말기가 없습니다") |
| `CXWardenSay <문장>` | 여동생이 말한 것처럼 WARDEN에게 발화(거리 무시) |
| `CXSolveWarden` | WARDEN 강제 해결(문 열기) |
| `CXWardenState` | WARDEN 상태 출력 |

### 튜토리얼·컷신

| 명령 | 설명 |
|---|---|
| `CXTutorialReset` / `CXTutorialShow <Id\|1~6>` / `CXTutorialEnable 0\|1` / `CXTutorialState` | 튜토리얼 초기화·강제 표시·끄기·상태 |
| `CXCutscene [시작컷 1~5]` | 오프닝 컷신만 재생(맵·세이브 변경 없음) |
| 실행 인자 `-CXNoTutorial` | 그 실행에서만 튜토리얼 끔(exe 바로가기 인자) |

### 1인 강제 플레이(솔로)

숨김 모드. 게임패드가 없을 때 시연용으로 한 사람이 키보드 하나로 오빠·여동생을 모두 굴린다. 일반 2인 모드가 기본이며 설정 파일은 바뀌지 않는다. 상세: `Docs/Guide/솔로_모드_가이드.md`.

| 명령 | 설명 |
|---|---|
| `CXSolo` / `CXSolo 0` | 솔로 켜기 — 오빠 조작, 여동생은 AI(따라다니며 근처 단말기·적 자동 해킹) |
| `CXSolo 1` | 솔로 켜기 — 여동생 조작, 오빠는 AI(따라다니며 가까운 거미 자동 사격) |
| `CXSolo off` | 솔로 끄기(일반 2인 모드 복귀) |
| `CXSoloSwap` | 조작 캐릭터 전환(플레이 중 `Tab`과 같음) |
| 키 | `Tab` 전환, `V` 누른 채 마이크 말하기, `Enter` 채팅 |

### 개발·자체 확인(시연에는 쓰지 않는다)

| 명령 | 설명 |
|---|---|
| `CXJeminiSelfTest [1]` | 기능 9종 자체 확인(거미 2기 소환). `1`이면 끝나고 종료 |
| `CXJeminiAdviceSelfTest [1]` | 조언·제안 흐름 자체 확인(서버 mock 모드 권장) |
| `CXWardenSelfTest [1]` | WARDEN 드롭·획득·거절·해결 자체 확인 |
| `CXGunTune loc\|rot\|scale\|show …` | 오빠 총 위치·회전·크기를 게임 중에 조정(`rot`은 Roll Pitch Yaw 순서). 최종 값은 `BP_Brother`에 적는다 |

## 엔진 기본 명령(시연에 유용)

| 명령 | 설명 |
|---|---|
| `open <맵 이름>` | 맵 이동. 맵: `Map_Title` `Map1_SoulCity1` `Map2_SoulCity2` `Map_SaveCorridor` |
| `stat fps` | 프레임 표시(패키징본 성능 확인) |
| `slomo <배율>` | 게임 속도(0.5 = 절반). 시연 설명용 |
| `quit` | 종료 |

## 주의

- **시연 전에 한 번씩 입력해 본다.** 패키징본에서 명령이 안 먹히면 Shipping 빌드이거나 `~` 키가 한글 입력 상태일 수 있다.
- `CXDeleteSave`, 실제 NEW GAME은 세이브를 지운다. 시연 도중에는 쓰지 않는다.
- 제미니·WARDEN 명령은 배포 서버(Render)가 잠들어 있으면 첫 응답이 느리다. 시연 전에 `/health`를 열어 깨워 둔다.
- 서버 없이도 시연하려면 `CXJeminiCmd`, `CXJeminiRuleAdd`, `CXSolveWarden`을 쓴다(LLM을 거치지 않는다).
