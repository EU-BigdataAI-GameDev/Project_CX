# 빌드 & 실행

UE5 C++ 프로젝트(`Project_CX/Project_CX.uproject`, 엔진 5.6). Unreal Build Tool이나 Visual Studio로 빌드한다.

## 처음 한 번

클론 직후 `Tools/setup_git.bat`를 실행한다(`git config core.quotepath false`). git이 한글 경로를 이스케이프해서 출력하면 UBT가 예외로 죽어 빌드가 실패한다.

## 빌드

- Visual Studio: `Project_CX.sln`을 `Development Editor`로 빌드.
- UBT 직접:
  ```
  <EngineDir>\Build\BatchFiles\Build.bat Project_CXEditor Win64 Development -Project="<repo>\Project_CX\Project_CX.uproject" -WaitMutex
  ```
- 헤더(.h)를 바꿨으면 에디터를 닫고 전체 빌드. .cpp만 바꿨으면 에디터에서 Live Coding 가능.
- 빌드 타겟: `Source/Project_CXEditor.Target.cs`(에디터), `Source/Project_CX.Target.cs`(게임).
- 자동화 테스트 스위트는 없다.

## 실행

- 에디터 실행: `Project_CX.uproject`.
- 에디터 시작 맵: `Map1_SoulCity1`.
- 게임 시작 맵: `Map_Title`.

## 테스트용 콘솔 명령

- `CXKillPlayer 0|1|brother|sister|all`
- `CXSpawnExitDoor`
- `CXSpawnSpider`
- `CXSolveHack`: 해킹 강제 성공(회로 연결 단말기 세션 중이면 정답 회로를 채운 뒤 성공)
- `CXGotoNextMap`
- `CXJemini <문장>`: 1P가 제미니에게 채팅한 것처럼 요청
- `CXJeminiBattery <0~100>`: 제미니 배터리 설정
- `CXJeminiEmotion <0~3>`: 드론 표정 고정(기본/기쁨/슬픔/화남), `-1`이면 자동
- `CXJeminiSister <문장>`: 2P(여동생)가 제미니에게 채팅한 것처럼 요청(쓰러진 상태에서도 됨)
- `CXJeminiCmd <이름> [brother|sister]`: LLM 서버 없이 ok 응답처럼 기능 실행(배터리는 실행 시 실제 비용 차감). 이름 = `ReloadSupport` `HackTerminal` `HackEnemy` `PulseAttack` `DamageBoost` `HealSupport` `Decoy` `QuickReboot` `Shield`
- `CXJeminiSelfTest [1]`: 기능 9종을 차례로 실행하고 단계별 결과를 로그(`CXJeminiSelfTest:`)로 남김(거미 2기 스폰, 단계마다 배터리 100). `1`이면 끝나고 종료
- `CXDamagePlayer <0|1|brother|sister> <양>`, `CXStunSpider`: 회복·보호막·적 해킹 확인용

## 제미니 서버

- 게임(PIE·패키징)을 켜면 `Jemini/` 서버도 자동으로 켜지고 게임을 끄면 같이 꺼진다(`UCXJeminiServerSubsystem`). 직접 띄워 둔 서버가 있으면 그걸 쓴다. 수동 실행: `cd Jemini` → `.venv\Scripts\activate` → `uvicorn app.main:app --port 8000`.
- 패키징한 게임에 넣기: `Jemini\tools\build_exe.bat` → `Tools\copy_jemini_to_package.bat <패키지 폴더> --with-key`(키 포함 — 내 PC용만). 자세한 건 `Jemini/README.md`.
- 실시간 자막(패드 Y로 말하는 동안 머리 위 글자): 로컬 faster-whisper `small` 모델이 필요하다. 처음 한 번 `Jemini\.venv\Scripts\pip install -r Jemini\requirements.txt` → `Jemini\.venv\Scripts\python Jemini\tools\download_stt_model.py`(→ `Jemini/models/faster-whisper-small/`, 464MB, gitignore). 없으면 서버가 첫 실행 때 자동으로 받는다. `build_exe.bat`이 모델을 exe 옆 `models/`에 넣고 `copy_jemini_to_package.bat`이 같이 복사한다(서버 폴더 약 680MB). 끄기: `Jemini/.env` `STT_ENABLED=false`.
- 마이크 없이 자막·음성 경로 시험: 콘솔 `CXJeminiVoiceFile "<16bit PCM wav 경로>" [0|1|sister]` — 파일을 실시간 속도로 녹음기 대신 흘려 넣는다.
- 서버 주소는 `Config/DefaultGame.ini` `[/Script/Project_CX.CXJeminiDrone] ServerUrl` — 따옴표 필수.
- 서버가 없으면 게임은 그대로 돌고, 제미니만 "신호가 끊겼어요" 대사를 한다.
