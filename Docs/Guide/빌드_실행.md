# 빌드 & 실행

UE5 C++ 프로젝트(`Project_CX/Project_CX.uproject`, 엔진 5.6). Unreal Build Tool이나 Visual Studio로 빌드한다.

## 처음 한 번

클론 직후 `Tools/setup_git.bat`를 실행한다(`git config core.quotepath false`). git이 한글 경로를 이스케이프해서 출력하면 UBT가 예외로 죽어 빌드가 실패한다.

## 빌드

- Visual Studio: `Project_CX.sln`을 `Development Editor`로 빌드.
- UBT 직접:
  ```
  <EngineDir>\Build\BatchFiles\Build.bat Project_CXEditor Win64 Development -Project="<repo>\Project_CX\Project_CX.uproject" -WaitMutex
  ```
- 헤더(.h)를 바꿨으면 에디터를 닫고 전체 빌드. .cpp만 바꿨으면 에디터에서 Live Coding 가능.
- 빌드 타겟: `Source/Project_CXEditor.Target.cs`(에디터), `Source/Project_CX.Target.cs`(게임).
- 자동화 테스트 스위트는 없다.

## 실행

- 에디터 실행: `Project_CX.uproject`.
- 에디터 시작 맵: `Map1_SoulCity1`.
- 게임 시작 맵: `Map_Title`.

## 테스트용 콘솔 명령

- `CXKillPlayer 0|1|brother|sister|all`
- `CXSpawnExitDoor`
- `CXSpawnSpider`
- `CXSolveHack`: 해킹 강제 성공
- `CXGotoNextMap`

## 패키징

- Development 빌드.
- 쿠킹 맵(`MapsToCook`): `Map_Title`, `Map1_SoulCity1`, `Map2_SoulCity2`, `Map_SaveCorridor`.
- 패키징 빌드 로그는 exe 옆 `<빌드폴더>\Project_CX\Saved\Logs`에 있다.
- 첫 실행 때 셰이더 컴파일로 잠깐 "응답 없음"이 뜰 수 있다. 버그가 아니다.
