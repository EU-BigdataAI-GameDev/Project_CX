# 코드 아키텍처

C++ 모듈: `Project_CX`(`Source/Project_CX/Project_CX.Build.cs`).

## 프로젝트 전용 폴더

- `Coop/`
  - 로컬 협동 게임모드 `ALocalCoopGameMode`: 폰 배정, 클리어·사망·게임 오버 판정, 맵별 배경음, 테스트 콘솔 명령.
  - `UI/CoopHUD`: 분할 칸별 Canvas HUD.
  - `Gameplay/`: 공용 상호작용(F / 패드 X), 출구 문, 세이브포인트, 맵 출구, 생명/부활, 체력, 발소리·리스너.
  - `Interfaces/`.
- `Core/`: 게임 인스턴스, 세이브(`CX_Slot0`), 설정(`UCXGameUserSettings`), 뷰포트 클라이언트(화면 분할 전환), 오디오(`UCXAudioSubsystem`, `CXSfx`).
- `UI/CXUIFonts`: UI 폰트 도우미(Oxanium = 게임 정보, IBM Plex Mono = 시스템 출력, 에셋 `Content/Project_CX/UI/Fonts/`, 경로 `DefaultGame.ini [/Script/Project_CX.CXUIFontSettings]`). 메뉴·HUD·채팅창이 모두 여기서 폰트를 받는다.
- `UI/Menu/`: 공용 메뉴 프레임워크(`UCXMenuSubsystem`, `UCXMenuWidgetBase`)와 시작/ESC/설정/클리어/게임 오버 위젯.
- `Tutorial/`: 첫 플레이 튜토리얼(코치 마크) — `UCXTutorialSubsystem`(발동·완료·일시정지/슬로모션), `CXTutorialTypes`(단계 표·문구). 상세: `Docs/Guide/튜토리얼_가이드.md`.
- `Solo/`: 숨김 1인 강제 플레이 — `UCXSoloSubsystem`(켜기/끄기·Tab 전환·자동 전환, 월드 서브시스템), `UCXSoloFollowerComponent`(조작하지 않는 캐릭터의 AI: 따라다니기·점프·순간이동 + 여동생 자동 해킹/오빠 자동 사격). 키보드는 `UCXGameViewportClient::RemapControllerInput`이 조작 캐릭터 쪽 로컬 플레이어로 돌린다. 상세: `Docs/Guide/솔로_모드_가이드.md`.
- `Title/`: 시작화면 게임모드·컨트롤러(`Map_Title`).
- `Variant_BrotherCombat/`: 오빠 사격(`BrotherCombatComponent`, `BrotherBullet`).
- `Variant_Sister/`: 여동생 캐릭터와 `Hacking/`(단말기, 해킹 퍼즐 `CXHackPuzzles`, 회로 연결 퍼즐 `CXCircuitLinkPuzzle`, 숫자 단서).
- `Variant_SpiderBot/`: 거미로봇 적(`ASpiderBot`).
- `Jemini/`: 드론형 AI 동료 제미니 — `ACXJeminiDrone`(배터리·명령 실행, 서버 권위), `UCXJeminiInputComponent`(Enter 채팅 / 패드 Y 음성), `CXJeminiClient`(LLM 서버 HTTP), `CXJeminiVoice`(마이크 → WAV), `UCXJeminiRuleComponent`(조건부 지시 규칙 보관·감시·발동 + 기능 C 작전 제안 대답 대기, 드론에 붙음) + `CXJeminiRuleTypes.h`(규칙 USTRUCT). `Jemini/Warden/`: 기능 B WARDEN 설득 퍼즐 — `ACXWardenTerminal`(증거 상태·대화·보안 문, 서버 권위), `ACXEvidencePickup`(오빠가 줍는 증거), `UCXWardenCoachComponent`(단말기 근처에서 막힌 플레이어에게 제미니가 고정 대사로 먼저 힌트, LLM 없음), `CXWardenClient`(`/persuade` HTTP), `CXWardenTypes.h`(증거 3개). 서버는 저장소 루트 `Jemini/`(Python FastAPI).

## Epic 스톡 템플릿/샘플

참고와 베이스용:

- `Project_CX/`: 기본 템플릿
- `Variant_Combat/`: AI 적·StateTree 샘플
- `Variant_SideScrolling/`: 사이드뷰 카메라 매니저 등
- `Variant_Platforming/`: 대시 샘플

신규 게임플레이는 이 샘플 폴더에 섞지 않는다. 프로젝트 전용 폴더에 같은 내부 구조(`AI/`, `Animation/`, `Gameplay/`, `Interfaces/`, `UI/`)로 작성한다.

## 맵과 레벨

- 맵 위치: `Content/Project_CX/Maps/`.
- 맵 목록: `Map_Title`, `Map1_SoulCity1`, `Map2_SoulCity2`, `Map_SaveCorridor`. `Map3_Final`은 예정(팀원 제작).
- 레벨 빌드 스크립트: `Tools/LevelBuild/`. 원본 트랜스폼 백업: `Docs/LevelManifests/`.
- 레벨 규칙: 아트 메시는 NoCollision이고, 충돌은 보이지 않는 `COL_` 박스가 담당한다.
- 레벨 디자인 상세: `Docs/Guide/레벨디자인_가이드.md`.

## 플러그인

- 활성화: `ModelingToolsEditorMode`(에디터 전용, 레벨 툴), `StateTree`, `GameplayStateTree`(모듈 의존).
- 쓰지 않는 플러그인은 켜지 않는다(빌드 시간 증가). MetaHuman은 제거했다.
- 모듈 의존: `HTTP`, `Json`, `AudioCaptureCore`(제미니). AudioCapture 플러그인은 엔진 기본 활성이라 uproject에 따로 적지 않았다.
