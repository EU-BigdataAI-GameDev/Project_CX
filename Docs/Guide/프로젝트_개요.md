# 프로젝트 개요

사이버펑크 도시의 5구역(지하 슬럼가, 가장 위험한 구역)을 배경으로 한 포트폴리오 프로젝트(상용 출시 목적 아님).

## 플레이 형태

- 한 PC에서 **2인 로컬 협동**(화면 분할, 기본 상하).
- 1P 오빠: 전투, 기본 키보드/마우스.
- 2P 여동생: 해킹, 기본 게임패드.
- 조작 장치는 설정 메뉴에서 바꿀 수 있다.

## 구현 범위 (MVP)

- 흐름: 방 1 → 방 2 → 세이브 복도 → 마지막 방(보스맵 `Map3_Final`, 팀원 제작) → 출구 문 → 클리어.
- 적: **거미로봇 1종**.
- 구현된 것:
  - 오빠: 자동 조준 사격
  - 여동생: 해킹 퍼즐(적 = 화살표 / 단말기 = 비밀번호·주파수·메모리 패턴)
  - 전투: 체력, 데미지, 거미로봇 AI
  - 세이브포인트와 맵 이동
  - 인게임 HUD
  - 메뉴 5종(시작/ESC/설정/클리어/게임 오버)
  - 부활과 게임 오버
  - 배경음과 효과음
- 진행 상황과 남은 작업: `Docs/TODO.md`. 버그 기록: `Docs/Debug_log.md`.

## 기획 문서

`.claude/Plans/`에는 원래 구상(6개 맵, 다종 적/보스)이 남아 있을 수 있다. 이는 미래 확장안이며 현재 구현 지시로 취급하지 않는다. 실제 구현 상태는 각 기획서 끝의 "구현 결과(as-built)"다.
