CAELUM:UNCHAINED

사이버펑크 도시의 지하 슬럼에서, 오빠는 싸우고 여동생은 해킹하며, 둘이 AI 드론 '제미니'에게 말로 지시하는 2인 로컬 협동 액션

이런 게임입니다

오빠 (1P · 키보드·마우스)자동 조준 레일건으로 거미 로봇과 싸우는 전투 담당.
이동·점프·사격, 조준 고정
여동생 (2P · 게임패드)적과 단말기를 해킹하는 해킹 담당. 회로 연결·주파수·메모리 패턴 퍼즐.
적 해킹 시 거미 3초 정지
제미니 (AI 드론)말을 알아듣고 재장전·회복·미끼·해킹 보조 등을 수행. LLM(Gemini)이 의미를 해석.
채팅(Enter) · 음성(V / 패드 Y)

장르: 3D 사이드 스크롤러 협동 액션 (PC · Unreal Engine 5.6). 한 PC에서 화면을 나눠 플레이하며, 두 사람은 서로 다른 정보(회로 짝·점멸 패턴·증거 등)를 보기 때문에 말로 소통해야 풀립니다.

특장점

  1. 비대칭 2인 협동 — 역할도, 화면에 보이는 정보도 다릅니다. 혼자서는 풀 수 없고 대화가 필요합니다.
  2. 말로 맡기는 조건부 지시(규칙) — "여동생이 해킹하는 동안 적이 5m 안에 오면 미끼를 써 줘"라고 말하면 제미니가 지켜보다가 조건이 되면 알아서 실행합니다. 싸우느라 입력할 시간이 없는 순간을 위한 기능입니다.
  3. 제미니가 먼저 제안 — 탄약 부족·체력 저하·퍼즐 정체·해킹 중 적 접근을 보고 "장전해 드릴까요?"처럼 먼저 묻습니다. "응" 한 마디 또는 버튼 하나로 실행되고, "미끼", "힐", "장전" 같은 한 단어 명령은 서버를 거치지 않고 바로 실행됩니다.
  4. 증거 기반 설득 퍼즐(WARDEN) — 문을 잠근 관리 AI는 명령으로는 열리지 않습니다. 두 사람이 나눠 모은 증거를 근거로 말로 설득해야 하며, 막히면 제미니가 단계별로 힌트를 줍니다.
  5. LLM은 해석, 판정은 게임이 한다 — LLM은 체크리스트·JSON만 채우고 문 열림·배터리·실행은 서버 규칙이 결정합니다. 프롬프트 주입이나 거짓말로는 열리지 않고, 모델 과부하나 서버 장애 때는 예비 모델·키워드 판정으로 자동 전환되어 게임이 멈추지 않습니다.

왜 LLM인가

고정 명령은 키워드로 빠르게 처리하고, LLM은 부정·복합 조건, 조건부 지시, 설득 논리 판정, 인젝션 거절처럼 결정이 필요한 순간에만 씁니다. 같은 문장 66개 비교에서 키워드 방식 44개(67%), LLM 64개(97%) 정답이었고, 어느 쪽에서도 문이 잘못 열린 적은 없었습니다. 안전은 LLM이 아니라 서버 판정 구조 덕분입니다.

시연 흐름 (3~5분)

  • 타이틀 → NEW GAME → 오프닝 컷신(5컷, 한·영 자막)
  • 맵1: 이동·점프 → 거미 전투 → 해킹 단말기 → 제미니에게 말 걸기·규칙 맡기기
  • 맵2 끝: WARDEN 증거 설득(시간이 되면)
  • 세이브 복도 → 베타 종료 안내·설문 QR
