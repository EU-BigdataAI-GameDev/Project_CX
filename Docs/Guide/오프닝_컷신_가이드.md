# 오프닝 컷신 가이드

NEW GAME을 고르면 첫 맵으로 가기 직전에 약 40초짜리 오프닝 컷신(5컷)을 재생한다. 기획·문구의 근거는 `Docs/Story/오프닝_컷신_초안.md`.

## 동작 방식

- 코드: `Source/Project_CX/UI/Menu/CXCutsceneWidget.h/.cpp` (`UCXCutsceneWidget`, 그림 그리기용 `UCXCutsceneArtWidget`)
- 새 맵이 아니라 **시작화면 위에 올라가는 오버레이 메뉴 위젯**이다(`UCXMenuSubsystem::PushMenu`, ZOrder 400). 맨 위 메뉴라 키 입력을 이 위젯이 모두 받고, 아래 시작화면 메뉴로는 새지 않는다.
- 흐름: `NEW GAME` → (세이브가 있으면 덮어쓰기 확인) → 세이브 삭제 + 튜토리얼 기록 초기화(기존 그대로) → **컷신 재생** → 끝나거나 건너뛰면 기존 `BeginStartGame`(검정 페이드 + 음악 페이드아웃 + 첫 맵 열기). 삽입 위치는 `CXTitleMenuWidget.cpp`의 `TryStartGame` 안 `StartNew` 람다 끝.
- `CONTINUE`는 컷신 없이 기존 그대로.
- 타이틀 BGM은 계속 재생된다(새 오디오 없음). 첫 맵으로 넘어갈 때 기존 시작 페이드가 음악을 내린다.
- 컷 사이는 검정을 거치는 페이드(0.6초). 컷마다 정지 일러스트 + 느린 켄 번스(확대/이동) + 하단 어두운 그라디언트 + 자막. 마지막 컷은 로고(`/Game/Project_CX/Title/Title_logo`)가 떠오른 뒤 검정으로 페이드하고 게임이 시작된다.
- 이미지는 화면을 꽉 채우도록(cover, 레터박스 없음) 확대되고, 켄 번스는 항상 그림 안쪽에서만 움직인다(배율 1.0 이상). 해상도/화면비/DPI와 무관하게 로컬 크기 기준으로 그린다.

## 건너뛰기

- **Esc / Enter / Space / 게임패드 A, B, Start** 중 아무거나 한 번 누르면 컷신 전체를 건너뛴다(0.35초 검정 페이드 후 게임 시작). 두 플레이어의 어느 장치든 된다.
- 시작 후 0.5초 동안은 입력을 무시한다(NEW GAME을 누른 키가 바로 건너뛰기가 되지 않게). 마우스 클릭은 아무 동작 없이 소비만 한다.
- 화면 오른쪽 아래에 `[SPACE / A]  건너뛰기  SKIP` 안내가 뜬다.

## 안전장치

- 컷 텍스처가 **하나도** 없으면 컷신을 건너뛰고 바로 첫 맵을 연다(로그 경고 `LogCXCutscene`). 위젯/컨트롤러를 못 만들 때도 동일.
- 일부 컷만 없으면 그 컷은 검은 배경 + 자막으로 재생한다.
- 감시 타이머: 재생이 전체 길이 + 10초를 넘기면 강제 종료. 콜백(맵 열기) 후 6초가 지나도 맵이 안 바뀌면 오버레이를 스스로 내린다.

## 데이터와 문구 위치

- **모든 컷 내용은 한 곳**: `CXCutsceneWidget.cpp`의 `UCXCutsceneWidget::GetOpeningCuts()`
  - 컷마다: `TextureName`, `Duration`, 켄 번스 `ScaleStart/End`(1.0 = 화면 딱 맞춤, 1.0 이상 유지) · `PanStart/End`(-1..1, y -1 = 그림 위쪽 정렬, +1 = 아래쪽 정렬, x -1 = 왼쪽, +1 = 오른쪽), 자막 목록(`Sub(시작초, 끝초, 한글, 영어)`), 선택: `FlashTime/FlashColor`(번쩍임), `LogoTime`(로고 시작, 마지막 컷)
  - 자막 시간은 컷 시작 기준. 자막은 앞뒤 0.4초씩 페이드한다.
- **조정값**(헤더 `CXCutsceneWidget.h`의 `UPROPERTY` 기본값): `CutFadeTime`(0.6), `SubtitleFadeTime`, `KoFontSize`(40, 1080 기준 — 화면 높이에 비례), `EnScale`(0.65), `EnOpacity`(0.85), `SubtitleMaxWidthFraction`(0.7), `SubtitleBottomFraction`, `OutlineSize`, `BottomShadeAlpha`, `LogoWidthFraction`, `LogoFadeTime`, `LogoDimAlpha`, `InputGraceTime`, `SkipFadeTime`
- 글꼴: `CXMenuStyle::Font`(Oxanium + 한글 서브 폰트) — 타이틀/튜토리얼과 같은 방식. 한글 굵은 글씨, 검정 외곽선 + 그림자.
- 헤더(.h)를 바꾸면 에디터를 닫고 전체 빌드, `.cpp`(컷 데이터/문구)만 바꾸면 Live Coding으로 충분하다.

## 이미지 교체

1. 원본: `Art/Source/Cutscene/cut1.png ~ cut5.png`(16:9, 글자 없음, 1672x941).
2. 에디터 콘텐츠 브라우저에서 `Content/Project_CX/Cutscene/`에 임포트. 에셋 이름은 `cut1`~`cut5`(대문자 `Cut1`도 인식).
3. 텍스처 설정 권장: Texture Group = `UI`(또는 `UserInterface2D` 압축), Mip Gen Settings = `NoMipmaps`, Never Stream 체크, sRGB 켜짐, Compression = `UserInterface2D (RGBA)` 또는 기본.
4. 같은 이름으로 덮어쓰면 코드 수정 없이 교체된다. 컷 수/이름을 바꾸려면 `GetOpeningCuts()`를 고친다.
5. 로고는 `Title_logo`(투명 PNG)를 그대로 쓴다.

## 콘솔 명령

- `CXCutscene` — 처음부터 재생. `CXCutscene 3` — 3번 컷부터.
- 콜백 없이 재생하며, 끝나거나 건너뛰면 검정에서 페이드아웃해 **원래 화면으로 돌아온다**(맵을 열지 않고, 세이브·튜토리얼 기록도 건드리지 않는다). 시작화면이든 인게임이든 쓸 수 있다(인게임에서는 재생 중 게임이 계속 돈다 — 테스트용).
- Shipping 빌드에는 포함되지 않는다.
