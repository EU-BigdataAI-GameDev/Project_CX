# 솔로 모드(1인 강제 플레이) 가이드

게임패드가 없는 환경(시연 등)에서 한 사람이 키보드 하나로 오빠(전투)와 여동생(해킹)을 모두 플레이하기 위한 **숨김 모드**. 평소 게임은 2인 로컬 협동이 기본이며 이 모드는 콘솔 명령으로만 켠다.

## 사용법

| 입력 | 동작 |
|---|---|
| `CXSolo` 또는 `CXSolo 0` | 켜기. 오빠 조작, 여동생 AI |
| `CXSolo 1` | 켜기. 여동생 조작, 오빠 AI |
| `CXSolo off` | 끄기(일반 2인 모드) |
| `Tab` / `CXSoloSwap` | 조작 캐릭터 전환 |

- 조작 캐릭터의 키는 원래 키보드 조작 그대로: 오빠 `WASD`·`Space`·좌클릭 사격·우클릭 조준 고정·`F`, 여동생 `WASD`·`Space`·`F`(해킹 시작/확인)·방향키·`Backspace`(해킹 취소).
- 제미니·WARDEN 대화: `Enter` 채팅, `V`를 누르고 있는 동안 마이크 녹음 → 떼면 전송(게임패드의 `Y`와 같은 경로). 키 안내는 HUD에 `[ENTER] CHAT / [V] HOLD TO TALK`로 뜬다.
- HUD: 조작 칸에 `SOLO MODE — [TAB] SWITCH`, AI 칸에 `AUTO`. ESC 메뉴 조작표도 솔로 키(V·Tab)로 바뀐다.
- 화면 분할·카메라는 그대로(두 칸). 튜토리얼 카드는 솔로 중 꺼진다.

## 동작 방식

- **입력**: `GameUserSettings`는 건드리지 않는다. 키보드/마우스 이벤트만 `UCXGameViewportClient`가 조작 캐릭터를 가진 로컬 플레이어로 돌리고, 장치 종류 조회(`UCXGameInstance::GetSlotDeviceType`)는 솔로 중에만 "조작 슬롯 = 키보드, 나머지 = 게임패드(AI)"로 답한다. 그래서 "둘 다 키보드 불가" 규칙은 일반 모드에서 그대로다.
- **AI 공통**: 조작 캐릭터와 수평 약 1m 유지, 목표가 높거나 앞이 낭떠러지/막히면 점프, 15m 넘게 멀어지거나 4초 넘게 막히면 조작 캐릭터 옆으로 순간이동.
- **여동생 AI(오빠 조작 중)**: 범위 안 단말기·거미(`USisterHackComponent` 탐지 범위 그대로)에 해킹 세션을 열고, 단말기는 1.5초·적은 1초 뒤 제미니 해킹 대행과 같은 성공 경로로 마무리(퍼즐 입력 생략). WARDEN은 자동 해킹 대상이 아니다(말로 설득).
- **오빠 AI(여동생 조작 중)**: 자동 조준 사거리(30m) 안 가장 가까운 거미를 평소 사격 경로로 쏜다(연사 간격·탄약 그대로, 탄이 0이면 자동 장전).
- **사망**: 기존 부활/게임 오버 규칙 그대로. 조작 캐릭터가 쓰러지고 상대가 살아 있으면 상대로 자동 전환.

## 제한

- Tab 전환은 채팅창·마이크 녹음·일시정지 메뉴·조작 중인 여동생의 해킹 중·상대 사망 중에는 거절된다. AI 여동생이 연 자동 해킹 세션은 전환 시 취소된다.
- 맵 이동(출구)에서는 솔로가 이어지고, 시작화면·RETRY·이어하기로 맵을 다시 열면 꺼진다(다시 `CXSolo`).
- AI는 지형 탐색(길찾기)을 하지 않는다. 복잡한 지형에서는 막히면 순간이동으로 따라온다.
- 시연용 보조 모드라 두 사람 플레이와 밸런스가 다르다.
