# 오빠 조준 포즈 / 임시 권총 설정

C++ 쪽은 `UBrotherCombatComponent`(BP_Brother에 붙은 BrotherCombat)에 들어 있다. ABP_Brother 그래프 작업은 에디터에서 직접 한다.

## 조준 알파 getter
- `GetFireAimAlpha()` (컴포넌트, BlueprintPure, 0~1): 발사 중 + 마지막 발사 후 `AimHoldTime`(기본 0.8초) 동안 1로 오르고, 이후 0으로 내려간다. 보간 속도는 `AimBlendInSpeed`/`AimBlendOutSpeed`.
- `GetFireAimAlphaForPawn(Pawn)` (정적 BlueprintPure): 캐스트 없이 `TryGetPawnOwner` 결과를 넣으면 알파를 돌려준다. BP_Brother의 부모가 엔진 `Character`라 캐릭터 단위 getter는 두지 못했다.
- 알파는 발사를 처리한 머신(서버/로컬 오빠)에서만 계산된다. 원격 클라이언트의 시뮬레이션 프록시에는 반영되지 않는다(로컬 협동 전제).

## ABP_Brother 설정
1. Event Graph(Update Animation): `Try Get Pawn Owner` -> `Get Fire Aim Alpha For Pawn` -> 변수 `AimAlpha`(float)에 Set.
   (또는 Try Get Pawn Owner -> Cast to BP_Brother -> `Get Component by Class(BrotherCombatComponent)` -> `Get Fire Aim Alpha`.)
2. AnimGraph: Locomotion 스테이트 머신 뒤에 `Transform (Modify) Bone` 노드를 `RightArm`, `RightForeArm`에 각각 추가.
   - Alpha = `AimAlpha`, Rotation Mode = `Add to Existing`, Rotation Space = `Bone Space`(또는 Component Space).
   - 프리뷰에서 AimAlpha를 1로 두고 Rotation 값을 조절해 총을 앞으로 겨눈 자세를 만든다.
3. 순서: Locomotion -> RightArm 노드 -> RightForeArm 노드 -> Output Pose.

## 총 메시/소켓 교체
- BP_Brother의 BrotherCombat 컴포넌트 디테일(Brother|Gun): `GunMesh`에 실제 Static Mesh 지정(비우면 엔진 큐브 임시 권총). `GunSocketName`(기본 `RightHand`), `GunRelativeTransform`으로 위치/회전/크기 조정.
- 총은 BeginPlay에서 만들어지므로 값을 바꾸면 PIE를 다시 시작한다. 충돌/그림자 없음.
- 임시 큐브일 때는 `GunRelativeTransform`의 Scale에 임시 크기가 곱해진다. 실제 메시로 바꾸면 Scale을 1 기준으로 맞춘다.

## 연속 점프에서 점프 애니메이션이 안 나오는 문제
상태: 인게임 미검증, 원인은 가설.
- C++ 쪽 원인은 찾지 못했다. 점프는 BP_Brother의 IA_Jump -> `Jump`/`StopJumping`만 호출하고 JumpMaxCount는 기본 1이며 점프 입력을 막거나 지연시키는 C++ 코드는 없다. 즉 실제 점프는 정상 동작한다.
- ABP_Brother 확인 결과(문자열 추출): 변수 `Speed`, `IsFalling`, `bIsInAir`가 있고 Locomotion 전이가 6개이며 Greater/LessEqual(Speed), Not, AND 노드를 쓴다. Jump 애니(Brother_Anim_Jumping)는 시퀀스 플레이어이고 전이 규칙의 정확한 배선은 에셋에서 읽을 수 없었다.
- 가설: `Idle/Run -> Jump` 조건이 IsFalling이 아닌 값(bIsInAir 등)이나 Speed 조건과 섞여 있거나, `Jump -> Idle/Run`이 Automatic Rule(남은 시간)로 걸려 있어서, 착지 직후 재점프하면 Jump 상태로 재진입하지 못하고 Idle에 머문다.

에디터에서 확인/수정할 것:
- `Idle->Jump`, `Run->Jump`, `Jump->Idle`, `Jump->Run` 4개 전이 규칙을 열어 한 변수(`IsFalling`)만 쓰도록 통일한다.
  - Idle/Run -> Jump: `IsFalling` == true (Speed 조건 넣지 않기)
  - Jump -> Idle: NOT `IsFalling` AND Speed <= 임계값 / Jump -> Run: NOT `IsFalling` AND Speed > 임계값
- 각 전이의 `Automatic Rule Based on Sequence Player in State`는 끈다(Jump 애니가 끝나면 Idle로 빠지는 경로 제거).
- Event Graph(Update Animation)에서 `IsFalling`/`bIsInAir`/`Speed`를 매 프레임 `Character Movement -> Is Falling`, `Get Velocity`에서 다시 읽는지 확인(Set이 특정 분기 안에만 있으면 값이 굳는다).
- 전이 Crossfade Duration을 짧게(0.05~0.1초) 둔다.
- 그래도 재현되면 프리뷰 디버그에서 점프 중 `IsFalling` 값과 활성 상태를 같이 확인해 알려 달라.
