CAELUM:UNCHAINED  혼자 플레이하기 (솔로 모드) 테스트 안내
==========================================================

이 게임은 원래 2명이 하는 게임입니다.
(1P 오빠 = 키보드·마우스 전투 / 2P 여동생 = 게임패드 해킹)
게임패드가 없거나 혼자일 때는 "솔로 모드"로 키보드 하나로 플레이할 수 있습니다.


1. 켜는 법
----------
1) Project_CX.exe 실행
2) 타이틀 화면에서 키보드 ~ 키(숫자 1 왼쪽)를 눌러 콘솔을 연다
   * 한글 입력 상태면 영문으로 바꿔야 열립니다
3) 아래 중 하나를 입력하고 Enter
      CXSolo       오빠로 시작 (기본)
      CXSolo 1     여동생으로 시작
4) NEW GAME (또는 CONTINUE)

끄기:  ~ 를 열고  CXSolo off   (원래 2인 모드로 돌아갑니다)
* 타이틀로 돌아가거나 이어하기로 맵을 다시 열면 꺼집니다. 다시 CXSolo 입력.


2. 조작
-------
  Tab ........ 오빠 <-> 여동생 전환
  W A S D .... 이동
  Space ...... 점프
  F .......... 상호작용 / (여동생) 해킹 시작·확인
  Enter ...... 제미니에게 채팅
  V .......... 누르는 동안 말하기 (떼면 전송)  * 마이크 허용 필요

 [오빠]  마우스 좌클릭 = 사격(자동 조준) / 우클릭 = 조준 고정
 [여동생] 방향키 = 해킹 조작 / Backspace = 해킹 취소


3. 다른 한 명은 어떻게 움직이나요?
---------------------------------
내가 조종하지 않는 캐릭터는 자동으로 1m 뒤에서 따라옵니다.

  오빠를 조종할 때   -> 여동생이 근처 적(거미)과 해킹 단말기를 자동으로 해킹
  여동생을 조종할 때 -> 오빠가 근처 거미를 자동으로 사격

* 자동 해킹은 1~1.5초 걸리고, 그동안 여동생은 그 자리에 멈춥니다.
* 조종 캐릭터가 쓰러지면 살아있는 쪽으로 자동 전환됩니다.
* 솔로 모드에서는 튜토리얼 카드가 나오지 않습니다.
* 화면 위에 SOLO MODE 표시와 AUTO 표시(자동 캐릭터)가 나옵니다.


4. 꼭 직접 해야 하는 것
-----------------------
  - WARDEN(맵2 끝 AI) 설득: 자동 해킹이 안 됩니다. Enter 또는 V로 직접 말해서 설득하세요.
  - 제미니에게 말 걸기: 채팅(Enter) 또는 음성(V)


5. 테스트해 주세요 (이상하면 알려 주세요)
----------------------------------------
  [ ] CXSolo / CXSolo 1 로 오빠, 여동생이 키보드로 각각 잘 움직이나요?
  [ ] Tab 전환 때 키가 눌린 채로 끼지 않나요?
  [ ] 자동 캐릭터가 잘 따라오나요? (끼거나 멀어지면 순간이동합니다)
  [ ] 자동 해킹(단말기·거미)이 동작하나요?
  [ ] 자동 사격이 동작하나요?
  [ ] 제미니: Enter 채팅과 V 음성이 둘 다 되나요?
  [ ] 맵 이동(Map1 -> Map2) 뒤에도 솔로가 이어지나요?
  [ ] CXSolo off 후 2인 모드로 돌아오나요?


6. 알아두세요
-------------
  - 인터넷이 필요합니다. 제미니는 온라인 서버를 씁니다.
    서버가 잠들어 있으면 첫 응답이 30~60초 걸립니다. (게임을 켜고 잠시 기다려 보세요)
  - 자동 캐릭터는 길찾기를 하지 않습니다. 지형에 막히면 점프하거나 순간이동합니다.
  - 솔로 모드는 테스트용 임시 기능입니다. 기본은 2인 플레이입니다.
