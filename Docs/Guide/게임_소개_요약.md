# CAELUM:UNCHAINED 게임 소개 (한 장 요약)

전시·심사·발표·"이 게임이 뭐예요?"라는 질문에 바로 쓰는 요약이다. 자세한 구현은 `Docs/Guide/프로젝트_개요.md`, 제미니·WARDEN은 `Docs/Jemini/`, 세계관은 `Docs/Story/`.

## 한 줄 소개

사이버펑크 도시의 지하 슬럼에서, **오빠는 싸우고 여동생은 해킹하며, 둘이 AI 드론 '제미니'에게 말로 지시해** 탈출하는 2인 로컬 협동 액션.

## 30초 설명

- 장르: 3D 사이드 스크롤러 협동 액션(PC, Windows). 한 PC에서 둘이 화면을 나눠 플레이한다.
- **오빠(1P, 키보드·마우스)**: 자동 조준 레일건으로 거미 로봇과 싸운다.
- **여동생(2P, 게임패드)**: 단말기와 적을 해킹한다(회로 연결·주파수 동조·메모리 패턴 등 퍼즐).
- **제미니(AI 드론)**: 두 사람의 말을 알아듣고 재장전·회복·미끼·해킹 보조 등을 한다. LLM(Gemini)이 말을 해석한다.
- 두 사람은 서로 **다른 정보**를 본다(회로 짝, 점멸 패턴, 증거 등). 그래서 말로 소통해야 풀린다.

## 특장점 (핵심 6가지)

1. **비대칭 2인 협동** — 전투와 해킹, 역할이 완전히 다르고 화면에 보이는 정보도 다르다. 혼자서는 풀 수 없고 대화가 필요하다.
2. **말로 맡기는 조건부 지시(규칙)** — "여동생이 해킹하는 동안 적이 5m 안에 오면 미끼를 써 줘"라고 말하면 제미니가 지켜보다가 조건이 되면 알아서 실행한다. 싸우느라 입력할 시간이 없을 때를 위한 기능이다.
3. **제미니가 먼저 제안** — 탄약 부족, 체력 저하, 퍼즐 정체, 해킹 중 적 접근을 보고 "장전해 드릴까요?"처럼 먼저 묻는다. **"응" 한 마디나 버튼 하나(키보드 G/H, 패드 LB/RB)** 로 실행된다. "미끼", "힐", "장전" 같은 **한 단어 명령**은 서버를 거치지 않고 바로 실행된다. 싸우는 중에도 쓰기 쉽게 하려는 설계다.
4. **증거 기반 설득 퍼즐(WARDEN)** — 관리 AI가 문을 잠그고 있다. 두 사람이 나눠 모은 증거를 근거로 말로 설득해야 한다. 명령으로는 열리지 않는다. WARDEN은 시스템 상태만 보고하고, 막히면 **제미니가 추측하는 말투로 단계별 힌트**를 준다(거절이 쌓이면 예시 문장까지).
5. **LLM은 해석, 판정은 게임이 한다** — LLM이 문을 직접 열지 않는다. LLM은 체크리스트·JSON만 채우고, 실행과 배터리·문 열림은 게임 서버 규칙이 결정한다. 그래서 속이거나 프롬프트 주입을 해도 증거 없이는 열리지 않는다.
6. **안정적인 폴백** — 모델이 과부하·지연되면 예비 모델로, 전부 실패하면 키워드 판정으로 바뀌어 게임이 멈추지 않는다. 서버가 없어도 제미니가 "신호가 끊겼어요"라고 말하며 진행은 가능하다.

## 왜 LLM을 쓰나요? (자주 받을 질문)

- **키워드 매칭으로도 되는 부분은 키워드로 처리한다.** 고정 명령("재장전")은 빠르게 처리하고, LLM은 결정이 필요한 순간에만 호출한다.
- LLM이 필요한 곳은 **부정·복합 조건**("해킹 중이 아닐 때만"), **조건부 지시**, **설득 논리 판정**, **인젝션 거절**이다. 같은 문장 66개를 비교했을 때 키워드 방식 44개(67%), LLM 64개(97%)를 맞혔고, 격차는 부정·복합 조건과 설득·인젝션에서 컸다(`Docs/Jemini/비교실험_결과.md`).
- 어느 방식에서도 문이 잘못 열린 적은 없다. 안전은 LLM이 아니라 서버 판정 구조 덕분이다.

## 시연 흐름 (3~5분)

1. 타이틀 → NEW GAME → 오프닝 컷신(5컷, 한·영 자막)
2. **맵1**: 이동·점프 → 첫 거미(오빠 자동 조준 사격, 여동생 적 해킹 3초 정지) → 해킹 단말기
3. **제미니**: Enter(채팅) 또는 V·패드 Y(음성)로 말 걸기. 예) "미끼"(한 단어 명령), "체력이 30 아래면 회복해 줘"(규칙). 탄약이 줄면 제미니가 먼저 "장전해 드릴까요?"라고 묻는다
4. (시간이 되면) **맵2 끝 WARDEN**: 증거를 모아 말로 설득해 문 열기
5. 세이브 복도 → "베타 테스트 종료" 안내와 설문 QR

시연 중 막히면 `~` 콘솔 명령(`Docs/Guide/콘솔_명령_목록.md`)으로 건너뛸 수 있다. 예) `CXGotoNextMap`, `CXGiveEvidence all`, `CXGotoWarden`.

## 구현 현황 (베타)

- 맵 3개: 맵1·맵2·세이브 복도(보스맵은 후속)
- 적: 거미 로봇 1종, 해킹 퍼즐 4종(화살표·회로 연결·주파수·메모리), 세이브·부활·게임 오버, 메뉴 5종, 튜토리얼, 오프닝 컷신
- 제미니: 기능 9종(재장전·단말기 해킹·적 해킹·펄스·공격력 강화·회복·미끼·재부팅·보호막), 조건부 규칙(최대 2개), 조언·작전 제안, 선제 제안(탄약·체력·퍼즐 정체·적 접근), 한 단어 명령, WARDEN 코치 힌트, 실시간 음성
- 서버: FastAPI + Gemini(함수 호출·구조화 JSON), 외부 배포(Render), 자동 테스트 260여 개

## 기술 요약

- Unreal Engine 5.6, **C++ 중심**(UI도 C++), 서버 권위 구조
- LLM: Gemini(주 모델 + 예비 모델), 키워드 폴백
- 음성: 마이크 입력 → 서버 음성 인식, 실시간 자막
- 에셋: 모델링 Blender, 배경음 Suno, 효과음 Kenney(CC0)
