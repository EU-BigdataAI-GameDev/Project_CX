# 튜토리얼(코치 마크) 가이드

처음 하는 사람에게 상황에 맞춰 한 번씩만 보여 주는 안내 카드다. 맵에 액터를 놓지 않고, 이미 있는 액터·상태(거미, 단말기, 제미니 드론, WARDEN)를 코드에서 읽어 발동한다.

## 어디에 무엇이 있나

| 내용 | 위치 |
|---|---|
| **문구·시간 표(여기만 고치면 됨)** | `Source/Project_CX/Tutorial/CXTutorialTypes.cpp` — `CXTutorial::GetSteps()` |
| 조작 표기 토큰(`{move}` `{jump}` `{fire_ro}` `{interact}` `{cancel}` `{dir}` `{talk}` `{talk_do}` `{chip_hint}` `{confirm}` `{skip}`) | 같은 파일 `CXTutorial::FormatText` |
| 발동 조건 / 완료 판정 / 일시정지·슬로모션 | `Tutorial/CXTutorialSubsystem.cpp` — `ShouldTrigger`, `IsCardComplete`, 거리 등 숫자는 맨 위 `CXTutorialTuning` |
| 화면 그리기(플레이어 칸별 Canvas) | `Coop/UI/CoopHUD.cpp` — `ACoopHUD::DrawTutorial` |
| 확인·건너뛰기 키 | `UCXTutorialSubsystem::HandleKeyDown` (`UI/Menu/CXMenuInputProcessor.cpp`가 메뉴가 없을 때 먼저 부른다 — 일시정지 중에도 동작) |
| "봤음" 기록·전체 on/off | `Core/CXGameUserSettings` (`TutorialSeenSteps`, `bTutorialEnabled`) |
| ESC 메뉴 조작법 화면 | `UI/Menu/CXPauseMenuWidget.cpp` — `CONTROLS` 항목 |

## 카드 종류

- **Hint**: 게임을 막지 않는다. 칸 아래 가운데 작은 띠. 행동하거나 시간이 지나면 사라진다. 입력을 가로채지 않는다(Esc = 평소처럼 일시정지 메뉴).
- **Action**: 슬로모션(전역 타임 딜레이션 0.15) + 화면 어둡게 + 강조 상자. 그 행동을 실제로 하면 끝난다. 슬로모션은 최대 `BlockTimeout`초(실시간) 뒤 자동으로 풀린다.
- **Info**: 월드 일시정지 + 설명 카드. 확인 키를 눌러야 닫힌다. `BlockTimeout`초(실시간) 뒤 자동으로 계속된다.

키 표기는 그 캐릭터의 조작 장치 설정(슬롯 0 오빠 / 1 여동생, `UCXGameInstance::GetSlotDeviceType`)을 따른다 — HUD의 `[F]`/`[X]`와 같은 기준.

| | 키보드 | 게임패드 |
|---|---|---|
| Info 확인 | Enter 또는 Space | A |
| Info·Action 건너뛰기 | Esc | Start |
| 예시 문장 넣기(5단계) | 1 / 2 / 3 | (말로 하면 됨) |

- **두 사람 대상 Info 카드는 각자 확인해야 닫힌다.** 먼저 확인한 칸에는 "파트너를 기다리는 중"이 뜬다. 건너뛰기(Esc/Start)는 누가 눌러도 단계 전체가 닫힌다.
- 쓰러진(부활 대기) 플레이어와 패드가 연결되지 않은 게임패드 플레이어의 확인은 기다리지 않는다. 확인할 수 있는 사람이 아무도 없으면 누가 확인 키를 눌러도 닫힌다.
- 대상이 아닌 칸(예: 3단계의 오빠)에는 "파트너가 안내를 읽고 있습니다…"만 뜬다.
- 카드가 뜬 직후 0.7초는 확인 입력을 받지 않는다(점프 연타로 바로 닫히는 것 방지).

## 단계

| # | Id | 대상 | 종류 | 발동 | 끝나는 조건 |
|---|---|---|---|---|---|
| 1 | `Move` | 둘 | Hint | Map1 시작 1.5초 뒤 | 각자 1.2m 이상 움직이고 점프(공중)하면 그 칸에서 사라짐. 12초 뒤 종료 |
| 2 | `FirstSpider` | 오빠 Action / 여동생 Hint | 슬로모션 | 쫓아오는(Chase/Attack) 거미가 오빠 16m 안, 또는 아무 거미나 10m 안 | 오빠가 쏘면 슬로모션 해제(최대 6초). 여동생 안내는 적 해킹을 시작하거나 9초 뒤 사라짐 |
| 3 | `FirstTerminal` | 여동생 | Info | 여동생이 해킹 가능한 단말기 상호작용 범위(HUD `TERMINAL ONLINE`)에 처음 들어옴 | 확인(30초 뒤 자동) |
| 4 | `JeminiHello` | 둘 | Hint | 1단계를 본 뒤 4초 이상 지나고 조용할 때(25m 안에 쫓아오는 거미 없음, 해킹·WARDEN 대화 중 아님, 제미니가 쉬는 중) | 누가 제미니에게 채팅/음성을 보내면 끝(응답은 기다리지 않음). 30초 뒤 종료 |
| 5 | `JeminiRule` | 둘 | Info + 예시 칩 3개 | 4단계 뒤 제미니 대답이 오고 3초 뒤(대답이 없으면 9초 뒤), 조용할 때 | 각자 확인(40초 뒤 자동). 키보드 플레이어가 1~3을 누르면 카드가 닫힌 뒤 그 예시가 채팅창에 들어간다(Enter로 전송) |
| 6 | `Warden` | 둘 | Info | 누군가 WARDEN 대화 거리(`ACXWardenTerminal::TalkRange` 5.5m)에 처음 들어옴 | 각자 확인(40초 뒤 자동) |

- 강조 상자: 2단계 = 그 거미(월드 투영), 3단계 = 좌하단 HACK LINK 패널, 4·5단계 = 우상단 제미니 패널, 6단계 = 증거 노트(증거가 하나도 없으면 강조 없음).
- 한 번에 한 단계만 뜬다. 표의 순서가 우선순위다.
- Info 카드는 채팅 입력창이 열려 있거나 음성 녹음 중이면 끝날 때까지 미룬다.
- 게임 오버·클리어·맵 이동이 시작되면 진행 중인 단계는 조용히 닫힌다(못 본 것으로 남아 다음에 다시 뜬다).
- 5단계 예시 문장은 서버 규칙 조건(`enemy_within` / `hp_below` / `ammo_below`)과 행동(`Decoy` / `HealSupport` / `ReloadSupport`)에 맞춘 것이다. LLM이 꺼진 mock 모드(`Jemini/app/mock.py`)에서도 규칙으로 등록된다. 예시를 바꿀 때는 `Docs/Jemini/02_요구사항_명세서.md`의 조건 키워드를 확인한다.

## "봤음" 기록

- 저장 위치: `GameUserSettings.ini`(`Saved/Config/…/GameUserSettings.ini`)의 `[/Script/Project_CX.CXGameUserSettings]` → `TutorialSeenSteps`, `bTutorialEnabled`. 세이브(`CX_Slot0`)와는 별개다.
- 단계가 끝나면(확인·완료·시간 초과·건너뛰기) 바로 기록된다.
- **시작화면 NEW GAME을 하면 기록이 지워져 다시 뜬다.** 이어하기(CONTINUE)와 게임 오버 RETRY는 유지한다.
- 수동 초기화: 콘솔 `CXTutorialReset`, 또는 ini에서 `TutorialSeenSteps` 줄을 지운다.

## 콘솔 명령(인게임 맵, `ALocalCoopGameMode`)

| 명령 | 동작 |
|---|---|
| `CXTutorialReset` | "봤음" 기록 모두 지우기 |
| `CXTutorialShow <Id 또는 1~6>` | 조건과 상관없이 그 단계를 바로 띄움. 예) `CXTutorialShow Warden`, `CXTutorialShow 5` |
| `CXTutorialEnable 0` / `1` | 튜토리얼 전체 끄기 / 켜기(ini에 저장) |
| `CXTutorialState` | 상태 한 줄 로그(켜짐, 진행 중 단계, 일시정지·슬로모션 소유, 봤음 기록) |

- 실행 인자 `-CXNoTutorial`: 그 실행에서는 띄우지 않는다(자동화용 — 기록·설정은 건드리지 않음).
- `CXJeminiSelfTest` / `CXJeminiAdviceSelfTest` / `CXWardenSelfTest`는 시작할 때 그 맵의 튜토리얼을 끈다(자체 확인이 일시정지에 걸리지 않게).
- 로그 카테고리: `LogCXTutorial`(시작·확인·종료).

## 단계를 추가하려면

1. `CXTutorialTypes.h`의 `ECXTutorialStep`에 값 추가(`Count` 앞).
2. `CXTutorialTypes.cpp`의 표에 같은 순서로 한 줄 추가(문구·종류·시간).
3. `CXTutorialSubsystem.cpp`의 `ShouldTrigger`에 발동 조건, Hint/Action이면 `IsCardComplete`에 완료 조건 추가.
4. 새 HUD 요소를 강조하려면 `ECXTutorialSpot`에 값을 추가하고 그 패널을 그리는 곳에서 `SetTutorialSpot`을 부른다.

## 제약

- 로컬 협동 전용. 네트워크 클라이언트(`NM_Client`)에서는 아무것도 하지 않는다.
- 일시정지·슬로모션은 튜토리얼이 건 것만 되돌린다. 슬로모션은 풀 때 딜레이션이 0.15 그대로일 때만 원래 값으로 복원한다(게임 오버 슬로모션과 겹쳐도 덮어쓰지 않음).
