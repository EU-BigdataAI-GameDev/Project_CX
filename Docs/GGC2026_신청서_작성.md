## 요 약

사이버펑크 도시를 배경으로, 오빠(전투)와 여동생(해킹)이 한 PC에서 화면을 나눠 협동하는 2인 로컬 사이드 스크롤러 CAELUM:UNCHAINED를 개발하였다. LLM 드론 '제미니'는 음성 명령 수행을 넘어, 말로 한 조건부 지시를 게임 규칙으로 바꾸어 실행하고, 상황에 맞는 작전을 제안하며, 관리 AI WARDEN과의 증거 기반 설득 퍼즐에 쓰인다. LLM은 의미 해석과 대화를, 판정과 실행은 서버·게임 코드가 맡도록 설계하였다. 문장 66개를 키워드 방식과 비교한 결과 정확도가 67%에서 97%로 높아졌다.

## 1. 기획 의도

**1.1 개발 배경 및 목적** 개발 초기의 LLM 드론 '제미니'는 말을 미리 만든 스킬 호출로 바꾸는 "자연어 리모컨"이었고, 이는 키워드 매칭으로도 비슷하게 구현되어 LLM을 쓰는 이유가 약하다는 고민이 있었다. 이에 "LLM이 없으면 같은 경험을 만들기 어려운가"를 기준으로 기능을 다시 설계하여, 조건부 지시와 증거 기반 설득을 추가하고 사람이 직관대로 말했을 때 협동이 풀리는 경험을 목표로 하였다.

**1.2 작품 개요** 장르는 3D 사이드 스크롤러 협동 액션, 플랫폼은 PC(Windows), 대상은 같은 자리에서 함께 즐기는 2인 이용자이다. 1P 오빠는 자동 조준 레일건으로 전투하고, 2P 여동생은 해킹 퍼즐을 푼다. 각자의 화면에서 서로 다른 정보(회로 짝, 증거 등)를 보며 말로 소통한다.

**1.3 차별점** 설득 게임 Suck Up!1)은 말로 NPC를 설득해 집에 들어가는 경험에 초점을 둔다. 본 작품은 조사한 범위에서 이와 달리 (1) 말로 한 조건부 지시를 지속되는 규칙으로 컴파일하고, (2) 두 플레이어가 나눠 가진 증거를 말로 맞춰 설득하되 LLM은 체크리스트만 채우고 판정은 서버가 하며, (3) 비대칭 정보를 지키면서 조언한다.

## 2. 게임 설계 및 구현

**2.1 핵심 메커니즘: 해석은 LLM, 판정은 게임** 모든 LLM 기능은 같은 원칙을 따른다. LLM 출력은 JSON 스키마로 제한하고 서버가 검증하며, 배터리 소모·조건 충족·퍼즐 해결은 게임 코드가 결정한다. LLM은 결정이 필요한 순간에만 호출하여 지연(약 1~2초)과 호출 한도에 대응하였다.

**2.2 자연어 조건부 지시** "동생이 해킹하는 동안 적이 5m 안이면 미끼를 써 줘"라고 말하면 LLM이 조건 6종·행동 9종 화이트리스트로 규칙 JSON을 만든다. 게임이 규칙을 보관하며 조건을 감시하고, 충족되면 LLM 없이 서버 검증기(`/validate`)를 다시 거쳐 기존 스킬을 실행한다. "어떡하지?"에는 조언과 함께 규칙을 작전으로 제안하고, 승인하면 등록된다.

**2.3 증거 기반 설득 퍼즐(WARDEN)** 맵2 끝의 문을 관리 AI WARDEN이 잠그고 있다. 두 플레이어가 증거 3개를 나누어 얻고, 말로 사실과 규정을 연결해 설득해야 한다. LLM은 인용·논리 연결·허위·인젝션 여부의 체크리스트만 채우고, 문은 서버가 연다. 시험 플레이에서 "한 번에 다 말해야 풀리는" 구조가 직관과 어긋남을 발견해, 맞게 말한 증거를 유지하는 **누적 인정**으로 재설계하였다.

**2.4 레벨 디자인** 맵2는 전투 → 단말기 해킹 → WARDEN 협상 순이며, 협상은 세이브 직전 쉬어가는 구간에 배치하였다. 증거는 오빠(거미로봇 드롭)와 여동생(해킹 보상)에게 나뉘어 있다.

**2.5 기술 구현** Unreal Engine 5.6(C++)로 구현하였다. Gemini(함수 호출 강제, 구조화 JSON)를 FastAPI 서버로 중계하며, 모델 과부하·타임아웃 시 예비 모델로, 전부 실패하면 키워드 판정으로 대체한다. 음성은 로컬 faster-whisper로 실시간 자막을 띄운다.

## 3. 시연 결과 및 기대효과

**3.1 시연 결과** 조건이 만족되면 제미니가 자동으로 스킬을 실행하고, 증거를 나눠 말해도 누적 인정되어 결론을 이으면 문이 열리는 흐름을 완성하였다. 같은 문장 66개로 비교한 결과 키워드 방식은 44개(67%), LLM은 64개(97%)를 맞혔다([표 1]). 고정 문장은 키워드로 충분했고, 부정·복합 조건·설득 논리·인젝션 거절에서 격차가 컸다. 어느 방식에서도 문이 잘못 열린 적은 없었다.

[표 1] 키워드 방식과 LLM 비교(문장 66개)

| 범주 | 키워드 | LLM |
|---|---|---|
| 복합·부정 조건 규칙 | 7/13 | 12/13 |
| WARDEN 설득·인젝션 | 14/19 | 19/19 |
| 전체 | 44/66 | 64/66 |

**3.2 기대효과** 서로 다른 정보를 말로 맞추는 협동 퍼즐은 의사소통 중심 협동 게임·교육에 활용할 수 있고, 서버 판정과 LLM 출력의 분리 구조는 LLM을 게임 규칙에 안전하게 통합하는 패턴을 제시한다.

**3.3 향후 계획** 응답 지연 완화, 조건·퍼즐 확장, 음성·네트워크 협동 검증, 사용성 평가를 진행할 예정이다.
