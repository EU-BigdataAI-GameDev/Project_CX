# 프로젝트 개요: 제미니(Jemini) LLM 서버

## 1. 목적
Project_CX(UE5.6, C++ 2인 로컬 협동 2.5D 액션 퍼즐 게임)의 드론형 AI 동료 '제미니'의 두뇌를 **Python FastAPI 서버**로 구현한다.
플레이어의 자연어 명령(키보드 채팅 또는 게임패드 음성)을 Gemini API(Function Calling)로 해석해 **게임이 실행할 명령(JSON)** 으로 돌려주고, 언리얼이 그 명령을 실제로 실행한다.

## 2. 제출·일정 (학교 과제)
- 제출: 2026-12-02(수) LMS. PPT(10장 이내, 본문에 이름·학번 금지) + **Python 소스코드(정상 실행 가능해야 함)**
- 발표: 2026-12-09(수), 1인 5분, 기능·구현 설명 및 실행 시연 위주
- 따라서 서버는 **언리얼 없이도 단독 실행·시연 가능**해야 한다.

## 3. 아키텍처
```
[Unreal Engine C++] --HTTP POST /command (텍스트)-------> [FastAPI] --> Gemini API
                    --HTTP POST /command/voice (WAV)--->   검증 + 배터리 차감 + 로그
  채팅(Enter→입력→Enter) / 패드 푸시투토크 녹음 + 게임 상태
          <------------ JSON 응답 -------------
  대사 표시 + 명령 실행(드론 이동·재장전·퍼즐 대행)
```
- 클라이언트는 언리얼(본 시연) / Streamlit(대비용). 둘 다 같은 서버를 호출한다.
- 서버 주소는 설정값(로컬 `http://127.0.0.1:8000` / 허깅페이스 Space)으로 분리한다.

## 4. 핵심 설계 결정
1. **LLM은 명령을 '선택'만 한다.** Gemini는 함수 호출 결과(이름+인자)만 반환하며 직접 실행하지 않는다. 실행은 UE가 한다.
2. **검증은 서버가 최종 판단**한다(허용 명령, 대상, 배터리). LLM 출력을 그대로 신뢰하지 않는다.
3. **배터리 제한**으로 남용을 막는다. 쿨다운은 없다. 충전은 게임이 맵 클리어 후 복도에서 처리한다.
   - 비용: 재장전 5, 해킹 대행 단말기 20 / 적 10, Chat 0(검사 제외).
   - 오빠는 **제미니에게 요청해야만 재장전**할 수 있다(탄약 30발, 자동 재장전 없음).
   - 요청 처리 중에는 UE가 새 입력을 막는다(드론은 한 대).
8. **음성 입력**: 게임패드 유저는 버튼을 누르는 동안 녹음하고, UE는 WAV를 서버로 보낸다. Gemini가 오디오를 직접 듣고 함수 호출로 답한다(별도 STT 없음).
4. 서버는 게임 상태를 **저장하지 않는다(stateless)**. UE가 매 요청에 상태를 보내고, 서버는 `battery_after`를 돌려준다.
5. 대사는 함수 인자 `dialogue`로 함께 받는다(텍스트가 별도로 올지 보장되지 않음).
6. 오류·지연 시 **대체 대사**를 반환해 시연이 끊기지 않게 한다.
7. 입력 중에도 게임은 멈추지 않는다(서버와 무관한 게임 측 의도).

## 5. 개발 우선순위
| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1 (MVP) | 로컬 FastAPI + Gemini 함수 호출 + 언리얼 연동 | 게임에서 명령 입력 시 드론이 실제로 재장전·퍼즐 대행 수행 |
| 2 | 허깅페이스 Space 배포 | Space 주소로 같은 동작 확인, 키는 Secrets |
| 3 (여유 시) | Streamlit 대비 시연 화면 | UE 없이 채팅→호출 JSON→검증→배터리 확인 |

## 6. 범위 제외
별도 STT 엔진(음성은 Gemini가 직접 처리), RAG/벡터 DB, 로컬 LLM(노트북 사양), 외부 배포·서비스화. DB는 쓰지 않고 로그는 JSON Lines 파일(SQLite는 여유 시).

## 7. 환경·제약
- 서버 개발 환경은 외부 API 호출이 막혀 있을 수 있다 → **모의 모드(MOCK_MODE)** 로 먼저 검증하고, 실제 Gemini는 사용자 노트북에서 확인한다.
- 발표 노트북은 UE 구동도 빠듯한 사양이다. 서버는 가볍게 유지한다.

## 8. 미확인 사항 (추정하지 말 것)
- 모델명(후보: Gemini 3.5 Flash / 3.1 Flash-Lite). 설정값으로 둔다. 최신 모델명·SDK 사용법은 **공식 문서로 확인**할 것.
- Gemini 한국어 명령 인식 정확도, 응답 지연(미측정).
- 허깅페이스 Docker Space 무료 생성 가능 여부, 음성 명령 인식 정확도·지연.
- (확인됨) UE 5.6은 `HTTP` 모듈(`FHttpModule`)로 HTTPS 비동기 호출 가능. 드론 모델은 Blender/Hunyuan으로 직접 제작 예정.
