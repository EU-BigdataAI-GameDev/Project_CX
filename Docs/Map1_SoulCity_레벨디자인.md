## 1. 좌표계와 플레이어 실측

| 항목 | 값 |
|---|---|
| 진행 방향 | **+Y**(화면 오른쪽). 카메라는 -X 쪽에서 +X를 바라봄 |
| 플레이 레인(깊이) | X ∈ [-250, 250], 앞/뒤/양끝 투명 경계벽(`COL_Bound_*`) |

| 최고 점프 높이 | 420² / (2×980) ≈ **90cm** |
| 이론 수평 점프 거리 | 450 × (2×420/980) ≈ **386cm** |
| 설계 한계 | 필수 상승 점프 **≤ 55cm**(여유 35), 필수 간격 **≤ 200cm**, 계단 경사 30°(한계 44°), 머리 위 공간 ≥ 210cm |

## 3. 아트 / 조명

- **배경 3단**: 레인 뒤 판자촌 파사드(X≈300, 2~3층 적층 + 간판/네온/전선) → 중경 원경 판자촌(X≈2600, 창문 불빛) → 원경 판자촌 군집(X≈7000) + 동굴 벽/천장 바위
- **전경 없음**(2026-10-05): 카메라 쪽 전경 바닥/연석 330개 제거(플레이어가 레인 앞까지 나오지 않음). 낮은 소품(쓰레기통, 바위 등)은 레인 뒤 벽 옆 발판 위(`*/WallProps`)에 둔다
- **배경 높이 제한**(2026-10-05): 실제 게임 카메라(2인 위아래 화면 분할, 여동생/오빠 카메라 각각)에서 어떤 위치에서도 중심이 화면 위쪽 경계보다 높은 배경/네온 42개 제거. 계산은 `Tools/LevelBuild/camera_cull.py`, 빌더에도 적용됨
- **계단 메시**: `SM_stairs_W1_H3_00`은 yaw 0이면 -Y로 올라가는 모양이라, +Y로 오르는 계단은 yaw 180으로 둔다(2026-10-05 수정, 맵2 계단도 동일하게 수정)
- **구간별 색**: S1 따뜻한 가로등/주황 간판, S2 차가운 서치라이트(흰빛·붉은 경고), S3 파란 네온 링 타워, S4 초록 코어 + 붉은 경고등, S5 핑크/청록 네온, 출구 청록
- **충돌 분리**: 플레이 지형은 보이지 않는 `COL_*` 박스(BlockAll), 장식 메시는 전부 NoCollision
- **소품 충돌**(2026-10-05): 레인 안 소품/장치/기둥/난간에 메시 바운드 크기의 투명 박스 `COL_Prop_<메시라벨>` 95개 추가(`Tools/LevelBuild/add_prop_collision.py`, 재실행 안전). 매달린 장식(빨래·전선·간판·전등·천장 배관)은 제외. 빌더로 레벨을 재생성했다면 이 스크립트를 다시 실행할 것
- 신규 머티리얼: `Content/Project_CX/Environment/Materials/M_NeonEmissive` + `MI_Neon_{Cyan,Pink,Orange,Green,Red,Blue,Purple}`

## 4. 미구현 기능 (마커만 배치)

`Gameplay/` 폴더의 `MARKER_*`(TargetPoint)로 위치만 잡아둠. 기능 구현 시 이 위치를 사용.

| 마커 | 용도 |
|---|---|
| `MARKER_Checkpoint_01~05` | 체크포인트/리스폰 지점 |
| `MARKER_Enemy_SpiderBot_S1_01` | S1 하급 적 |
| `MARKER_DronePatrol_S2_01~03` | S2 순찰 드론(서치라이트 위치와 일치) |
| `MARKER_DefenseDrone_S4_01~02` | S4 방어 드론 |
| `MARKER_ChaseDrone_S5_01~02` | S5 추격 드론 |
| `MARKER_HackTerminal_01` | 코어 해킹 장치 상호작용 지점 |
| `MARKER_ExitGate_ToDistrict4` | 최종 게이트(다음 구역 이동 트리거) |
| `MARKER_ScrapLift_Optional_S3` | 스크랩 리프트(선택 경로) |

기획안의 **벽 점프**는 프로젝트에 구현되어 있지 않아 필수 동선에서 제외했고, **스크랩 리프트·시간 제한·드론 AI·해킹 미니게임**도 미구현이다.

## 5. 알려진 사항

- 로컬 2인 **스플릿스크린(위아래 분할)**에서는 화면 세로 시야가 좁아져 S3 타워 상승 구간의 윗 발판이 잘 안 보일 수 있다. 공유 카메라 도입 여부 결정 필요.
- 서치라이트/네온은 정적 조명이다(회전·깜빡임 애니메이션 없음).
- Soul City는 2014년 모바일 데모 에셋이라 일부 머티리얼이 현재 조명(Lumen)에서 약간 평면적으로 보일 수 있다.
- 에디터 캡처 기준으로 검수했으며, 실제 조작감(점프 타이밍, 카메라 가림)은 플레이 테스트로 확인해야 한다.
