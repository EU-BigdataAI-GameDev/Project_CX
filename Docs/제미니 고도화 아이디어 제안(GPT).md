# CAELUM: UNCHAINED — LLM 드론 시스템 고도화 제안

## 1. 배경

현재 프로젝트는 Unreal Engine 5.6(C++) 기반 2인 로컬 협동 사이버펑크 게임입니다.

- 오빠(P1): 레일건 전투 담당
- 여동생(P2): 해킹 및 퍼즐 담당
- 서로 다른 정보를 가지고 소통하는 비대칭 협동 게임
- 지원 드론 '제미니'에 Gemini 3.1 Flash-Lite API 적용
- FastAPI 서버에서 LLM 요청·응답 및 검증 처리
- 게임 리슨 서버에서 실제 스킬 실행
- 개발자 1명, 제출일 2026년 12월 2일

현재 제미니는 자연어 명령을 해석해 미리 정의된 10개 함수 중 하나를 실행하는 구조입니다.

**문제는 LLM이 사실상 자연어 리모컨 역할만 한다는 점입니다.** 키워드 매칭으로도 비슷한 결과를 구현할 수 있어 LLM 활용의 차별성이 부족합니다.

목표는 LLM이 자연어 해석뿐 아니라 **상황 추론, 협동 전략 수립, 지속적인 명령 관리**에 관여하도록 개선하는 것입니다.

## 2. 추천 기능

### ① 자연어 조건부 지시 시스템 — 우선 구현

플레이어가 조건과 행동을 자연어로 지시하면 LLM이 이를 구조화된 규칙으로 변환하는 기능입니다.

예시:
- "동생이 해킹하는 동안 적이 5m 안으로 접근하면 미끼를 써 줘."
- "체력이 30 아래로 떨어지면 회복해 줘. 단 배터리는 최소 20 남겨."
- "내가 쓰러지면 가능할 때 바로 부활시켜 줘."

**구현 원칙**
- LLM: 자연어 → 조건·행동 JSON 변환
- C++: 조건 감시, 배터리 검사, 스킬 발동
- 규칙 등록 시에만 LLM 호출하며, 실시간 전투 중에는 호출하지 않음
- 기존 10개 스킬을 재사용
- 조건과 행동은 허용 목록(Whitelist)으로 제한
- 복합 AND 조건 지원, 규칙 2개 이내, 기본 1회 발동

이 기능의 핵심은 **LLM이 자연어 명령을 지속적으로 실행 가능한 게임 규칙으로 컴파일한다는 점**입니다.

### ② 증거 기반 보안 AI 설득 퍼즐 — 핵심 차별화 기능

기존 해킹 퍼즐 중 하나를 자연어 설득형 퍼즐로 확장합니다.

예시 상황:
- 오빠는 '비상시 작업자 안전을 최우선으로 한다'는 보안 규정을 발견
- 여동생은 '냉각 시설 고장과 관리자의 사고 은폐 기록'을 발견
- 두 플레이어가 단서를 공유
- 여동생이 보안 AI에게 증거와 논리를 제시해 문을 열도록 설득

**구현 원칙**
- LLM: 플레이어 설득문의 주장·증거·논리적 관계 해석
- 게임 서버: 실제 획득한 증거, 퍼즐 필수 조건, 접근 권한 확인
- LLM이 문 열림 여부를 단독 결정하지 않음
- 미발견 증거나 숨겨진 정답은 LLM에 전달하지 않음
- 단순 명령, 근거 없는 주장, 프롬프트 인젝션은 통과하지 못하도록 검증
- 퍼즐 1개, 핵심 증거 2~3개로 범위 제한

**핵심 목표는 정해진 답을 입력하는 것이 아니라, 플레이어가 수집한 정보를 자연어로 연결해 논리적인 해결책을 구성하는 게임플레이를 만드는 것입니다.**

### ③ 협동 작전 계획 시스템 — 시간 여유가 있을 때

두 플레이어의 게임 상태와 수집한 단서를 기반으로 드론이 작전을 제안하는 기능입니다.

예시:
"동생이 단말기를 해킹해야 하는데 적이 많고 탄약도 부족해. 어떻게 하지?"

드론:
"적을 모두 처치하기보다 미끼로 유인하는 편이 유리해요. 제가 적을 유인할 테니 오빠는 동생을 보호해 주세요."

**구현 원칙**
- LLM: 현재 상태와 목표를 바탕으로 최대 3단계 작전 제안
- C++: 각 행동의 실행 가능 여부 검증
- 플레이어가 승인한 행동만 실행
- 기존 스킬과 게임 상태를 최대한 재사용
- 드론은 플레이어가 발견하거나 전달한 정보만 활용
- 작전 계획은 제안이며 무조건적인 자동 실행이 아님

이는 드론이 단순 명령 수행자를 넘어 **플레이어와 협동하는 전략적 동료**가 되도록 하는 기능입니다.

## 3. 공통 설계 원칙

1. LLM은 자연어 의미 해석, 단서 간 관계 추론, 작전 계획 생성에 집중합니다.
2. 게임 코드가 스킬 실행, 배터리 소모, 조건 검사, 퍼즐 정답 판정을 최종 결정합니다.
3. 출력은 JSON Schema 기반으로 구조화하고 FastAPI에서 검증합니다.
4. 게임 상태가 요청 시점과 응답 시점에 달라질 수 있으므로 실행 직전 재검증합니다.
5. 플레이어와 게임 문서의 자연어는 신뢰할 수 없는 데이터로 취급합니다.
6. 분할 화면의 비대칭 정보 구조를 유지하여 드론이 모든 단서를 자동으로 알려주지 않도록 합니다.
7. API 호출을 최소화하고, 실시간 판단은 가능한 한 C++에서 처리합니다.
8. 기존 구현된 기능과 아키텍처를 최대한 재사용합니다.

## 4. 개발 우선순위

**1순위: 자연어 조건부 지시 시스템**

구현 비용이 상대적으로 낮고 기존 드론 구조를 활용할 수 있습니다.

**2순위: 증거 기반 보안 AI 설득 퍼즐**

LLM을 게임플레이에 활용했다는 사실을 가장 설득력 있게 보여줄 수 있습니다.

**3순위: 협동 작전 계획 시스템**

앞선 두 기능이 안정적으로 동작할 경우에만 구현합니다.

제출 일정이 촉박하므로 새로운 대형 시스템을 여러 개 만들기보다는, **기존 레벨 하나에서 위 기능들을 시연할 수 있는 Vertical Slice**를 구성하는 것이 목표입니다.

## 5. 발표 및 검증

LLM을 사용한 의미를 객관적으로 보여주기 위해 키워드 매칭 방식과 비교 실험을 진행할 계획입니다.

비교 항목:
- 자연어의 다양한 표현에 대한 해석 정확도
- 복합 조건 및 부정 조건 처리
- 두 플레이어가 제공한 단서의 논리적 통합
- 근거 없는 설득 및 프롬프트 인젝션 거절
- 응답 지연과 API 호출 수

특히 같은 의미를 서로 다르게 표현한 문장들을 테스트하여, 단순 키워드 탐지를 넘어서는 의미 해석 능력을 보여주고자 합니다.
