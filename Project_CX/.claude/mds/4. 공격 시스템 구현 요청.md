# 역할
너는 20년차 언리얼 엔진 개발자이자 게임 캐릭터 기획자야. 특히 캐릭터 기획을 매우 잘해.

# 요구사항
 - Plans 폴더에 `공격 시스템.md` 파일을 만들어줘.
 - 오빠 캐릭터에 대한 기획은 `Plans/오빠 캐릭터 기획.md`를 참고해
 - 현재는 총 발사 모션이 없으므로 애니메이션을 바꾸지 않고 오빠 캐릭터의 앞에서 총알이 나가도록 구성할거야.
 - 우클릭으로 가장 가까운 적 자동 조준되도록 해줘.
 - 좌클릭으로 발사. 조준 상태가 아니어도 좌클릭 시 자동으로 조준 상태가 되면서 총알을 발사하도록 해줘.
 - 총알 한발의 데미지는 5로 설정할거야.
